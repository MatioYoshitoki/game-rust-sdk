# OBS-05 镇龙压制属性裁定

2026-11-07，用户明确选择“按文字：攻速降低30%”。`effect_zhenlong_suppress`的第一项旧`fix_attribute[1,-30,1]`映射为通用`attack_speed=-3000bps`，不再解释为ATK减少。原资料包及历史审计保留不变。

来源：source-config的状态说明、zhenlong-baoshu施加5000ms/1层，以及source-rules文档55（cultivation-insight.INTERFACE）“普通攻击冷却推进减速”。攻速表示普攻冷却的推进速率：10000bps正常、7000bps为原速率的70%，不是把间隔加30%。只调整成员普攻及NPC近战普攻，不调整ATK、SPD、技能准备/后摇/CD、引导脉冲或已释放弹道。

当前冷却实时推进，状态开始/叠层/刷新/结束/来源退出在逻辑边界生效；状态到期跨步分段积分。1000ms基础冷却、全程-30%时向上取整为1429ms；若仅前300ms有效，则总1090ms。零速率暂停推进，有限状态到期后恢复，不除零；多来源叠加下限0，上限由配置控制。排队普攻随就绪时刻更新其提升/宽限窗口，原目标和动作ID不变。

本裁定只关闭OBS-05中该项攻速/ATK歧义。其龙威资源、按层移速、满层消费/控制/Boss转换及OBS-05其余两项不因此签收。
