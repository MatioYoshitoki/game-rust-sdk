# SDK-5-92 每席训练目标操作验收

SDK 0.159.0，机制 105，配置 schema 7，协议 6。使用独立合成输入复现 S32 的目标清理和零成长写入断言。 [范围与验收标准](../batches/SDK-5-92-progression-modes-and-privacy.md#gp05-每席训练目标操作) · [接入契约](../interfaces/publications-v6.md#每席训练目标)

| 验收路径 | 结果 |
|---|---|
| 目标归属 | A 无法选 B 的目标组或攻击 B 的训练目标。宿主配置拒绝跨席共享、遗漏归属和收费准入。 |
| 战斗运行时 | A 和 B 都有在途弹道和区域效果。A 清理后，仅 B 的原弹道、区域和召唤保留，B 的目标生命、实体代次和本人状态保持原值。B 的原弹道随后实际扣除 10 点生命。 |
| 换组和重连 | A 可以切换预设再切回。重建后的目标使用新代次，旧目标输入和旧连接请求被拒绝。A 同局重连保留已选目标组。 |
| 退场和资产 | 目标操作期间无资产事务提交。击倒训练目标没有掉落或成长计分。A 退场后 B 仍可参战。两席各有一次空扣费准入和一次空入账退场凭据。对局正常关闭，未决责任为零。 |

普通 Node 宿主连接真实 Rust 进程和 SQLite 跑完一场双人对局。7 条全量和 44 条增量通过协议 Schema 和 Node 解码。

Rust 默认与全特性各 96 项、Node/H5 共 233 项通过。格式检查、Clippy 全目标全特性、最小宿主编译和普通内核构建通过。 [Rust 双人隔离回归](../../src/world/two_members/training_target_contract_tests.rs) · [Node 解码回归](../../adapters/node/replication.test.mjs)

本轮训练目标采用固定靶。移动靶、训练专属复活、训练指标和正式宿主数据验收继续按 R5.3/R6.2 跟踪。
