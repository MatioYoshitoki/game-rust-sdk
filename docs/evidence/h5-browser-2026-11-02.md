# H5 浏览器验证记录

日期：2026-11-02。范围：本地 H5 前端和 HTTP/SSE 适配，连接 B1 Rust 内核及受控内存存储。流畅度修复为 Create 增加有限发布模式；B1 验收已按本轮源码重新执行并绑定哈希，冻结配置不变。

后续 B2-1 已加入进程内刷新/断线恢复，本文九项原有浏览器检查已按最新实现回归通过；新增六项连接恢复验收单列在 [B2-1 记录](B2-1-reconnect-2026-11-02.md)。

实际执行 `python3 scripts/verify_h5.py`，先执行四项投影/坐标测试，再构建 Rust `kernel-host`，在临时本机端口启动服务，并以 Chromium/Playwright 驱动网页。**八个功能场景及实时性能检查通过，页面脚本异常为 0。** 测试服务在结束时已退出。

| 场景 | 实际验证 |
|---|---|
| 实时手动操作 | 键盘移动/松开停止，保护暂停/恢复，提前撤离拒绝；关闭后仓库 98、一次死亡结算、未决责任 0 |
| 等距操作与坐标 | WASD 按屏幕上下左右移动，组合键斜向；实际攻击击杀后走向静态墙，持续输入不穿透；窗口缩放后鼠标指向反算为正确的世界施法方向，内核真实提交技能 |
| 正常自动闭环 | 浏览器完整进入至撤离；仓库 102、修为 30、一次入场/结算，五个闭环步骤完成 |
| 结算回执丢失 | 真实存储提交后 unknown；内核查询原结果，金额不重复 |
| 存储拒绝与核对 | 拒绝时仓库 95、结算 0、未决 2；手动核对后完成相同终局向量 |
| 关闭后核对 | 未决期间创建新实例被拒；原 World 已关闭，冻结责任仍可核对完成，金额与次数不变 |
| 取消自动操作 | 关闭按钮取消自动流程，内核按关闭流程结算，操作按钮重新可用 |
| 手机尺寸触控 | 390px 宽无横向溢出；真实触控向右时世界 x 增/y 减、投影方向水平向右；抬手停止，可正常关闭结算 |

同时检查：另一浏览器所有者无法读取当前实例，附带世界字段的操作载荷被拒绝，普通 HEAD/GET 页面可访问。所有业务均经同一公开边界，没有更改内核规则来配合页面。

## 等距地图验收

H5 已改为 2:1 菱形地面投影，共用的正反变换覆盖地面、脚点、障碍、掉落、范围和指针。立体障碍分段后与实体按地面深度排序；地图网格缓存，保留 30ms 同步及收到位置间的插值。四项 Node 测试检查负坐标/小数坐标正反变换、屏幕方向在 Rust 归一化后的朝向、桌面/手机与偏移矩形地图的视口适配，以及 2:1 比例和显示高度。

浏览器专项经公开操作把角色走到真实墙前，验证持续输入仍被阻挡；调整视口后实际反算并提交约 `[40,-140]` 的施法方向，内核事件确认技能成本 20。新局按键状态会清空，替换会话前结束旧确认流，避免旧请求进入新局。具体实测坐标、源码 SHA-256 与九项浏览器结果见下方机器报告。等距视角下完整撤离、故障核对和死亡结算的金额与次数约束继续通过。

等距场景的独立性能数据见 [performance-isometric.json](../../artifacts/h5/performance-isometric.json)，采集真实 SSE 与 Canvas 角色标签绘制坐标；单帧位移使用 CSS 像素计量，不与下方历史世界坐标值混用。下方平面视角的流畅度数据保留为修复历史。

## 流畅度复测

修复前场景直接绘制约 270ms 一次的冻结位置，没有插值；浏览器动画帧本身正常，输入 HTTP 约 2～9ms，没有检测到主线程长任务。主因是状态发布频率不足。实时模式现选择每步发布，并对已收到的位置作显示插值；确认队列与按键分离，账本按变化推送，HUD 合并更新。一键验收后再创建一局，仍按原手动时钟选择启动。

同机 Chromium，真实 Rust 子进程、SSE 与公开输入，连续向上/向下移动各 1.4 秒：

| 指标 | 修复前 | 修复后 |
|---|---:|---:|
| 快照间隔中位数 | 276.2ms | 30.6ms |
| 快照间隔 P95 | 279.6ms | 31.9ms |
| 动画帧间隔中位数 | 8.3ms | 8.3ms |
| 主线程长任务 | 0 | 0 |
| 按键到首份实际移动状态 | 未采集 | 23.9ms |

复测还拦截 Canvas 的实际角色绘制坐标：稳定走动期间 97.7% 的相邻帧位置发生变化，最大单帧位移 3.28 世界单位，证实画面使用平滑过渡。机器原始数据见 [修复前](../../artifacts/h5/performance-before.json) / [修复后](../../artifacts/h5/performance-after.json)。这是本机短时试玩表现，不作生产容量结论。
