2026-11-10，SDK 0.142.0，机制 105，schema 7，协议 6。RL01～RL04 的环境节点、多人容器和堆叠库存使用独立合成输入通过。 [模块范围](../batches/SDK-5-91-resources-instances-and-containers.md) · [配置与接入](../interfaces/world-loot-v1.md)

| 验收 | 结果 |
|---|---|
| RL01 奖池 | 固定条目、0/100% 独立概率和组内无放回复现。组内两条不同记录各出现一次，数量落在配置闭区间。 |
| RL02 环境节点 | 热点候选优先使用已放置的共享容器锚点。定时阻挡关闭时冻结抽样，解除后使用同一抽样与合法落点。最后一堆拾取或过期后重新计时，新代使用新资源 ID。 |
| RL03 多人容器 | 验证存活守护者拒绝开启、同一容器的竞争、保护与取消释放。地面预算满时保留开启费用，重试成功后仅扣一次。私有资源和事件仅向对应席位发布，隐藏容器按距离和视线展示。自动参战席位通过原生动作开箱和拾取。 |
| RL04 部分拾取 | 5 件堆叠按 3 和 2 分给两名成员，满包失败后余量与原 ID 保持。Node 重投同一请求仅发布一次部分更新，取尽仅发布一次移除。 |
| 公开宿主与账本 | 两局 Node 协议 6 联调分别验证部分拾取与容器。撤离后物品余额分别为 `[7,6]` 和 `[6,6]`，每席位结算一次，未决责任为零。从两份冻结检查点重启后余额和结算次数一致。JSON Schema 校验 82 个发布封包，其中 16 个包含可见容器。 |
