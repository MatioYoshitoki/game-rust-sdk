|---|---|
| 装载与提交 | 拒绝未知模板、数量越界和过短寿命。两成员各一个槽位时，输出容量 152 装载成功，151 拒绝。已满和落点失效时保持灵力、气血和冷却，提交成功一次性创建完整数量。 |

| 公开接入 | Rust 与 Node 解码器通过全量、增量、重连与非法引用回归。真实 Node 宿主连接普通时钟 Rust JSONL，两组输入分别为每人一只和两只。都通过重复提交去重、满额拒绝、来源连接代次升至 2 后保留召唤身份、退场增量回收及各结算一次，未决责任为零。 |
