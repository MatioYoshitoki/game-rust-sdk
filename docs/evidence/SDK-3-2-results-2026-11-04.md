真实进程通过 33 个结果阶段和 7 个强杀边界：

- 默认撤离/死亡金额与原版一致，结果 ID 可更换；结算请求与事件使用配置结果和策略。
- 四种策略组合覆盖两条触发，包括交换策略和同策略绑定。死亡选择 preserve 时完整保留并获得收益 30；撤离选择 attrition 时按配置损耗并获得收益 3，资格和时点仍由 Rust 判定。
- Unknown 查询原证明、fencing 未提交按原正文重试、拒绝后保留原核对责任；重复调用/存储执行/回执只生效一次。
- 未就绪仅退入场，激活后关闭按死亡触发的绑定策略结算；关闭后继续处理冻结责任。
- 入场、结算、补偿中断后连续两次恢复保持原 ID、策略、金额与业务身份；不重建 World。冻结后修改外部结果 ID/策略，旧责任仍按保存的原文/hash 完成。
- 一项普通时钟完整对局通过，其余加速场景仍由 Rust 自行推进逻辑时钟。
