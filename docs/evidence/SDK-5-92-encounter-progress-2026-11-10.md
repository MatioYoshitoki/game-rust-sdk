# SDK-5-92 共享击杀进度与阶段验收

| 验收路径 | 结果 |
|---|---|
| 共享进度 | 真正击倒原生目标后扣减。原模板保持原值，在场目标换档时保留生命比例。成员间击倒不会扣减。 |
| 一次性强化 | 首次归零开启。后续击杀保留原截止。首次登场的下一波采用强化属性，到期回到零值常规档。验证四档掉落量，以及触发击杀使用旧池。 |
| 阶段时间 | 达标可提前推进，未达标到期仍按配置进入下一阶段。配置为固定截止的后续阶段保持相同的总预算。同刻到期先于旧阶段命中。末波未完成时结算失败。 |
| 发布 | 成员重连全量保留计数和阶段截止。成员与旁观全量、增量通过协议 Schema 和 Node 解码。解码拒绝进度倒退、延长强化和提前清除倒计时。旁观资源不包含物品 ID 和私人账本。 |
| 持久结算 | 普通 Node 宿主连接真实 Rust 进程与 SQLite 跑完两场双人局。达标局 B 拾取 3 件强化掉落，结算回执模拟丢失后经查询确认，物品与附属事实仅提交一次。超时局末波未清，失败结算无通过事实。两局均正常关闭，未决责任归零。 |
