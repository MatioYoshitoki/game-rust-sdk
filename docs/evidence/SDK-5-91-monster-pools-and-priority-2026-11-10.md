# DELIVERY-04 怪物一次性掉落与贡献优先期验收

2026-11-10，SDK 0.143.0，机制 105，schema 7，协议 6。使用独立合成输入验证 RL05a。 [模块范围](../batches/SDK-5-91-resources-instances-and-containers.md) · [配置与接入](../interfaces/world-loot-v1.md)

| 验收 | 实测结果 |
|---|---|
| 一次性供应 | 怪物模板绑定统一奖池。未知奖池、旧表同时配置、超出容量的奖池和非法优先时长拒绝装载。地形阻挡与堆数预算满载期间保持原抽样；成功投放后独立计时，过期回收且不补充。 |
| 贡献与竞争 | 一席实际扣血 60，另一席提交 100 伤害但实际只扣 40。后者获得击杀，前者获得拾取优先权。验证同分稳定排序、召唤伤害归所有者、怪物回巢重置清除贡献、优先者终局立即释放。 |
| 双成员与重连 | Node 通过协议 6 观察同一公开资源。非优先者被拒，优先者拾取 3 件后重连，保持同一资源 ID、2 件余量和优先权。到期后另一席取尽，部分更新和移除各一次。83 个发布封包通过 Schema 验证。 |
| 守恒与恢复 | 5 件实际供应对应两席净拾取 3 和 2。两席撤离各结算一次，持久余额为 7 和 6。冻结账本重启后余额、结算次数一致，未决责任为零。把其中一席的净拾取与入账同时增加 1 并重算摘要后，恢复拒绝合计超出供应的账本。 |

Rust 默认和全特性各 45 项，Node/H5 218 项。格式、Clippy 和最小 Rust 宿主离线检查通过。重连验收覆盖同一运行中 World；进程重启覆盖冻结的结算账本。实例物品、死亡遗物和模块整体验收待完成。 [合成回归](../../src/world/two_members/world_loot_contract_tests.rs)
