# DELIVERY-05 旁观权限与分席发布验收

2026-11-10，SDK 0.154.0，机制 105，配置 schema 7，协议 6。用合成输入运行 Rust、Node 和 SQLite。 [批次范围](../batches/SDK-5-92-progression-modes-and-privacy.md#gp06-旁观与多人组合范围) · [旁观接入](../interfaces/publications-v6.md#旁观发布)

| 验收 | 实测结果 |
|---|---|
| 公开投影 | 三人局的公共伤害、位置与地面对象可见。私人容器掉落只有拥有者收到，公开对象只含 ID、位置与期限。伪造的私有字段、事件及错误接收者被解码器拒绝。 |
| 基线及换代 | 两个旁观席同时接收，只有已发送一席得到后续增量，失败一席重发全量。跨席回执、旧连接回执和旧代重新订阅被拒绝。重新分配席位后使用新连接全量。 |
| 容量 | 合成 Rust 对局配置八个参战席与八个旁观席。四席推进增量，四席暂停至超时并独立重发。参战成员保持就绪。 |
| 真实持久结算 | 三人局在旁观回调挂起时完成移动、伤害与私人掉落；两局五个参战席各完成一次入场和一次结算。旁观发布保留在传输层，SQLite 账本沿用原责任和成员输出。 |
| 终局观礼 | 双席对抗的判负成员在原参战视图保留期后由宿主授权旁观。公开胜负可读，重新请求返回相同终局视图。旁观保留期截止时缓存回收，后续接入被拒绝。 |

Rust 默认和全特性各通过 83 项，Node/H5 通过 225 项。实际旁观发布共 21 帧，包含 10 帧全量和 11 帧增量，全部通过 Schema 和私有字段检查。格式、Clippy、最小 Rust 宿主离线检查及历史资料开关下的源码编译通过。 [Rust 旁观回归](../../src/two_members/spectator_tests.rs)

原具名场景、实际网关与生产几何和容量组合继续按既有工作包验收。
