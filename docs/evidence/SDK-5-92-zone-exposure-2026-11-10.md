# SDK-5-92 区域停留与共享交互验收

SDK 0.164.0，机制 105，配置 schema 7，协议 6。使用独立合成输入。 [需求与验收标准](../batches/SDK-5-92-progression-modes-and-privacy.md#gp05-区域停留累积削弱与共享交互) · [接入契约](../interfaces/publications-v6.md#区域停留与共享交互)

| 验收路径 | 结果 |
|---|---|
| 区带与时钟 | 验证阈值等号、跨带保留比例、首次积层、同刻重复推进、满层停止、减层后重新累积和硬截止。连接保护期间继续积累，重连后保留同一份状态。 |
| 交互竞争 | 验证距离、移动阻挡、无层减层、旧修订和冷却边界。两席同时选择不同分支时只接受一席，原请求重放保持同一修订和冷却。另一席在就绪后可获得增益。再次使用刷新期限，增益到点失效。 |
| 实际战斗 | 层数和短时增益共同改变实际普攻与技能共用的攻击值和物理承伤。同一份合成输入下，短时增益使技能实际扣血为 45。 |
| 发布与清理 | 实跑 158 条成员帧和 107 条旁观帧通过 Node 复制器及协议 Schema。区带、层数与增益期限只发给本人。A 退场清除个人状态，B 的增益、冷却修订和累积继续。 |
| 双席结算 | 真实 Rust 进程经 Node 宿主接入 SQLite。A 主动退出，B 正常撤离。两席各准入和结算一次，未决责任归零，资产恢复检查点省略局内暴露状态。 |
