# SDK-5-92 H5 参考客户端权威等距渲染验收

SDK 0.172.0，机制 105，配置 schema 7，协议 6。 [范围](../batches/SDK-5-92-progression-modes-and-privacy.md#h5-权威等距渲染与正交回归) · [等距契约](../interfaces/world-geometry-v1.md#权威等距格网)

共享投影模块 `web/isometric.js` 新增 `plain` 投影、`projectionFor`、`toWorld` 与 `tilePolygon`，数值对齐内核 `to_world`。协议 6 双席参考页 `web/delta.js` 在配置声明 `pve.isometric_grid` 时按真实世界坐标渲染菱形地块、圆形足迹与沿世界轴的 WASD/点击输入；正交配置继续走 2:1 显示投影。`two-member-server` 的 `/api/view` 向浏览器透传 `isometric_grid`。合成 6×6、`cell_size` 64、`tile_height` 32、`origin [-100,20]` 地图驱动真实内核验收。

| 验收路径 | 结果 |
|---|---|
| 等距渲染 | Chromium 双席对局。阻挡地块 (2,1) 中心 `(-68,84)` 采样为 `#344854`，可行走地块 (4,1) 中心 `(-4,116)` 与 (5,1) 中心 `(28,132)` 采样为 `#243d3e`，均落在权威世界坐标处。B 席独立视口同图渲染通过。 |
| 输入映射 | 等距局 WASD 沿世界轴：按 `d` 后位置 `(-100,68)→(-73,68)`，仅横轴变化。点击地块 (2,3) 中心，公开输入的 `navigate` 目标为 `[-132,116]`（误差 <1），内核沿菱形格网寻路推进。 |
| 正交回归 | 同尺寸正交配置（无 `isometric_grid`）复验：方块地块经 2:1 显示投影渲染、`d` 保持屏幕右对角（世界 +x/−y）、点击反演回 `[224,288]`。等距重写未改变原路径。 |
| 单元与门禁 | `adapters/h5/isometric.test.mjs` 新增 4 项：投影选择、`toWorld` 对齐内核参考值、菱形/方块顶点与全宽/全高对角线、plain 视口包围盒与距离均匀性。Node/H5 共 246 项、Rust 默认与全特性各 122 项、格式、Clippy 全目标全特性、最小宿主编译和真实内核构建通过。 |

接入方浏览器渲染权威等距输入的参考实现就位。正式宿主库存、转世选择及封存仍待实际接入；生产装饰、阵法和具名场景按原宿主范围跟踪。
