# DELIVERY-03 高差、坡道与地形伤害验收

2026-11-10，SDK 0.139.0，机制 105，schema 7，协议 6。GN04 使用合成地形和数值。坡道按格内轴向线性插值，跨格限值取离开的格。地形伤害在主动移动前采样，减伤后保留不足 1 HP 的余量。 [验收范围](../batches/SDK-5-90-geometry-navigation-and-ai.md) · [配置与协议](../interfaces/world-geometry-v1.md)

| 验收 | 结果 |
|---|---|
| 配置准入 | 拒绝未启用世界几何的高差配置、越界高程和跨格限值、非法坡道、超出精度的伤害和不足的输出预算。 |
| 高差与导航 | 20 高差阻断低处直行，允许在离开格限值内下行。斜穿格角拒绝绕过不可跨接缝，普通移动在崖前停下，强制位移截在首个接缝前，寻路经连续坡面到达高地。视线和弹道仍按各自阻挡配置判断。NPC 在归位半径内也绕开不可跨接缝，到达出生点后才完成归位和恢复。 |
| 暴露与防御 | 50 HP/s 在 30 ms 步长产生 1、2 交替扣血。50% 减伤后 4 步累计扣除 3 HP。采样到安全格、保护或免伤时清除余数。按免伤、减伤、吸收盾、致死保护和扣血结算。扣血可打断撤离。 |
| 生命周期与归属 | NPC 地形死亡没有击杀归属和掉落。召唤体死亡后立即退出发布并在下一步回收，所属成员可继续行动。 |
| Node 宿主 | 真实双成员协议 6。危险格成员收到 25 次无攻击者的 `terrain_damage`，在 x≈30.8 处停下，经坡道抵达 `[80,20]` 时 HP 为 75，另一成员保持 100。连接代次 2 的全量帧恢复相同位置和 HP。两成员各结算一次，未决责任为零。 |
