# DELIVERY-05 加持护盾、费用与替换验收

2026-11-10，SDK 0.149.0，机制 105，schema 7，协议 6。使用独立合成输入验证同一 World 内的加持护盾、资源扣费和状态来源。 [批次范围](../batches/SDK-5-92-progression-modes-and-privacy.md) · [接口](../interfaces/world-boons-v1.md)

| 验收 | 实测结果 |
|---|---|
| 费用 | 原价 19。两级倍率后的预约为 12、9，取消预约保持原灵力。零费用保留零，正费用最低为 1。自动参战席按 12 点准入并扣费，实际回执与预约一致。 |
| 标记清理 | 同一成员的普通技能状态和另一成员的同定义状态均保留。替换当刻只删除旧加持产生的两个标记。第一席退出后第二席的状态仍可见。 |
| 护盾与来源 | 普通盾上限 30，普通盾与一级加持共 40。非 NPC 来源只吸收普通盾，原生 NPC 可耗尽加持盾。升阶保留余量 5，下一击吸收 5 并扣除 2 点生命。保护期间到时未重建，重新就绪后按二级生成 60。替换后普通盾与新加持共 50，退场清零。 |
| Node 双席 | 费用不足保留空槽。首席三次实际扣费为 12、9、19，护盾首获与重建为 12、24。重连保留已强化槽位和未到期的重建时钟，替换同步移除护盾与标记。两条条件触发均投递首席，两席各结算一次。 |
| 配置和协议 | 两个加持定义片段及三种非法变体通过 Schema 正反向校验。97 条真实全量或增量发布通过协议 6 Schema。Rust 目录另行校验等级序列、重建步长和输出预算。 |
