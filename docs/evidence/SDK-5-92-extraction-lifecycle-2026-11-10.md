# SDK-5-92 撤离时限与读条广播验收

SDK 0.162.0，机制 105，配置 schema 7，协议 6。使用合成输入验证遗迹崩塌与撤离广播共用机制。 [验收范围](../batches/SDK-5-92-progression-modes-and-privacy.md#gp05-撤离时限终局宽限与读条广播) · [接入契约](../interfaces/publications-v6.md#撤离时限与读条广播)

| 验收路径 | 结果 |
|---|---|
| 时钟 | 部署期省略时钟，激活后全房共用硬截止。三个预警阈值按配置投影，重连与 A 离场保持 B 的时钟。A 的重新发布保留离场时的阶段。 |
| 宽限伤害 | 配置间隔跨步后只结算一次。最大生命为 100 的 B 在一跳中先消耗 10 点护盾，再扣除 5 点生命并中断读条。护盾全额吸收时可以在同刻完成读条。连接保护席位仍参与时限伤害，免疫在宽限内生效。 |
| 硬截止 | 读条恰好到期时，硬截止先结算。仍在场成员与原生目标生命归零，覆盖连接保护与免疫。环境结算无击杀积分。A 已完成的撤离保留。 |
| 发布与隐私 | PvP 受击和本人取消各有一次中断。B 重连全量可见 A 原读条的起始位置与时刻。成员和旁观全量、增量通过 Node 解码与协议 Schema。普通局保留本人读条，终局全量不含其他成员在途读条，旁观帧无库存或账本字段。 |
| 持久结算 | 普通 Node 宿主连接真实 Rust 进程与 SQLite 完成一场双人局。A 撤离取回 1 件战备，B 到达硬截止时进入死亡结算，1 件战备按死亡损耗处理。两席各一次准入和结算，未决责任归零。 |

最终构建实跑校验 179 条成员帧和 135 条旁观帧，分别含 15 条和 6 条全量。该次 B 的读条结束时间晚于硬截止一个模拟步。同刻优先级由 Rust 固定步回归验证。

Rust 默认与全特性各 106 项、Node/H5 共 237 项通过。格式、Clippy 全目标全特性、最小宿主编译和普通内核构建通过。 [Rust 回归](../../src/world/two_members/extraction_lifecycle_contract_tests.rs) · [Node 解码回归](../../adapters/node/replication.test.mjs)

具名地图和正式数据由宿主接入。遗迹竞夺装备、追猎和深度状态等剩余流程按 R5.3 跟踪。
