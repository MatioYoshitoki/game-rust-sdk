# SDK-5-92 训练运行时验收

SDK 0.160.0，机制 105，配置 schema 7，协议 6。验收使用独立合成输入。 [范围与验收标准](../batches/SDK-5-92-progression-modes-and-privacy.md#gp05-训练目标行为复活与个人统计) · [接入契约](../interfaces/publications-v6.md#目标行为复活与个人统计)

| 验收路径 | 结果 |
|---|---|
| 训练目标 | 移动靶实际往返。定时挡板关闭时停下，打开后继续。永久阻断的路线在加载时拒绝。可重建靶承受超杀时只扣实际生命，换代后拒绝旧目标引用并中断仍指向旧代的读条。 |
| 战斗与复活 | 训练 NPC 选择所属席位。A 被真实弹道击倒，A 的区域清除，B 的原区域、目标和实体保持有效。A 倒地时拒绝移动，连接丢失后仍按时在宿主指定点满生命和灵力复活。重连后实体代次递增，技能冷却和统计保持。倒地退出取消复活排程。 |
| 私有统计 | A 的 15 点技能暴击实际扣血计为一击，记录来源、暴击、最高值和两类 DPS。滚动伤害滑出后归零，历史总量保留。重置 A 只清空 A。成员解码拒绝过期复活时间和不一致的来源合计。旁观投影不含倒计时和个人统计。 |
| 资产与终局 | NPC 击倒和训练操作期间无资产事务提交。两席各有一次空扣费准入及空入账退场，零训练掉落和成长计分。房间正常关闭，未决责任为零。 |
