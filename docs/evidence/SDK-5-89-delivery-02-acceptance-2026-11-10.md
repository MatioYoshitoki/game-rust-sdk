# DELIVERY-02 武器、世界效果与召唤签收

2026-11-10，SDK 0.137.0、机制 105、schema 7、发布协议 6。R3.4 与 R3.5 的 SDK 机制范围通过验收。 [模块规格](../batches/SDK-5-89-world-effects-and-summons.md) · [召唤配置](../interfaces/combat-rules-v1.md#有界成员召唤)

资料核对使用包外《rust-match-kernel-v1.1》中的 `behavior.md`、`source-config.json` 的 `factor_summon` 与技能说明，以及 `source-rules.json` 内的功法战斗设计和接口。它们要求复制普通非终极技能、共享复制间隔、按比例继承 ATK/DEF/最大生命，以及实际死亡时的有限爆破。宿主用白名单声明可复制技能、阶段和数值，SDK 提供授权、判定和结算。历史游戏配表、阶段比例和原始测试向量仍由宿主验收。 [来源路由](../audits/sdk-5-17/README.md)

| 验收 | 结果 |
|---|---|
| WE01 接触与世界效果 | 复用既有六类普攻、器型、位移和轨迹证据。新组合验证墙挡复制弹道、陷阱首次进入与限次、锚点迁移带动依附领域、每跳上限，以及同一步内按来源清理。 |
| WE02 配置与预算 | 循环召唤、陷阱、锚点、未知或重复 ID 在装载时拒绝。真实 JSONL 校验弹道组合输出容量 380 可装载、379 拒绝，圆形组合 272 可装载、271 拒绝。满额、非法落点、越权锚点和释放重验失败各保留相应费用或冷却。 |
| WE03 召唤与复制 | 两成员各有实体身份、额度和共享间隔，成员内每只召唤体有独立的每技能冷却。定点主动攻击和敌方承伤走共享伤害链。属性冻结后改变本体攻击也不重采样。单位、圆形、方向和锁定弹道均执行授权伤害。目标失效不消耗共享间隔。实际死亡执行一次限目标爆破，并回收自己的弹道和状态，其他来源继续运行。退出、到期、换代和关闭不爆破。 |
| WE04 公共接入 | 同一机制构建运行两组包外 Node → Rust JSONL 场景，分别是每人两只加弹道复制、每人一只加圆形复制，两组都叠加陷阱与迁移锚点领域。通过重复提交去重、共享场内伤害、连接代次 2 全量恢复、离场增量清理，以及独立入场和结算各一次，未决责任归零。解包后的 release Rust 二进制和随包 Node 宿主再次通过两组场景。 |
