# DELIVERY-05 条件加持与召唤本体验收

2026-11-10，SDK 0.148.0，机制 105，schema 7，协议 6。使用合成配置验证加持槽的条件触发和召唤本体的伤害组合。 [模块范围](../batches/SDK-5-92-progression-modes-and-privacy.md) · [加持接口](../interfaces/world-boons-v1.md) · [召唤接口](../interfaces/combat-rules-v1.md#有界成员召唤)

| 验收 | 实测结果 |
|---|---|
| 条件被动与来源 | 首席领取前、另一席和派生接触均无触发。首席的零伤害合法接触施加一级减疗。同一动作的多次接触共用触发预算。被动附加的状态随来源退场清除。 |
| 等级与冷却 | 一级和二级分别引用 30% 与 60% 减疗。升阶与重连后，原冷却内仍未触发。同一动作到达冷却截止也无法重触发，新动作可用二级效果。替换后停止新的触发，已有状态按原时限执行。 |
| 召唤所有权与时点 | 首席同主两具召唤时输出从 12 增至 18，受击从 20 降至 15，召唤自身攻击仍为 7。第一具被致死后效果保留。最后一具到期同刻输出恢复 12，受击恢复 20。另一席的召唤按自身期限独立存活，退场时回收。 |
| Node 双成员联调 | Rust 子进程通过协议 6 处理真实施法、重连、到期和结算。首席五次实际伤害为 20、36、45、45、30，第二席为 10。一级与二级各发出一次私有触发，第二席收到零次。两席 SQLite 各提交一次结算。 |
| 配置 | Rust 拒绝缺少加持引用、非法动作汇总、无效高阶状态、不同效果类型和非法召唤倍率。启用召唤减伤需状态规则。两个真实输入片段及四个非法变体通过 Schema 正反向校验。 |

Rust 默认和全特性各 61 项，Node/H5 221 项。格式、Clippy、最小 Rust 宿主离线检查及历史资料开关下的源码编译通过。 [合成回归](../../src/world/two_members/boon_contract_tests.rs)
