# SDK-5-92 GP03 共享仓库格与位置写入验收

SDK 0.156.0，机制 105，配置 schema 7，协议 6。验收使用合成输入。 [范围与标准](../batches/SDK-5-92-progression-modes-and-privacy.md#gp03-共享仓库格与位置写入) · [接入契约](../interfaces/settlement-progression-v1.md#共享格)

| 验收路径 | 结果 |
|---|---|
| 共享占用基线 | 仓库按布局内堆叠、已持有实例和布局外占用计数。战备扣除释放一格。缺失可信占用、数值溢出、布局遗漏、实例误列为堆叠与零堆叠规格均拒绝。 |
| 容量分配 | 五格合成仓库从四格增至五格。第一类堆叠补入 1 并溢出 1，第二类使用最后一格，第三类溢出 2，两件新实例全部溢出。减少既有占用后可分配到实例。既有占用超过五格时可补齐原堆叠，总占用保持原值。 |
| 结算恢复 | 篡改冻结占用并重算摘要仍被 Rust 拒绝。恢复收到未提交证明后，以同一操作 ID 和事务正文重试。 |
| 位置与存储事务 | SQLite 合成测试拒绝共享格基线冲突，回滚保留资产、区域和原坐标。同区域迁移也会推进位置修订并清除坐标。旧修订、旧序号和同序号异值写入均拒绝，同序号同值可安全重试。重开数据库后查询并重试核心事务，保留新版本坐标。 |

Rust 默认与全特性各 87 项、Node/H5 共 227 项通过。 [Rust 成长契约测试](../../src/world/two_members/settlement_progression_contract_tests.rs) · [Node 持久化测试](../../adapters/node/two-member-host.test.mjs)

普通 Node 宿主使用真实 Rust 二进制和 SQLite。A 拾取四份资源后撤离，仓库占用 4→5。A 的核心提交回执丢失后，旧进程发出查询且暂不接收回复，B 在同一 World 完成独立结算。重开数据库并启动新 Rust 进程，按原操作查询后只追加一次附属事实。两席核心提交各一次，待处理责任归零。A 同区域位置修订 7→8，重启保留版本 8 的坐标，版本 7 的写入仍拒绝。

格式检查、Clippy 全目标全特性、最小宿主编译和普通二进制构建通过。启用历史测试入口的全目标编译通过。真实历史数据包留待接入验收。
