# 参战 NPC v1

SDK 0.141.0 的机制 105、schema 7 和协议 6 支持自动控制普通成员席位。在宿主的冻结目录中，顶层 `participant_ai` 按 `CreateV6.participants[].participant_id` 提供策略。席位仍需要真实、独立的宿主账户绑定及正常的入场收据、加入、全量送达和就绪输入。创建时拒绝缺席的策略引用。

| 字段 | 契约 |
|---|---|
| `decision_interval_ms` | 决策间隔，从固定步长到 60000 ms。仅对就绪、存活且当前可操作的成员执行。 |
| `loot_radius` / `threat_radius` | 地面物品搜索和可接战怪物的发现半径，范围 0～10000。0 关闭相应分支。 |
| `withdraw_hp_bps` | 当前 HP 比例达到或低于此值时进入撤离路线，范围 0～10000。0 关闭低血撤离。 |
| `extract_after_looted` | 本局实际累计拾取件数达到此值时撤离，范围 0～1000000。0 关闭配额撤离。 |
| `extract_before_timeout_ms` | 剩余对局时间达到或低于此值时前往撤离点，范围 0～对局时限。0 关闭提前撤离。 |
| `search_points` | 可选，最多 16 个合法世界坐标。没有战斗和可拾取物品时依序前往，抵达后继续搜索。 |
| `combat_skill_id` | 可选，指向宿主配置的敌方指定单位效果。决策使用成员当前装备的技能、资源、冷却和公开目标，提交仍按原生技能资格检查。 |

达到低血、拾取或时间条件，或发现敌方而当前缺少可用战斗技能时，撤离意图保持到终局。Rust 使用 `Navigate` 和 `ExtractStart`，按地图连通、开闸、距离和引导条件推进。进入保护时停止决策，恢复就绪后继续。战斗走 `CastUnit`。搜刮复用 `Navigate` 与 `Pickup`，按距离和资源 ID 排序，逐批探查可达路径。拾取仍校验所有者、共享资源和背包版本，双方同时竞争时按 World 的固定步执行顺序裁决。此入口处理地面物品，容器及复杂掉落的接入归资源模块。

自动席位的外部输入只接受宿主生命周期指令，包括加入、就绪、重连和离开。移动、拾取等外部玩法输入返回 `UNAUTHORIZED`。公开投影和事件沿用成员身份，背包只在本席位的私有快照中返回。策略表是宿主侧配置。入场、拾取和撤离产生的资产责任仍由既有账本和收据结清。
