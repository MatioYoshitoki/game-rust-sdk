# 世界几何 v1

机制 105、schema 7、协议 6 的 PvE 场景可选 `pve.world_geometry`。顶层 `geometry` 描述格网的外接矩形。可选配置提供该范围内的实际边界及附加阻挡，和已有地形格同时生效。所有对局输入和快照使用权威世界坐标。

| 字段 | 契约 |
|---|---|
| `boundary` | 3～16 个顶点，按数学坐标逆时针排列的严格凸多边形。末点无需重复起点。移动、落点、视线和弹道都受边界约束。 |
| `blockers` | 0～64 个对象。每项提供唯一 `id`、同样规则的 `vertices`，以及三个布尔字段 `blocks_movement`、`blocks_projectiles`、`blocks_vision`，至少启用一项。 |
| `active_window` | 阻挡项可选 `start_ms` 与 `end_ms`，按 World 开局后的毫秒计，包含起点，不包含终点。省略时始终生效。 |

出生、撤离和场景点在初始阻挡状态下通过配置校验。圆形足迹用于阻挡和边界判定，弹道使用同一形状检测最早接触。窗口开始时，如果新阻挡会覆盖成员、NPC 或召唤体的活体足迹，Rust 每个固定步重试，直到腾空或窗口结束。开启和关闭会刷新现有导航路径，移动仍逐步检查实际路径。

启用配置时，协议 6 全量帧的 `active_blockers` 给出实际生效的阻挡 ID。增量中该字段出现时替换整组 ID，空数组表示当前没有生效的阻挡。重连以新的全量帧为准，客户端将 ID 与本次冻结的配置关联。

## 高差、坡道和地形伤害

SDK 0.139.0 起，有 `world_geometry` 的配置可在 `pve.palette` 提供高差和地形伤害。SDK 0.171.0 的等距格网也支持这些字段。两项均未启用时，各格高程一致，爬升、跌落及地形伤害为零，省略 `slope`。

| 地形字段 | 契约 |
|---|---|
| `elevation` | 平地高程，或坡道坐标较小的一边的高程，范围 0～10000。 |
| `slope` | 可选对象，`axis` 为 `x` 或 `y`，`endElevation` 为坐标较大的一边的高程，范围 0～10000。格内沿该轴线性变化。 |
| `maxClimbHeight` / `maxDropHeight` | 离开本格时允许的单次向上/向下高差，范围 0～10000，包含等于阈值。 |
| `dotDamagePerSecond` | 每秒环境伤害，范围 0～10000，最多三位小数。0 表示安全地面。 |

角色中心跨格时在实际接缝取两侧高程。沿平滑坡面行进只消耗平面移动预算。斜穿格角要求两条相邻跨格路线均通过。走路、导航、突进、击退和 NPC 归位都遵守高差，强制位移在首个不可跨接缝前停止。圆形足迹继续约束地块、边界和多边形阻挡。视线和弹道使用各自的阻挡字段，允许跨越高差。合法跌落的效果为位置变化，伤害由当前格独立配置。

世界在周期状态结算后、主动移动前，按成员、NPC、召唤体的顺序采样当前格并推进一个固定步。只有可受伤实体累计暴露，保护、免伤、归途和采样到安全格时清除余数。扣除减伤后保留不足 1 HP 的余量，足量时先由护盾吸收，再结算致死保护和实际扣血。扣血可打断撤离。地形伤害无攻击者，不产生攻击归属、战斗事实、战斗窗口记录、击杀奖励或掉落。记录盾仍按自己的规则累计承伤或吸收量。

协议 6 的 `event_v4` 发布 `terrain_damage`，字段为地形 ID `terrain`、目标实体 `target`、实际扣血 `amount`、盾吸收 `absorbed` 和当次扣血后的 `hp`。护盾吸收事件的来源标签为 `terrain:<id>`。地形触发致死保护时发私有 `terrain_death_guard_activated`。重连从全量帧读取 HP 与位置，暴露余数仅留在运行中的 World。

## 权威等距格网

SDK 0.171.0 起，`pve.isometric_grid` 可声明 `tile_height` 和 `origin`。`pve.cell_size` 表示菱形地块的完整宽度，`tile_height` 表示完整高度，两者范围 4～128。`origin` 是第一个地块的顶点。`width`、`height` 和 `cells_rle` 沿原行优先格索引。省略时沿用正交格网。

格坐标 `(u,v)` 映射为 `x = origin.x + (u-v) × cell_size / 2`、`y = origin.y + (u+v) × tile_height / 2`。顶层 `geometry.min/max` 使用投影后四角的外接矩形，`walls` 留空。格网自身会限制菱形边界；`world_geometry` 可以进一步约束边界和加入世界坐标多边形。坐标可为负，半径、速度和距离继续以世界单位计。坡道轴指格坐标的 `u` 或 `v` 方向。

寻路使用等距地块中心，移动、视线、弹道和落点使用同一格网与世界边界。等距格网的碰撞在世界坐标中检测圆形足迹与实际菱形地块。空间查找保持原地形索引及三个独立阻挡通道。Rust 与 Node JSONL 宿主可直接使用该配置。协议 6 双席参考页按真实世界坐标渲染 `isometric_grid` 地块并沿世界轴映射输入；正交配置继续使用 2:1 显示投影。共享投影模块 `web/isometric.js` 的 `projectionFor`/`toWorld`/`tilePolygon` 可作为接入方浏览器渲染的参考实现。
