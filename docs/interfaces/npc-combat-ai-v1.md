# 怪物战斗 AI v1

SDK 0.140.0 起，机制 105、schema 7、协议 6 的多人场景可在 `pve.npc_ai` 启用怪物战斗 AI。怪物模板、出生点、技能和数值由宿主提供。

| 字段 | 契约 |
|---|---|
| `switch_threat_bps` | 已持有仇恨目标时，新目标的仇恨至少达到原目标乘以此比例才切换。范围 10000～100000。相同仇恨保留原目标，初选同分按实体 ID 排序。 |
| `groups` | 可选的出生实体 ID 到群组 ID 映射。默认模板的出生实体按 `template_id` 加从 1 开始的序号标识。双方有群组时必须相同，双方均无群组时按距离协同。 |
| `forced_target_statuses` | 可选，最多 8 个按来源分组的非周期有害状态 ID。对怪物生效的状态以实际施加者作为强制目标。多个合法来源取最新施加时间，同刻按来源 ID。 |
| `profiles` | 可选，按怪物模板 ID 配置 `slots` 和 `retreat_below`。省略模板配置时沿用模板原有的攻击技能选择。 |

怪物独立累计每个实际伤害来源造成的 HP 损失。强制目标优先，其次为仇恨、记忆目标、同群呼救和自然发现。强制目标、仇恨与呼救都可超出自然警戒半径，仍受目标记忆范围约束。自然发现要求视线可达。同群呼救读取上一步可用目标，受接收者 `help_range` 约束，单纯响应呼救的怪物无需转发。目标退场、进入保护或丢失实体代次时清理仇恨和锁定的未提交攻击。

怪物超出出生点的 `leash` 时拒绝攻击。归位途中回到牵引范围，敌方实际扣血可中断归位并累计仇恨。完成归位时恢复基础 HP 和灵力，清除仇恨和技能时钟并更新实体代次。归位和远程拉开距离沿用地形和阻挡判定。可选的 `retreat_below` 小于模板的 `melee_range`，进入该距离后优先尝试拉开到 `melee_range`，受地形与牵引范围限制。

## 技能槽

`slots` 按顺序提供最多 8 个槽。每次尝试依次检查冷却、目标、费用、容量与 `chance`，首个满足条件的槽优先于普攻。尝试节奏取 `params.runtime.ai_decision_ms`，每个槽独立记冷却，所有槽共用后摇。准备时锁定实体代次，提交重新检查资格，失败时保留灵力和该槽冷却。

| `kind` | 契约 |
|---|---|
| `projectile` | `chance` 为 0～1。省略 `ability` 时引用模板主弹道，可使用主技能已有的区域交付。`ability` 可定义唯一 ID 的额外普通弹道，复用 `ProjectileAbility` 的费用、射程、时序、伤害及命中规则。额外弹道的状态绑定须省略。 |
| `heal` | `chance`、`range`、`include_self` 由宿主提供。使用模板已有 `combat.heal`，在合法同群目标中选 HP 比例最低者，同分按 ID。模板 `hp_threshold` 仅用于选择。提交时按目标有效最大 HP 和 `heal_bps` 冻结总治疗预算，分到配置的跳数，逐跳检查目标并应用受治疗倍率和生命缺口。 |

协议 6 的全量和增量沿用 `monsters[].target`、`returning` 和 HP。`event_v4` 的 `npc_skill_committed` 提供 `source`、`target`、`skill_id`，`npc_heal_tick` 额外提供本跳实际恢复 `amount` 及 `hp`。重连从全量恢复已发布结果。仇恨表、技能预算和时钟留在运行中的 World。

## Boss 阶段

SDK 0.141.0 允许有 `pve.npc_ai.profiles` 条目的额外怪物模板使用已有的 `boss.phases`。阶段数为 1～8，首阶段阈值为 10000 bps，其余严格降序。生命值除以当前有效最大 HP 达到阈值时进入相应阶段，一次跨过多个阈值会按顺序逐一发布。治疗保留已经到达的阶段。完成归位时恢复首阶段，并更新实体代次和冷却状态。

AI 模板可用 `phase_slots` 按阶段 ID 给出 `slots` 的零基索引顺序，单阶段内索引唯一。缺省时使用完整基础顺序，空列表表示该阶段仅执行普攻及移动。新技能决策的概率为阶段 `cast_chance` 乘槽位 `chance`，新普攻间隔取阶段 `attack_interval_ms`。已锁定的准备和引导继续使用原槽位。各阶段引用同一索引时共享冷却。

协议 6 在 Boss 的 `monsters[].boss_phase` 中发布阶段 ID、名称、索引、阶段总数、普攻间隔和概率，`epoch` 对应实体代次。`boss_phase_changed` 附带 `from_index`，`boss_reset` 附带归位后的实体和阶段。全量与增量读取相同字段，解码器按实体代次检查阶段单调性。
