# 成员施法锚点

本批归 R3.4。可信配置将地面圆形技能绑定为布置技能，并声明可使用该锚点的普通弹道或圆形区域技能。用通用样例验收固定世界点和动作归属。

| 验收项 | 预期 |
|---|---|
| 布置 | 复用 `cast_ground` 的落点、费用与冷却。提交生成定时锚点，位置固定。每名成员的同一布置技能最多留一个锚点，再次布置替换旧 ID 并复用区域槽。 |
| 使用 | `cast_at_anchor` 显式提交技能和锚点 ID。接受及提交重验己方原实体、技能绑定、未到期、配置距离、视线和合法落点。弹道额外校验发射足迹及方向。提交前失效保留费用和冷却。 |
| 物化 | 区域以锚点为圆心，弹道从锚点发射。原成员依旧负责资源、伤害与收益归属。动作提交后位置冻结，后续替换或到期不改变已释放动作。技能的普通施法入口继续可用。 |
| 发布与回收 | 协议 6 发布锚点 ID、所有者、位置和期限。重连恢复同一有效锚点。到期、替换、来源死亡或退场及关局均回收。过期 ID 和其他成员的锚点无法用于施法。 |

锚点可重复使用至到期。样例选择普通弹道和圆形区域。启用迁移时见[锚点再施放](SDK-5-88-member-anchor-recast.md)。
