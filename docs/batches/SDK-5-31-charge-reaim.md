# SDK-5-31 蓄力期间重瞄准

对应 R3.1/M02 及原施法生命周期接口 §4.2。起点 SDK 0.32.0，目标 SDK 0.33.0、协议 6、schema 7、机制 48。范围是同 World 1～8 成员 PVE 的普通和穿透方向弹道蓄力。

在 `charge` 下加入可选的 `aim_update` 对象，两个必填整数为 `min_interval_ms` 和 `max_turn_deg_per_sec`。间隔至少 50 ms，且至少为自动提交前留出一个固定步。角速度为 1～720 度每秒。字段省略时按下锁向。机制 48 支持显式配置，旧机制或非法对象在启动加载时拒绝。

客户端通过 `update_charge_aim` 提交本人蓄力 ID 和方向，沿原成员、连接、序列、准备状态门禁。Rust 归一化有限非零方向。以开始时间或最近一次有效改向时间为基准，达到配置间隔后可以改向。最短夹角不得超过实际逻辑时间乘角速度预算，限额等号通过。相同归一化方向在角度容差内幂等成功，方向和时间基准保持原值。超频返回 `INVALID_STATE`，超角返回 `OUT_OF_RANGE`，保持最近有效方向。更新只改变准备中的方向和最近改向时间。

手动 `release_charge` 可携带可选最终方向，适用相同方向门禁。合法时在一次输入内冻结方向和实际持有时长。提前释放沿原取消语义处理，方向参数须合法且技能可编辑。省略方向时使用最近有效方向。自动提交使用截止前最近有效方向。已释放待提交、截止、取消、退场及重连后的迟到更新沿原事务拒绝。提交仍按实际起点重验和扣费。

可编辑动作的本人准备快照带方向和最近改向时间，提交事件带实际冻结方向。H5 用原地图点选和显式更新按钮提交意图，并显示权威方向。范围覆盖准备期间的方向更新及释放收尾。

| ID | 验收 |
|---|---|
| RA01 | 主槽、附加槽的配置门禁，20 Hz 与 720 度每秒上限，机制 47 锁向配置和原输入兼容。 |
| RA02 | 归一化、重复方向去重、间隔和夹角等号、超频及超角原子拒绝。 |
| RA03 | 手动释放使用有效最终方向，自动提交使用最近有效方向。普通和穿透弹道使用实际位置、冻结威力和一次费用。 |
| RA04 | 准备方向仅本人可见，坏帧原子拒绝，重复输入、串成员、取消及重连后的旧 ID 隔离。 |
| RA05 | 包外普通宿主和真实 4/8 页 H5 完成显式更新、手动或自动提交、同伴继续和独立结算。 |
| RA06 | 同候选全量 Rust/Node、Clippy、格式、离线源码和机制 47 包外回归。 |
