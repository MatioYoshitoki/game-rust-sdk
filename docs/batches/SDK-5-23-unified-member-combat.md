# SDK-5-23 统一多人战斗入口与指定单位弹道

2026-11-05；实现前冻结UC01～UC12。起点0.24.0/协议6/schema7/机制39；目标0.25.0/协议6/schema7/机制40。SDK-5-22后多人PVE已可战斗，本批补统一内部战斗入口和既有unit_projectile的多人适配。固定1～8必需成员；不以本批关闭完整R2/R3或M01/M02/M03/M04/M14。

## 统一边界

同一World内以kind/id/generation解析实际实体，统一实体存活、可受击资格、基础属性、来源归属和目标关系。关系为self/friendly/hostile：当前PVE成员之间、NPC之间为友方，跨类为敌方；此为当前PVE模式策略，不声明任意阵营配置或PvP开放。攻击仅敌对目标，自身HOT仅self；盾/状态仍遵守既有绑定和关系限制。关系判断集中一次，后续机制复用，不以技能ID、地图ID或连接代次判断敌我。

成员→NPC、NPC→成员的直接伤害及DOT共用一个伤害结算入口，统一当前DEF→既有取整/minimum_damage→盾→HP，再由目标存储适配触发撤离中断、死亡、归功与一次掉落。HOT共用实体基础maxHp/当前HP的回复入口；状态共用实际来源/目标解析、基础maxHp与清理/权限流程。直接命中的随机、倍率、附带与回灵仍位于直接接触层，DOT不重触发。旧1～39公开语义和数值保持。保留旧单成员协议适配，不声称本批重写所有历史单人运行时。

## 指定单位弹道

机制40在schema7/协议6开放既有unit_projectile与cast_unit{skill_id,target:{id,generation}}。本批目标限当前World已发布的存活敌对NPC；输入身份转换为完整EntityRef并冻结，不能转绑到同ID新代。接受和提交均校验目标存活/非归途、关系、来源资格、中心射程与视线；目标移动时提交按当前合法位置冻结方向。准备期失效/出射程/断视线/换代以原ActionRejected拒绝，不扣费/CD、不授予自身状态、不创建弹道。取消/保护/退出中断沿原规则。

提交后按原成本/CD/冻结有效ATK、飞行速度/半径/距离/TTL及配置状态绑定执行。方向不追踪，不换人、不补扣或退款；目标死亡/进入归途/换代则结束在途计划。来源退出/死亡/真实复位失效；同World重连保留已提交计划，保护中断未提交准备。墙与单位同时接触墙优先；其它合格敌对单位先挡住时只消耗弹道，不造成伤害、附带、随机或回灵。命中指定目标共用上述直接伤害与状态/盾/DOT链。零HP损失仍为成功合法接触。

Pending与内部计划保存完整EntityRef。本人pending_action及私有ActionCommitted复用unit_target；公共ProjectileViewV4新增可省略unit_target，仅指定单位计划输出，存在必须为非null的{id,generation}。普通/NPC/旧机制弹道省略，不增加成员私有字段。Rust投影再diff，Rust/JS解码校验ID/代次/来源/目标及原子基线。六类Client、协议和金融/恢复DTO不变；重启只Closed金融责任，不热恢复战斗计划。

全部战斗数值、绑定、重复策略、出生点及工程预算通过配置初始化。参考Node/H5只发送发布的NPC身份与输入意图，不能裁决敌我、命中、伤害或资产；两套外部配置验证四人/八人。旧机制拒绝新配置/输入；非法配置在I/O前拒绝。
