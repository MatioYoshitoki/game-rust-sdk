# B3-14 湿地完成后削弱圣所支援治疗

2026-11-04。W01～W05 受控验收通过。

玩家可先完成湿地，也可从遗迹进入圣所。Rust 根据本局指定遭遇是否已完成，为每次新开始的支援治疗选择版本。配置定义触发节点、技能身份、名称和治疗量。来源普通渡生按目标最大生命的 12% 计算总治疗预算，衰弱渡生按 6% 计算。两者共用现有目标选择、次数、灵力、冷却和打断规则。

支援动作开始时锁定治疗版本、预算和目标。触发节点在读条或引导中完成时，从下一次动作开始生效。受保护、断线、回防和整组复位仍按现有规则取消动作。湿地只击败部分目标、等待后续波次或发生复位时，仍使用普通版。完成后的湿地状态在本局保留，圣所复位后再次施放时仍选削弱版。切换本身不补回次数、灵力或冷却。

schema 2 的机制版本 13 增加可选 `support.on_encounter_completed`，字段为 `encounter_id`、`id`、`name`、`heal_bps`。加载校验引用、字段类型、技能身份冲突以及治疗量范围。原 `SupportView.skill_id` 和 `name` 显示当前动作的版本，空闲时显示下一次可选版本。

B3-14 场景以遗迹和圣所作为调谐所需目标。遗迹敌人的首次奖励增加保底火灵石，数量取自调谐成本，两条路线都能取得足量材料。H5 提供前往主线遭遇的导航，使用现有公开输入。终局继续冻结实际完成节点、击杀和资产，重启按原责任履行。

| 编号 | 验收标准 |
|---|---|
| W01 | 来源包和历史场景配置校验通过。新配置拒绝旧能力、无效遭遇引用、非法治疗量、缺失或未知字段、技能身份冲突。替换配置的节点、名称和治疗量后，Rust 按新值判定。 |
| W02 | 通过公开操作跑通直达主线和先打湿地两条路线。按实际治疗事件验证普通和削弱的治疗量，完成调谐、解封、开箱、拾取和撤离。 |
| W03 | 湿地部分击杀并脱战复位时，圣所仍使用普通治疗。湿地完成后，圣所部分战斗脱战复位，重新进场仍使用削弱治疗且首杀收益不重复。 |

| W05 | H5 显示 Rust 发布的技能名，主线快捷导航和原路径可用。冻结节点、积分、材料和奖箱结果在重启后保持一致，历史支援、目标链与复位闭环回归通过。 |
