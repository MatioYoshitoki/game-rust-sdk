# SDK-5-96 分歧裁定执行

DELIVERY-06 / R6.2。按 [裁定清单](../decisions/SDK-5-95-divergence-arbitration.md) 的建议方向执行八处分歧：五处保持现状回写文档（1A/2A/3A/4A/7A），三处机制改动（5A/6B/8B）。

| 验收 | 可判定结果 |
|---|---|
| 5A 控制打断事件 | 准备期被控制打断时，施法者收到面向本人的 `ActionInterrupted` 事件恰 1 次；S10 的分歧断言翻转为与源 oracle 一致（1 次）。 |
| 6B 弹道来源存续可配 | 技能新增 `end_on_source_invalid`（默认 false=随源清理，现状不变）；开启时成员退场后其弹道冻结载荷继续飞行命中；S13 在开启配置下与源 oracle 一致（B 900），默认配置行为不变。 |
| 8B 判负即时裁决 | 对抗阶段判负到期即刻裁决胜负（败者 Loss、对手 Win），不再等阶段时钟；S34 的 B 结果为 Win 且结论恰 1 次。 |
| 文档回写 | 尾跳取整（1A）、pvp 分摊（2A）、激活时刻（3A）、中止相位（4A）、unknown 顺序（7A）在裁定清单与相关接口文档标注为既定口径；账本对应分歧条目结案。 |

机制改动的既有测试全部保持通过（默认行为不变约束）；分歧场景测试从「登记内核值」翻转为「与源一致」。
