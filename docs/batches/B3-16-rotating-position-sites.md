# B3-16 固定点位轮转与陨星荒原闭环

2026-11-04。R01～R05 受控验收通过。[执行记录](../evidence/B3-16-rotating-position-sites-2026-11-04.md)

在 B3-15 的限时站位流程中增加固定站位轮转判定。地图配置给出有序点位、世界坐标、站位半径、预警和伤害参数。每次预警开始时锁定当轮点位、截止时间、成功伤害和反噬伤害。点位按配置顺序循环。

到期读取角色实际位置，进入当轮圈内或处于边界算成功。伤害打向距离当轮点位中心最近的存活终局守卫，等距按稳定 ID 排序。站在旧圈、后续圈或其它位置时走反噬结算。移动与当步已有攻击先处理，成功和失败都走既有伤害、死亡、计分和掉落流程。

离开终局范围、保护、核心死亡、终局结束会清理当前预警。同轮取消后的下次预警轮转到下一点。整组脱战复位后，从首个点位重新开始，已完成的侧路继续生效。

陨星荒原使用来源地图的通行、阻挡、速度和承星参数，采用适合单人验证的敌群与出生位置。来源熔岩持续伤害在本验证场景取零。三处承星位沿用来源名称和顺序，在可达的终局空地布置。北陨脊完成后，后续预警由 3.2 秒延长到 4.7 秒。东残片场完成后，后续反噬乘以 55%。H5 显示当前圈、名称与剩余时间，靠近按钮提交原导航输入。

| 编号 | 验收标准 |
|---|---|
| R01 | 配置声明固定轮转类型。拒绝旧能力版本、重复或空点位、非法半径、越出终局或不可达的点位。雷云谷旧配置按原哈希加载。 |
| R02 | 三个点位按序轮转并回到第一个点。验证实际站位、圆边界、站错圈失败、从点位中心选目标、死亡目标跳过和一次结算。 |
| R03 | 分别验证北陨脊的预警加时和东残片场的反噬削弱。预警中完成侧路时，当前参数保持，下次预警采用新值。 |
| R04 | 退出、保护、核心死亡和关闭清理预警。实际脱战复位后从首点开始，原侧路效果保留。 |
| R05 | 浏览器验证直达和完成两条侧路，分别观察承星成功与反噬并完成击败守卫、调谐、开箱、拾取、撤离和重启核对。雷云谷两条导雷路线回归通过。 |

本批验收单人承星闭环。三处点位、侧路、目标与数值均由配置描述。
