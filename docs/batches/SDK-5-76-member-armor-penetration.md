# SDK-5-76 自身技能破甲

对应 R3.3/M04 和原行为规格 §4.1、§4.2。目标 SDK 0.78.0、机制 93、schema 7、协议 6。自身技能通过 `self_status.on_commit_self_statuses` 提供 `timed_attribute_modifier / armor_penetration`。配置时长和正向 `modifier_bps`（1～10000），同源刷新。

成员对敌方 NPC 的直接伤害在命中结算时读取施加者当前破甲。有效实例相加，以 `有效 DEF × max(0, 1 − 破甲 bps / 10000)` 得到本次参与减伤的护甲，保留小数直至原伤害公式取整。护盾继续在 DEF 结算后吸收。破甲属于攻击方增益，目标 DEF 和其他成员的攻击保持各自状态。NPC 伤害、DOT、抗性及其它伤害路径沿用各自规则。

客户端使用目标私有的自身增益状态和现有伤害事实。范围为当前多人 PvE 的成员直接伤害 DEF 路径，原专属武器、功法、装备和完整抗性公式按各自规格接入。

| ID | 验收 |
|---|---|
| AP01 | 机制 93 接受合法自身技能破甲，拒绝旧机制、越界、非法重复策略、道具和其他绑定。 |
| AP02 | 验证原 `defense-basic` 与 `defense-pierce` 两组直接伤害向量，以及小数护甲、有效 DEF 和护盾顺序。 |
| AP03 | 验证命中读取、叠加后护甲归零、同源刷新、精确到期、目标私有及其他伤害来源保持原行为。 |
| AP04 | Node 和 H5 四人、八人房验证同一攻击者的三次真实弹道普攻，实际伤害分别为 66 → 80 → 66 与 66 → 72 → 66。每位成员结算一次。 |
| AP05 | 同一交付包通过仓库外空缓存离线接入、机制 92 冷却缩减兼容复验及 Rust 和 Node 回归。 |
