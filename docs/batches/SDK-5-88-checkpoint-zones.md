# 定时区域检查点

本批实现 R3.4 的定时世界锚点，并为 R5.3 的风眼阶段提供检查点计数。宿主在开局配置中声明区域位置、开启节奏、持续时长和目标次数。Rust 计算窗口与成员进度。

| 验收项 | 预期 |
|---|---|
| 配置与时间 | 一局最多 4 组计划，每组最多 32 个依次使用的中心点。时间相对于 World 激活时刻。窗口开端计入，截止时刻排除。校验标识、有限坐标、可站立中心、非重叠时序、次数及绝对终局边界。 |
| 权威到达 | 在固定步末读取成员当前位置。已准备且存活的成员位于圈内，且到中心的直线路径未被地图移动障碍截断，即计入本次。窗口开启时已在圈内也计入。连续停留、重复进入和重连均只计该窗口一次。 |
| 席位独立 | 多名成员可分别获得同一个窗口的进度。保护、退场和死亡期间不计入。退场快照保留本人的最终进度，清空活动区域。另一名成员继续参加当前 World。 |
| 发布与恢复 | 协议 6 公共快照发布活动窗口、位置和时限，私有快照发布本人的已获得次数、目标及最近窗口。进度事件仅发给获得者。增量可清除已结束窗口，重连读取同一 World 的状态和时钟。 |
| 风眼样例 | 三个窗口分别从激活后 8、16、24 秒开启，每个持续 3 秒，半径 150，目标为 3。样例围绕配置中心取半径 250 的三个点，实际中心由宿主预计算后提供。 |

本批采用窗口内固定步占位判定，跨越整个圆且步末在圈外时无进度。圈外风压、四劫阶段判定与奖励归 R5.3。
