# SDK-5-53 即时用药的受治疗倍率

对应 R3.3/M04。目标 SDK 0.55.0、机制 70、schema 7、协议 6。多人 PvE 恢复道具可在 `member_item_use` 的气血或双恢复条目设置 `apply_healing_received: true`，让即时气血恢复应用已有的 `healing_received`。省略或设置为 `false` 使用原公式。机制 69 及更早版本拒绝此字段，纯灵力条目也拒绝此字段。

用药时，先按固定量或最大气血比例计算，并应用道具品质倍率，向下取整得到基础恢复量。再乘执行时仍有效的受治疗倍率，向下取整，最后按当前气血缺口截断。受治疗倍率与自身 HOT 共用同一状态计算，截止时起失效。本次用药附带的状态在本次回复和扣除道具之后施加。灵力继续按该条目的恢复和品质配置计算。

气血和灵力实际回复均为零时，拒绝本次用药，库存、修订、冷却和状态都不产生写入。任一有实际回复时复用原子用药流程。已有 `item_used` 事件发布实际气血和灵力回复，沿用本人权限。队友的治疗、NPC 治疗和自然恢复留待各自验收。

| ID | 验收 |
|---|---|
| IH01 | 机制 70 支持固定量、比例和双恢复条目的布尔开关。旧机制、纯灵力条目以及非布尔值拒绝该字段。省略和显式关闭沿用旧公式。 |
| IH02 | 验证品质取整先于受治疗倍率、最终才裁剪缺口，覆盖正负倍率、到期边界和大数。 |
| IH03 | 零实际恢复时不扣道具、不增修订、不启动冷却、不应用附带状态。双恢复仍可凭实际灵力回复成功一次。 |
| IH04 | 本次附带状态只影响后续用药。回复事件、道具扣除与结算按成员隔离。 |
| IH05 | Node 和 H5 的四人及八人房，走通受伤、拾取、建立倍率、用药、到期再用和退出。基础量 53，四人房 +50% 实回 79，八人房 −50% 实回 26，到期后均实回 53。 |
| IH06 | 同一发布包通过离线接入、机制 69 的 HOT 兼容回归及 Rust、Node 回归。 |
