# SDK-5-44 恢复道具共享冷却

对应 R3.1/M02。目标 SDK 0.46.0，协议 6，schema 7，机制 61。同一 PVE World 的 1～8 名成员可为生命与灵力恢复道具配置共享冷却。

`member_item_use` 条目可在机制 61 配置 `cooldown_group`。组 ID 非空、最多 64 个 UTF-8 字节且无控制字符。同组每个条目都须配置相同的 `cooldown_ms`，时长遵循机制 59 的规则。省略组 ID 的条目沿用自身冷却。

成功使用一种道具后，服务器将同组条目的截止时间设为同一个逻辑时刻。冷却属于使用者，转移不改变任何成员的冷却状态。冷却中返回 `INVALID_STATE`，生命、灵力、库存修订和截止时间保持原值。到期后允许重新校验并使用。本人快照沿用 `item_cooldowns`，逐条展示同组受限道具，包括当前背包中没有的条目。

同局重连保留截止时间，提前离场清除冷却。结算沿用净拾取份额，按实际消耗扣减。最小闭环覆盖四人房先使用生命道具、同组灵力道具受限、到期后使用，以及八人房转交后由队友独立使用。

| ID | 验收 |
|---|---|
| CG01 | 配置门禁、组 ID、同组时长约束与机制 60 兼容。 |
| CG02 | 成功使用才启动共享冷却，组内其他道具受限，组外保持独立，到期可用。 |
| CG03 | 拒绝时库存和恢复属性保持原值，重复请求幂等。 |
| CG04 | 本人快照、转移、重连、离场和剩余份额结算。 |
| CG05 | 普通 Node 和 H5 验证四人同组到期使用及八人转交后独立使用。 |
| CG06 | Rust、Node 回归和同候选离线交付，验证机制 60 兼容。 |
