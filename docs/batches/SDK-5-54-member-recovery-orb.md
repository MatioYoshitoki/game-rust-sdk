# SDK-5-54 多人回复光球的模板倍率

对应 R3.3/M04，覆盖原需求 §4.3 中普通及高档回复光球的数值差异。目标 SDK 0.56.0、机制 71、schema 7、协议 6。在多人 PvE 的 `pve.additional_templates` 中，启用 `drop_orb` 的怪物模板可设置 `recovery_orb`，其中 `hp_bps` 和 `spirit_bps` 为 0～10000 的整数，至少一项大于零。省略该对象时使用现有对局全局比例。

击杀时分别以击杀成员的最大气血和最大灵力乘对应比例，向下取整后冻结为光球的绝对恢复量。光球沿用现有的击杀归属和资源过期时间。拾取时分别按当前缺口裁剪，满值也可消费光球。拾取只改变自身气血、灵力及资源修订，不计入背包物品或结算资产。倍率、模板名和档位由配置定义。

| ID | 验收 |
|---|---|
| RO01 | 机制 71 可加载模板倍率。旧机制、非整数、缺项、全零、越界、显式 null 和关闭掉球的配置拒绝。 |
| RO02 | Rust 验证击杀时按击杀者上限冻结，拾取时按当前缺口裁剪，覆盖满值消费和向下取整。 |
| RO03 | 同一 World 内拒绝他人拾取、过期、修订冲突和重复拾取。光球不改变背包、净拾取量或资产奖励。 |
| RO04 | 四人和八人房使用同一发布包，Node 和 H5 走通施法消耗、击杀、归属、拾取、实际恢复与退出结算。1000 气血、200 灵力上限下，两房分别回复 30/30 和 150/120。 |
| RO05 | 机制 70 兼容复验覆盖旧全局光球比例和即时用药，核对同一候选的离线接入、Rust 及 Node 回归。 |
