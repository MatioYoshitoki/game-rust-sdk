# SDK-5-14 方向型直线穿透弹道最小闭环

2026-11-05；先冻结需求/验收，再实现。目标crate0.17.0、机制32，schema4/协议3单人PVE，仍最多两个玩家技能。复用通用ContactBudget身份历史/总预算，首次接入方向型直线弹道。

## 配置与提交

新增玩家mechanism=piercing_projectile，主副槽均可。严格必填原projectile的id/cost/windup_ms/recovery_ms/cooldown_ms/damage_bps/range/speed/radius，新增ttl_ms、max_hits；可选已有合法self/hit状态绑定。仅≥32/schema4/PVE；射程/弹速0.1～10000、半径0～128、伤害/成本/时长/唯一ID/引用沿原两槽边界。ttl_ms为2×step_ms～60000，max_hits为1～128整数。禁止ground参数、target、contact_policy及未注册字段/null；本批仅每身份一次，不提供正重复间隔或每步扫描配额，避免无效参数。

复用Cast{skill_id,direction}及原准备/ready/保护/资源/独立CD/共享后摇；有限非零方向在接受时归一化冻结，技能/TTL/预算/轮次/绑定一起冻结。提交取施法者当前位置为起点；不瞄准单位、不追踪/换方向。当前灵力、整组self容量和最多2个在途玩家穿透弹道的容量在提交时原子预检，失败发ActionRejected、不扣费/开CD/施加状态/建弹。容量只限制新穿透，不误拦普攻/自身/原弹道/地面计划。成功施加self状态后冻结有效ATK比例量，扣自己成本一次、开启自己的CD和共享后摇，创建穿透计划；0前摇仍下一固定步提交，创建同一步不移动。

## 连续接触与预算

每固定步从上步位置沿冻结方向移动min(speed×step_ms/1000,remaining_range)，用现有segment_circle扫掠（弹半径+目标当前半径），不能只看终点而漏掉高速穿过的敌人。当前存活/启用、非归途/非复位倒计时、原遭遇轮次为候选；按路径归一化首次接触进度t、稳定目标ID字节序、代次（最后索引兜底）排序。同一步每身份最多尝试一次，进入接触前重验资格/身份/轮次；首个弹道阻挡墙体截断，墙与单位同t时墙优先，墙后无伤害/状态，不穿墙。

通过原直接命中链才记录成功接触：共享ContactBudget按当前World的{id,generation}存储，每身份每发弹终生一次、最多max_hits次总成功接触；历史≤128。闪避/失效/阻挡不消耗预算、不写成功历史，继续前方候选；若以后仍重叠，可在下一步再次尝试尚未成功的身份。0HP损失/全盾吸收仍算成功接触并沿原合法hit状态；附带状态/阶段/反击/DOT不重复扣预算。击杀只消费一次且不重复掉落；新代是新身份，不绑定旧历史。多个弹道独立历史/预算。直接攻击量冻结、每次当前DEF/盾/闪避、原伤害/状态/击杀/掉落/遭遇保持。

预算耗尽立即停在该接触点并结束，不再伤后面的目标。否则整段有效接触后，若有墙停在墙接触点并以wall结束；无墙则移至本步终点、扣实际行程预算，remaining_range=0以range_exhausted结束。TTL截止点排除：now≥expires_at_ms时在移动/接触前以expired结束。最后合法接触恰在射程端点时仍处理接触，若预算归零以hit_budget_exhausted优先；墙体同距始终优先。每发弹只结束一次，不退款/回滚CD或已发生效果。

## 生命周期和输出

未提交CancelAction/后台/死亡/终局/关闭/实际换轮沿原准备策略免扣；移动保持准备。提交后移动/取消输入/后台/同World重连保留飞行方向/位置/行程/期限/历史/预算及CD/后摇；来源固定当前participant，死亡/终局/关闭/任何实际遭遇换轮结束所有剩余穿透弹，不跨新轮伤害或掉落。旧严格单位弹道的目标失效/非目标阻挡和原首接触弹道/NPC/区域行为保持。

机制32 PveView增加可省略piercing_projectiles：action_id/skill_id/position/direction/radius/speed/remaining_range/expires_at_ms/max_hits/used_hits/remaining_hits及contacts（稳定ID/代次排序，target、hit_at_ms）。新增PiercingStarted{projectile}、PiercingHit{action_id,skill_id,target,position,remaining_hits}、PiercingEnded{action_ids,reason}。结束原因hit_budget_exhausted/wall/range_exhausted/expired/owner_died/terminal/closed/encounter_reset。外部取消有界聚合，关闭预算多计一条在途穿透结束事件；旧1～31不输出新字段/事件。公开DTO/枚举源码消费需适配，Client六类/协议1～3/资产/恢复schema保持。

H5显式点选/触摸地图设置方向，显示Rust发布的弹道/余量/历史；未设置方向禁用新技能，准备中改瞄准点不改已接受方向。Node仅提交方向意图，不算碰撞/伤害/预算。两套包外配置改变ID/主副位置/速度/伤害/成本/TTL/预算/绑定，A预算2穿透前两敌、第三不误伤，B预算3命中三敌；验证真实命中/状态/回复→三敌击杀/拾取→撤离/死亡。纯触屏双终局、资源/容量/非法意图拒绝、重连/强杀和旧19～31保持。

同World重连保留已成功身份/预算，不重复建弹/扣成本/接触；旧连接拒绝，重复输入原操作只执行一次，若接受后的精确重复请求与换代交错，仅允许旧连接STALE_CONNECTION且不得换代重发已接受操作。进程重启仅履行原Create/hash/金额/operation ID责任，不恢复弹道/历史/预算/临时战斗或按新配置重算旧金额。
