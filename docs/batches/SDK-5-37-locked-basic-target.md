# SDK-5-37 普攻锁定敌方单位

对应 R3.1/M02 及原需求的手动指定普攻目标。目标 SDK 0.39.0，协议 6，schema 7，机制 54。范围为同 World 1～8 成员 PVE 的现有普通弹道普攻。

新增有限意图 `attack_unit`，只接收已发布敌方 NPC 的 `target.id` 和 `target.generation`。机制 54 开放，旧机制继续使用 `attack`。现有配置决定射程、前摇、弹道和冷却。受理、排队释放和实际提交都重验同一目标的代次、敌对、存活、非回归、射程与视线。目标无效或超距时拒绝，不移动追击或自动改选。

可立即执行时进入原普攻准备。开启 SDK-5-36 的 `basic_followup` 后，冷却内可通过 `attack_unit` 替换同一待执行槽。两类普攻输入共享该槽。拒绝和重传保留最新有效选择。准备不设新冷却，成功提交才发射并启动冷却。方向取提交时的权威位置。飞行沿原普通弹道的扫掠和首个合法接触规则。

本人 `pending_action.unit_target` 在当前仍存在的锁定代次上给出准备目标，已消失的代次可省略，提交失败仍由权威事件报告。本人成功提交事实的 `unit_target` 给出所用目标身份。公共弹道沿原形态发布。取消、失联、重连、终局以及技能接管按现有准备和队列规则清理。自动追击、移动追踪弹道和玩家目标分别验收。

| ID | 验收 |
|---|---|
