# SDK-5-9 自身施法最小闭环

2026-11-04；**先冻结需求与验收，现已实现并通过受控验收**。目标crate0.12.0、机制27；schema4/协议3、单人PVE、最多两个玩家技能。

## 配置与输入

- 保留skill主槽、可选一个additional_skills及旧projectile字段/规范化形状。主槽和附加槽均可选择新mechanism=self_status，或者仍用原projectile；不以槽位或示例技能ID决定机制。
- self_status只包含id、cost、windup_ms、recovery_ms、cooldown_ms及非空on_commit_self_statuses（1～2个不同的已登记状态ID）。数值沿原成本0～1000000、时间0～3600000ms、ID不为空/不含控制字符/最多64字节等边界。状态定义/数值/重复策略来自原配置，可使用已有合法self绑定（ATK/DEF/受治疗修正、吸收盾、自身HOT）；不增加状态族。DOT自施加仍禁止。
- 新形状严格拒绝damage_bps/range/speed/radius/on_hit_target_statuses等弹道字段，即使null或空数组也拒绝；未知字段、缺少/空/null/重复/未知绑定、混合机制、非法数字均拒绝。旧projectile的必填字段和严格校验保持；self_status仅机制27/schema4/PVE可用。
- 新意图为`{"kind":"cast_self","skill_id":"..."}`，不接受方向、目标、客户端效果或金额等多余字段。旧Cast继续必须提供合法方向。CastSelf指向弹道技能或Cast指向自身技能在动作可接纳时返回INVALID_MESSAGE；旧机制使用新意图返回UNSUPPORTED；未知技能在动作可接纳时UNSUPPORTED。公共Action增加枚举分支，Rust消费方需适配；六类Client、协议1～3/资产/恢复schema保持。

## 共享施法与效果

接受后冻结所选技能、ID、参数和原遭遇轮次，复用现有单准备动作与每技能独立CD。self_status到提交点原子预检整组状态容量和当前灵力，成功才施加整组状态、扣自己的成本、启动自己的CD与共享后摇；不创建弹道、不造成直接攻击、不获得击杀/拾取/攻击命中收益或消费攻击随机数。零前摇仍通过下一固定步提交，不在RPC接受回执中同步执行效果。

支持配置零成本/CD/后摇；仍受单pending、固定步与原队列/状态/发布预算限制。refresh/ignore/stack沿各合法状态定义；ignore是成功施法，保持原实例但正常消费成本/CD，不把它误认作失败退款。整组满槽拒绝不能部分刷新/授予、扣费或开CD。

准备中/共享后摇内不可施放其它技能或普攻，移动/导航/取消/前后台/重连不缩短已提交后摇；未提交取消、后台、死亡、终局、关闭或遭遇实际换轮不扣成本或开CD。取消复位倒计时不取消同轮准备。提交后取消不退款、不撤销已施加状态/在途弹道。两类技能在途/状态实例互不因下一次选择改变。

Snapshot和ActionCommitted沿用机制26的player_skills/pending_action、主技能CD别名和skill_id；无需新客户端派生状态。重连保留同World已提交CD/后摇/状态身份，准备取消沿原连接策略。进程重启只履行原冻结资产责任，不重建临时技能/状态/World，不按新数值重算原Create/hash/结果/金额。

## 消费与范围

Node/H5根据配置mechanism选择Cast或CastSelf，按钮明确自身施法/效果，点击自身技能不依赖鼠标瞄准或附近敌人。金额、伤害、CD、状态由Rust裁决。一个弹道技能＋一个自身技能，以护盾/HOT等现有状态验证；另一包外配置交换主副槽位并改ID/参数/绑定。示例数据属于接入配置，不增加地图专用分支。

本批不包括严格单位/地面目标、任意技能数量、引导/蓄力/再施放、多技能AI、新状态族、HP成本、多人或完整技能目录；D-03/D-05和生产门禁保持。
