# SDK-5-33 方向弹道单次再施放

对应 R3.1/M02 及原资料中同动作再施放的 `redirect` 行为。目标 SDK 0.35.0，协议 6，schema 7，机制 50。范围为同 World 1～8 成员 PVE 的普通方向弹道。

普通方向技能的主槽与附加槽可选 `recast` 对象，完整配置 `window_ms`、`spirit_cost`。窗口至少一个固定步，与 `step_ms` 对齐，至多 30000 ms 且不超过普通玩家弹道的 TTL。灵力费用为 0～1000000 整数。仅机制 50 允许该字段。本批接入固定准备与普通提交，蓄力、引导、穿透或其它形态的组合单独验收。

初次提交沿用原生命、灵力、技能冷却、后摇、状态与弹道事务。每名成员最多保留一个再施放机会。新的可再施放弹道成功提交时替换本人旧机会，旧弹道继续飞行。未提交、提交失败和其它技能不会替换它。窗口从初次提交算起，截止等号拒绝。弹道命中、阻挡、耗尽射程或过期后，机会同步清除。

`recast_projectile` 提交初次动作的 `action_id`、`recast_index: 1` 和新方向。Rust 在当前成员与连接身份下校验窗口、在途弹道、方向和周期外的独立灵力。成功只扣配置的再施放灵力，在当前弹道位置改变方向，保留原弹道 ID、攻击、剩余射程和绝对 TTL，消费一次机会。成功可在初次后摇内触发。既有请求幂等继续生效；新请求重用已消费动作、越权、过期、非法方向或资源不足均不得重复扣费、重写冷却、重施自身状态或生成弹道。资源不足时窗口仍可在到期前重试。

本人协议 6 快照通过 `self.projectile_recast` 发布机会和截止，成功时发布本人 `projectile_recast` 事件及实际费用。取消动作关闭本人机会并保留弹道。后台与重连期间机会按逻辑时间继续，仅当前连接恢复就绪后可消费。死亡和离场清本成员机会及弹道。迁移、回返、多次再施放及链式效果分批验收。

| ID | 验收 |
|---|---|
| RC01 | 两类槽位严格加载，版本、形态、时间、TTL、费用和旧机制兼容。 |
| RC02 | 初次真实弹道、再施放实际折向与命中，原射程、TTL、攻击、冷却、生命费用与效果归属。 |
| RC03 | 窗口等号、命中或阻挡后失效、取消、替换及失败重试。失败不消费机会或扣费，成功只能消费一次。 |
| RC04 | 幂等、成员隔离、重连代次、终局清理、仅本人快照和事件、非法 full/delta 原子拒绝。 |
| RC05 | 普通 Node 与真实 H5 在四人验证再施放，在八人验证过期。对照弹道 ID、费用、同伴与独立结算。 |
| RC06 | 同一候选 Rust/Node 回归、格式/Clippy、离线交付和机制 49 包外回归。 |
