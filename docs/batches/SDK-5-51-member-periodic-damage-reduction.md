# SDK-5-51 周期伤害减伤

对应 R3.3/M04。目标 SDK 0.53.0、机制 68、schema 7、协议 6。同一多人 PvE World 内，NPC 对成员的物理持续伤害每跳复用已有 `damage_reduction`。实际结算顺序为防御、百分比减伤、护盾吸收、剩余生命扣减。已有 50% 合计上限和种子舍入适用。机制 67 的减伤继续只作用于直伤。

每跳沿用执行时的目标资格和属性。在 `executed_at_ms` 检查减伤与护盾，截止时刻起失效。`scheduled_at_ms` 继续标识排程，迟到执行按执行时状态结算。保护、归位或失效导致的跳过沿用既有处理。`periodic_tick` 继续发布实际 `absorbed`、`hp_damage` 和排程、执行时间。

样例由 NPC 实际命中并施加持续伤害，成员拾取后使用配置了减伤和护盾的玄甲丸。两房的无状态周期伤害均为 100。四人房减伤后为 75，首跳由 75 点盾全吸收。八人房减伤后为 68，首跳由 40 点盾吸收，生命扣 28。盾耗尽后的有效期内仍减伤，到期后伤害回到 100。
