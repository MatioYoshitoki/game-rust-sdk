# SDK-5-26 穿透弹道多人适配

2026-11-05；实现前冻结 PP01～PP12。起点0.27.0/协议6/schema7/机制42；目标0.28.0/协议6/schema7/机制43。固定1～8必需成员PVE，沿既有piercing_projectile配置与cast方向输入，将穿透接入同一World弹道容器、敌对接触选择、ContactBudget和直接伤害/附带/死亡归功流程。不新增地图内容或伤害公式，不宣称完整多人战斗/模式完成。

## 最小范围与机制

主副技能均可配置piercing_projectile，字段沿原id/cost/windup_ms/recovery_ms/cooldown_ms/damage_bps/range/speed/radius/ttl_ms/max_hits及self/hit绑定，repeat_interval_ms可省略或为0（每生命身份一次），正数按实际逻辑固定步时刻、上次成功接触+间隔含等号。一次固定步同一身份最多尝试一次，不为跨过的重复期限补命中；再次合格仍必须与该步扫过的路径实际接触。所有数值和绑定由配置初始化，复用旧严格类型/范围/版本校验。

cast方向必须有限非零，由Rust归一化；cast_ground/cast_unit/cast_self不能施放穿透技能。接受/提交均检查来源起点与弹道半径足迹的地图/弹道阻挡资格。提交前起点、灵力、整组self状态或共享弹道槽不足，原子无成本/CD/授状态/弹道；准备取消/保护不花费。提交self绑定后冻结有效ATK、当前位置和接受方向，付费/CD一次；之后移动/后台/同World重连不改变已发弹道的速度、方向、余程、预算、历史或绝对截止。

普通/单位/NPC/穿透弹道共用members.projectile_capacity（1～64）；区域不占弹道槽。机制43额外校验容量×最大穿透max_hits≤128份全World弹道历史预算，以及成员/并发弹道/每步目标上限的输出工程预算，超预算在I/O前拒绝。机制1～42不增加此限制，不修改任何既有JSON。

穿透只走直线、不追踪、不反弹。每固定步从旧位置扫圆到speed×dt与余程的较小距离，复用连续扫圆墙/地图边界；目标接触半径含当前目标足迹，按碰撞进度、稳定ID、代次排序，墙与单位同刻墙优先。一个步内可命中多个合格敌方目标，重复历史不阻挡后面的新目标；友方/死亡/归途跳过，复位新代是新身份。闪避不耗预算/不刷新重复时钟，全盾合法接触仍消耗预算并触发原命中附带。DEF/盾读取当前值，DOT不递归穿透接触，死亡归功和掉落一次。

提交步不移动/伤害；now≥created+ttl先结束，不做截止点接触。总成功预算耗尽、碰墙、余程耗尽、TTL到期、来源失效各仅结束一次，不退款/重置CD。来源settling/死亡/Leave/撤离/断线超时立即清自己的穿透，不等未知金融、不误删同伴。Close/绝对终局清全部穿透；重启仍只金融Closed责任，不热恢复World、弹道、状态或发布基线。

## 发布与兼容

沿ProjectileViewV4及projectiles列表增量，新增可省略非null的piercing对象，含skill_id、方向/速度/余程、created_at_ms/expires_at_ms、max_hits/used_hits/remaining_hits、repeat_interval_ms（省略配置归一成0）和contacts。每项历史含target{id,generation}、hit_at_ms、next_eligible_at_ms（0重复时明确null）。只有穿透输出该对象，不能同时有unit_target；旧普通/单位/NPC弹道省略。Rust字面量补piercing:None。

ProjectileStarted沿原事件；新增公开ProjectileContact包含World弹道ID、实际来源/目标、接触位置/逻辑时间和剩余预算。ProjectileEnded新增可省略reason，仅穿透输出wall/range_exhausted/expired/hit_budget_exhausted/source_invalid；旧事件省略。终局视图沿原冻结契约，既有普通NPC弹道可保留为冻结事实，不表示仍在运行；关闭后的穿透计划必须清空。无私有输入action/request ID、攻击量、状态绑定或成本泄露。Rust/JS严格校验身份/有限几何/单位方向/正速度余程/时间/预算/代次历史/互斥字段；坏帧原子拒绝、缓存不变。full/delta创建、更新、删除及空清沿原列表契约；协议/六类Client/金融/恢复DTO不变。

两套新4席/8席配置，分别验证一次/正间隔重复、不同速度/半径/比例。Node/H5只提交方向、投影Rust位置/预算/历史和观察真实接触，不模拟伤害或命中。新4213预览/4214验收/4215包外只读端口与独立账本，既有预览不动。
