# SDK-5-80 自身技能闪避率

对应 R3.3/M04 和原行为规格 §4.1、§4.2。目标 SDK 0.82.0、机制 97、schema 7、协议 6。自身技能通过 `self_status.on_commit_self_statuses` 提供 `timed_attribute_modifier / dodge_chance`。配置时长和正向 `modifier_bps`（1～5000），同源刷新，有效实例相加后封顶 5000 bps。

NPC 弹道接触或合法近战尝试时，在资格与保护判定后读取被攻击成员的当前闪避率。0% 使用确定结果，其余沿用 Rust 对局随机流。闪避成功结束本次接触，伤害、NPC 近战暴击、护盾消耗和附带状态留给成功命中。近战尝试沿用原攻击间隔。周期伤害、环境伤害及原成员对 NPC 的闪避压制分别沿用现有路径。

客户端观察防守成员的私有增益状态、弹道和既有伤害事实。该切片覆盖自身技能、多人 PvE 的 NPC 弹道与近战，其他闪避投放和通用命中属性交互按各自规格接入。

| ID | 验收 |
|---|---|
| EV01 | 机制 97 接受合法自身技能闪避率，拒绝旧机制、越界、非法重复策略、道具及其他绑定。 |
| EV02 | 验证 NPC 弹道在资格判定后读取闪避、封顶、同源刷新、到期、目标私有和护盾及附带状态顺序。 |
| EV03 | 验证 NPC 近战、暴击随机流、攻击间隔、受保护成员和周期伤害、旧机制兼容。 |
| EV04 | 固定种子的 Node 和 H5 四人、八人房验证三发 NPC 弹道伤害为 66 → 0 → 66，仅中间一发闪避，各成员结算一次。 |
| EV05 | 同一交付包通过仓库外空缓存离线接入、机制 96 闪避压制兼容复验及 Rust 和 Node 回归。 |
