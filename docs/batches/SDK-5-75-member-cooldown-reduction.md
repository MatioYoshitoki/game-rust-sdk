# SDK-5-75 自身技能冷却缩减

对应 R3.2/M03/M04 和原行为规格 §4.1、§5.1。目标 SDK 0.77.0、机制 92、schema 7、协议 6。自身技能通过 `self_status.on_commit_self_statuses` 提供 `timed_attribute_modifier / cooldown_reduction`。配置时长和正向 `modifier_bps`（1～4000），同源刷新，有效实例相加后封顶 4000 bps。

每次主动技能成功提交时读取当时的缩减，再登记冷却。计算为 `基础冷却 × (10000 − 有效 bps) ÷ 10000`，向下取整到毫秒。正冷却下限为基础冷却与模拟步长的较小值，基础零冷却保持零。本次提交新施加的缩减从之后的提交开始生效。冷却截止时间登记后保持固定，缩减刷新、到期和退场各走现有规则。普攻、道具、NPC 和技能后摇沿用原冷却和期限。

客户端读取现有 `player_skills.ready_at_ms` 和目标私有状态。这个切片覆盖自身技能加成与主动技能提交，原装备、专精和其它缩减来源按各自规格接入。

| ID | 验收 |
|---|---|
| CR01 | 机制 92 接受合法自身技能缩减，拒绝旧机制、越界、非法重复策略、道具和其他绑定。 |
| CR02 | 验证聚合封顶、取整、最小值、零冷却和提交时读取，含施加加成的技能及准备期间到期。 |
| CR03 | 验证截止时间冻结、到期边界、失败不扣费、目标私有，以及普攻、道具和后摇原期限。 |
| CR04 | Node 和 H5 四人、八人房验证首次 2000ms 冷却缩至 1500、1200ms，加成先到期，原截止时间保持，下一次提交使用完整 2000ms。每位成员结算一次。 |
| CR05 | 同一交付包通过仓库外空缓存离线接入、机制 91 加减速兼容复验及 Rust 和 Node 回归。 |
