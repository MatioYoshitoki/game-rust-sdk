# 青芽诀、万木归元与友方治疗组合

本批属于 DELIVERY-01。宿主以技能 ID 和可信熟练阶段选择治疗公式、可选生息、目标周边群疗和溢出盾。客户端沿用现有指定友方施法。初次锁定和提交均重验主目标，继续使用原灵力预约、费用和冷却流程。

| 验收项 | 预期 |
|---|---|
| 两组原配方 | 青芽诀和青芽续生使用原技能 ID、费用、冷却和机动点选时序。青芽诀覆盖五阶段的即时治疗、生息、群疗和圆满溢出。万木归元对照五行原阶段即时治疗公式。 |
| 冻结生息 | 每跳原始治疗按提交时的即时治疗预算比例冻结，实际恢复沿用受疗倍率和缺口钳制。同一来源、目标和状态 ID 刷新，独立来源可共存。首跳在 1 秒，最后一跳在第 3 或第 5 秒的截止点，完成后清理状态。 |
| 群疗与溢出 | 大成起围绕主目标选取 150 范围内仍有效的成员，次要目标即时预算 60%、生息预算 50%。圆满即时治疗的实际溢出按配置进入 6 秒护盾，同来源的盾上限为目标最大生命 10%，沿用统一盾池。 |
| 双成员闭环 | 验证预约取消、主目标失效不扣费、两端私有结果、重连恢复冻结数值与剩余跳数、退场停止对应来源。配置拒绝无法执行的状态引用及越界数据。 |

样例以结构化治疗因子确定直接数值，青芽诀熟练使用显式的固定 100 加 220% 来源威力，青芽续生使用技能行的 700%。原说明中的「+10%」和「150%」与这些结构化行待复核。群疗倍率依据阶段设计应用到次要目标，生息冻结的是受疗调整前的即时预算。圆满转盾样例将即时治疗溢出全量送入统一护盾池再钳制。主目标沿用 SDK 的指定其他成员路径，范围内施法者可获得次要治疗。万木归元愈纹、万木长春溢出盾、主目标自选以及常驻成长与真意分别保留验收。
