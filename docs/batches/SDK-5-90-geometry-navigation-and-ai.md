# SDK-5-90 生产几何、导航与对局 AI

DELIVERY-03 覆盖 R4.1 和 R4.2。沿用模块 02 的世界接触和清理契约。资料包 G-02 已提供地形标记和编排装饰元数据，正式装饰碰撞、程序化装饰和动态阵法的权威几何仍需宿主导出。第一轮用包外合成输入验证 Rust 几何机制。

| 验收 | 可判定结果 |
|---|---|
| GN01 几何输入 | 宿主在同一世界坐标系提供格网、完整凸边界、静态装饰和定时阻挡凸多边形。校验拒绝无效顶点、重复标识、不合法时段及越界出生和落点。首轮按资料包的平面地图验证。 |
| GN02 一致性 | 圆形足迹不能穿过细障碍或斜边。移动、导航、击退、视线、弹道和落点复用几何。通行、视线和弹道分别按声明处理。 |
| GN03 动态变化 | World 按相对开局时间推进阻挡。关闭会覆盖活体足迹时推迟关闭。已存在路径按新几何重新校验，宿主通过协议 6 的全量和增量读取实际生效状态。 |
| GN04 高差与地形 | 启用 `world_geometry` 后，走路、导航、突进和击退按离开格的爬升/跌落上限判断跨格。坡道在格内线性变化，按实际过界点比较高差，斜穿格角须通过两侧检查。地形伤害由固定步推进，依次验证免伤、减伤、护盾、扣血与死亡清理，并验证安全地面清除累计余数。弹道和视线仍按各自的阻挡配置判断。 |
| GN05 怪物战斗 AI | 用同一 World 的两名成员验证每只怪物独立记录实扣 HP 仇恨，按可配置阈值稳定换敌。合法强制目标可超出自然警戒范围，保护、失效或超出记忆范围时回退。呼救和支援检查同群、距离和实体资格。牵引外拒绝攻击，回到范围内的有效伤害可打断归位，完成归位才回血和清仇恨。技能按配置顺序检查目标、费用、冷却、容量和概率；支援锁定同群最低 HP 比例；远程在近身时先沿合法地面拉开距离。 |
| GN05 Boss 阶段 | 按配置降序跨越生命阈值，一次跨越多个阈值时逐阶段发布。治疗期间阶段单调，完成归位才恢复第一阶段并更新实体代次。新决策读取当前阶段的技能顺序和普攻间隔，已准备的技能仍按原槽位提交，共享槽冷却保持。全量、增量和重连一致。 |
| GN05 参战 NPC | 宿主在冻结配置中为指定席位选择策略。成员完成正常入场和就绪后，Rust 依配置搜索、拾取、选择敌方技能或撤离。测试低血量、拾取目标、库存归属、保护与并发拾取，确认使用同一动作、库存和结算入口。外部玩法指令不可接管自动席位，公开快照与事件沿用普通成员身份。 |
| GN06 模块验收 | 用两组包外合成对局验证公开 Rust/Node 接入，一组覆盖地形、Boss 阶段与重连，另一组覆盖参战 NPC 的搜索、战斗、拾取和撤离。正式地图几何由宿主提供并单独核验。 |
