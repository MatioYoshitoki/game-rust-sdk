# SDK-5-65 友方持续治疗溢出转护盾

对应 R3.3/M04 及原行为规格 §4.2、§4.3、§4.4。目标 SDK 0.67.0、机制 82、schema 7、协议 6。允许 `ally_heal.hot_status` 绑定显式配置 `overheal_shield` 的 `periodic_heal`。HOT 和引用的吸收盾都采用 `refresh` 与 `source_scoped: true`。使用既有 `cast_unit`，接受与提交重验友方身份、射程和视线。

每跳读取目标当时有效的受治疗倍率，先回复气血，再对实际溢出按配置万分比取整并转换为盾。沿用单盾、总盾上限和追加余额规则。零新增时保持护盾期限。状态槽已满时保留本跳已结算气血，只拒绝新增盾。保护或失效的周期跳沿用原规则。

每跳回复和实际授盾依序发给来源及目标，状态实例只进入目标快照。来源和目标退场都清理对应 HOT 与转换盾，其他来源保留自己的实例和节拍。

| ID | 验收 |
|---|---|
| AHOT01 | 机制 82 接受显式转盾的友方 HOT，拒绝旧机制、错误比例、非来源分组或非刷新盾。 |
| AHOT02 | 验证按跳读取目标倍率、气血优先、向下取整、同来源余额与刷新、单盾和总盾上限。 |
| AHOT03 | 验证保护跳过、状态槽不足时保留回复、实例与事件归属，以及来源或目标离场清理。 |
| AHOT04 | Node 和 H5 的四人房实回 0/0/0、实授 55/55/0，施法者先离场。八人房实回 100/60/0、实授 0/20/50，目标先离场。两组退出时清理 HOT 和盾，各成员结算一次。 |
| AHOT05 | 同一交付包通过仓库外空缓存离线接入、机制 81 友方即时转盾兼容复验、Rust 和 Node 回归。 |
