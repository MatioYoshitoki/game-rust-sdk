# 开放式方向普攻引导

本批属于 DELIVERY-01 与 R3.4。通过可信席位的普攻 profile 配置 `basic.beam`，在既有普攻行动结算上添加开放式方向会话。选择贯世明光的源参数验收。每个成员最多持有一个会话。局内换装和装备实例解析继续按各自工作包验收。

| 验收项 | 预期 |
|---|---|
| 启动和转向 | `start_attack_beam` 只收方向并生成服务端 action ID；`aim_attack_beam` 与 `end_attack_beam` 必须引用该 ID。方向有限、非零并归一化，旧 ID 无法干预当前会话。 |
| 开放式时钟 | 无会话时限。首跳在一个配置周期后，此后每周期一跳。首跳前松手保留一次以最后合法方向执行的脉冲，松手后不再接收转向。首跳后松手于下一固定步结束且不追加脉冲。 |
| 权威命中 | 每跳重建平头有限矩形。怪物碰撞圆与矩形相交即可进入候选，按沿轴距离和 ID 排序，目标中心仍须通过精确弹道视线。每跳独立裁决，允许重复命中同一目标，无额外表现延迟。 |
| 移动和控制 | 会话中保存最新移动、寻路或停止意图，位置暂停；结束后按现有规则恢复。眩晕中断会话；定身和沉默维持 SDK 既有的移动和技能边界。会话占用普攻准备槽，阻止并行普攻、技能和撤离。 |
| 退场和重连 | 断线或保护立即隐藏射线且撤销终态收益，下一固定步结束。重连全量不继承旧会话。死亡和离场直接清理。 |
| 动作终态和接入 | 实际伤害进入同一普攻动作账本，终态最多回灵和整次动作吸血一次，再开始配置冷却。公有发布含持有中的会话、方向、首跳及下一跳时钟；宿主据此冻结客户端移动预测。Rust、Node/H5 传输及普通宿主验收。 |

贯世明光样例使用 440 射程、22 半宽、150 ms 周期、每跳 1800 基点、最多 8 个目标。周期须为固定步的整数倍。SDK 方向会话的输入不携带目标、威力、范围或时长。
