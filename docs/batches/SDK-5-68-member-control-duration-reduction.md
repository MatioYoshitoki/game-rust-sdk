# SDK-5-68 控制时长减免

对应 R3.2/M03/M04 及原行为规格 §4.1、§4.4。目标 SDK 0.70.0、机制 85、schema 7、协议 6。自身技能通过 `self_status.on_commit_self_statuses` 施加 `control_duration_reduction` 定时修正。使用 `timed_attribute_modifier`、`refresh` 和来源分组。每个定义的 `modifier_bps` 为 1～4000 万分比，实际有效修正相加后封顶 4000。

本批将减免接入 NPC 弹道沉默。命中时先判断免疫，再读取目标当前减免。沉默有效时长为配置基础时长乘剩余比例，向下取整到毫秒，最低 1 毫秒。原始伤害和同次其他效果不受影响。首次施加或刷新各自冻结新的截止时间，后续减免变化按下一次命中计算。免疫仍返回 `IMMUNE`，已有沉默保持原期限。

客户端使用目标私有状态的施加、截止时间及移除事件展示结果。增益、DOT、已有沉默的当前期限和其他模式的控制乘区各自沿用原规则。

| ID | 验收 |
|---|---|
| CD01 | 机制 85 接受合法自身技能减免，拒绝旧机制、越界比例、非法重复策略及非自身技能绑定。 |
| CD02 | 验证逐次命中读取减免、叠加上限、毫秒取整、同源刷新及精确到期。 |
| CD03 | 验证免疫优先、其他状态保持期限、减免到期不改变已施加沉默，以及私有归属。 |
| CD04 | Node 和 H5 在四人、八人房验证首次 NPC 沉默分别为 2100、1680ms，减免先到期但沉默仍按冻结期限结束；第二次命中恢复为 2800ms，各成员结算一次。 |
| CD05 | 同一交付包通过仓库外空缓存离线接入、机制 84 定时免疫兼容复验、Rust 和 Node 回归。 |
