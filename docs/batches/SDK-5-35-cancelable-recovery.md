# SDK-5-35 可取消后摇

对应 R3.1/M02 及原手动动作契约中「可取消后摇同一步结束并建立新动作」。目标 SDK 0.37.0，协议 6，schema 7，机制 52。范围为同 World 1～8 成员 PVE 的普通方向弹道。

普通方向技能的主槽或附加槽可选 `recovery_cancel: {"after_ms":600}`，从成功提交起算。数值必须是固定步的非负整数倍，且比后摇结束至少早一个固定步。0 表示提交后立即可取消。仅机制 52 允许该字段。未配置时保留原后摇和 SDK-5-34 的跟进规则。蓄力、引导、再施放、穿透、其它技能形态及普攻不进入这条取消路径。

在 `cancel_at_ms <= logical_ms < recovery_until_ms` 内有两种操作。原 `cancel_action` 结束本人的后摇并清除待执行跟进。另一普通方向技能的原 `cast` 在同一步先完整验证新动作的准入，再结束旧后摇、清除旧队列并建立新准备。失败的输入保留已有后摇、队列、冷却和费用。新准备之后仍由原提交门禁重验并结算。显式取消过早时只按原语义取消待执行意图，后摇继续。自然结束等号时按原普通施法准入。

已经提交的弹道、实际费用、技能冷却与状态保留。移动和停止继续沿用各阶段策略，明确取消后恢复普通移动。后摇结束与新准备不会同时投影。SDK-5-34 的队列在允许取消前仍按原规则接受。开放取消后，有效的新施法即时接管。未触发取消时，既有队列仍等自然结束。

本人快照可选 `recovery_cancel`，包含来源技能与可取消时刻，仍以现有 `recovery_until_ms` 为截止。后台、失联、重连清旧意图，保留已提交的取消时刻和后摇截止。恢复就绪后按原时间继续；离场和死亡按原终局清理。其它成员看不到该私有投影。H5 用权威快照显示取消时机并发送原动作。
