# 施法锚点返回与主动结束

本批归 R3.4。原资料的再施放包含返回来源和消费实例。点锚的返回在一次输入中把中心移到施法者当时的权威位置。宿主在原 `recast.behaviors` 中选择 `relocate`、`return_to_source` 和 `end`。省略该字段时沿用迁移，三个动作共享原窗口、次数和每次灵力费用。

| 验收项 | 预期 |
|---|---|
| 准入 | `return_anchor` 与 `end_anchor` 只携带锚点 ID、原动作 ID 和下一序号。沿用原所有者代次、装备、距离、视线、控制和动作阶段检查。配置拒绝空集合、重复与未知行为。 |
| 返回 | Rust 读取施法者位置并校验落点。返回后保留锚点和绑定领域的 ID、时钟与命中预算。已经位于施法者位置时拒绝本次输入。 |
| 主动结束 | 成功消费原实例，发布一次携带原身份与序号的 `anchor_recast_ended`，锚点以 `recast_consumed` 结束。绑定领域以 `anchor_invalid` 同步回收。固定落点效果继续按其生命周期处理。 |
| 结算 | 成功只扣一次再施放费用，原布置冷却继续计时。重复、越权、非法坐标、窗口截止和资源不足均在变更前拒绝。 |
| 发布 | 增量和同 World 重连恢复显式启用的行为、锚点位置和已用次数。主动结束后重连没有已消费的锚点或绑定领域，另一名成员的实例仍可用。 |

本批覆盖点锚。沿路径飞回的运动实例和生产地图几何另行验收。
