# SDK-5-70 道具净化自身沉默

对应 R3.1/M02、R3.2/M03/M04 与原行为规格 §4.4 的清状态边界。目标 SDK 0.72.0、机制 87、schema 7、协议 6。复用 `use_item` 和本局拾取库存。在 `member_item_use` 配置 `cleanse_self_statuses`，列出 1～2 个互异、已登记的沉默状态定义 ID。净化道具是独立效果，可以配置原道具冷却及共享组。回血、回灵、转盾、品质倍率及附带状态各走原配置分支。

成员沉默期间可使用净化道具。Rust 校验版本、可消费库存、冷却和当前有效状态。一次成功使用消费一件、推进一次库存版本并启动配置冷却，移除自身所有匹配的有效实例。没有有效匹配、版本冲突、库存不足或冷却中均原子拒绝。目标收到私有 `status_removed`（`cleansed`）和原有 `item_used`。移除最后一个沉默后可重新施法，已打断的动作不自动恢复。下一次命中仍可重新施加沉默。净化保持其他状态、当前气血与灵力。

本批用道具入口验证显式状态选择与移除。该入口是最小验证切片，原技能、功法的净化触发，以及其他控制或驱散增益按各自规格接入。

| ID | 验收 |
|---|---|
| CL01 | 机制 87 接受独立净化道具，拒绝旧机制、空表、重复、未知 ID、非沉默及组合效果。 |
| CL02 | 沉默中成功消费一件，仅移除自身配置命中的有效实例，保持其他状态和资源。目标收到正确私有事件，解除门禁且下一次命中可重新沉默。 |
| CL03 | 覆盖无匹配、精确到期、旧库存版本、未拾取库存及冷却失败的原子性。 |
| CL04 | Node 与 H5 四人、八人房验证击杀、拾取、沉默、净化、恢复施法、再次中沉默与一次结算。 |
| CL05 | 同一交付包通过仓库外空缓存离线接入、机制 86 首控免疫兼容复验、Rust 和 Node 回归。 |
