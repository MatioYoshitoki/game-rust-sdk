# 移动区域进入与碰撞安全击退

本批归 R3.4。使用 NPC 既有选敌、施法准备、打断、费用和冷却。可信配置给指定 NPC 技能绑定线性移动圆形区域，并声明进入伤害、击退和命中状态。罡风刃用于验收，试炼阶段与风眼目标由各自的工作包验收。

下表记录 SDK 0.119.0 的初次验收。来源失效后的接触见 [后续验收](SDK-5-88-detached-enter-area.md)。

| 验收项 | 预期 |
|---|---|
| 选点与释放 | NPC 准备时冻结目标位置及方向，开始准备后公开该路线。750 ms 采用结构化施法规则。释放重验原点及精确视线，成功后占用共享区域容量并开启原费用及冷却。取消、目标保护导致无合法目标、来源失效或容量拒绝时回收准备。 |
| 区域推进 | 圆半径 60，速度 400，最大行程 900。每个固定步按区域与成员的相对运动扫掠，先按进入进度，再按距离与身份排序。首次进入和满足间隔的再进入可命中，连续停留仅登记一次。每步最多八个目标，每实例最多 32 次。源 20 Tick 映射为 2000 ms，周期 Tick 不配置效果。 |
| 命中与击退 | 合法接触读取目标当前最大生命，取 500 基点。比例伤害跳过阶差与护甲，依次应用减伤、护盾和保命。存活目标沿冻结施法者原点到自身的方向推离最多 200，按角色碰撞半径连续裁剪到安全位置。重合或有控制免疫时跳过位移。最后按共享状态规则施加来源独立的 20% 减速，刷新 3000 ms。滑移倍率 3 只随位移事实发布。 |
| 成员与发布 | 两席位独立准入、身份和命中记录。保护、无敌与死亡按既有规则处理。重连可读取同一准备或已释放区域。到达路线终点、期限或命中预算用尽结束实例。已释放区域按配置可在来源失效后走完路线，接触裁决仍要求有效的原来源，继任代次不承接旧命中。 |

源技能表的 1.2 秒为旧叙述和旧字段，使用结构化施法生命周期的 750 ms。场景接口给出最大生命 5%，优先采用该语义。扫掠由最大行程限定，未将原长寿命配置映射为停止后驻留。路线按地图边界裁剪，击退按移动障碍裁剪。
