# SDK-5-21 DOT/HOT 多人适配

2026-11-05；先冻结MP01～MP12再实现。起点SDK-5-20 / 0.22.0 / 协议6 / schema7 / 机制37；目标0.23.0 / 协议6 / schema7 / 机制38。沿固定1～8名必需成员、单一World与逐接收者full/delta及冻结金融责任；不寻找第二款游戏。本批主要补R2实体关系和R3.2/R3.3已有周期能力的多人接入切片，不宣称完整工作包关闭。

## 范围与契约

复用已有Statuses定义/实例/来源分组和take_periodic_due统一队列，不为每成员创建World或另写一套DOT/HOT公式。只支持现有普通方向弹道的命中目标DOT（玩家→NPC、NPC→玩家），及技能提交时的自身HOT（玩家→自身、NPC→自身）。NPC引用同一status_definitions；NPC自身提交绑定本批仅HOT，NPC命中绑定仅DOT。原玩家ATK/DEF自身及命中状态保持。不支持成员互伤、友军HOT、其它单位技能/区域/穿透、盾/受治疗修正/控制/召唤或其它周期公式。

仅schema7的机制38开放新增能力，协议6/CreateV6/六类Client调用/金融DTO/恢复schema保持。旧机制1～37及协议1～5不扩大能力、旧JSON原文/hash/归档不修改。NPC视图新增可省略statuses，仅机制38输出：本人来源施加在该NPC上的状态，以及NPC自身状态；不包含其他成员来源的状态。本人statuses仍只含本人目标状态，members仍只含公共字段。Rust权限投影后再diff；全量/增量/重连均遵守同一权限。新字段的Rust结构体字面量及旧严格JS解码器须按0.23.0迁移。

## 目标、来源与时序

实体身份由kind/id/generation组成，不用participant常量或连接ID代替。连接换代不改变实体代次；同World重连保留实例/节拍/成本/CD。NPC真正归位复位时，机制38清除以其为来源或目标的状态、提高其实体generation，并拒绝旧代弹道/周期；不把同ID的新生实体当旧目标。

source_scoped=true时，同NPC上的同定义DOT按来源独立；false沿原refresh/ignore：refresh保留实例ID并转移到最新合法来源，重取该来源有效ATK并重置完整节拍；ignore保留原来源/计划。旧来源退出不得删除已转移给其他来源的实例；来源分组不关闭时也不重复授予。ignore的实例身份通知只给实际保留来源，不能把别人私有实例发给尝试施加者。

DOT在合法直接命中后对仍存活的敌对目标施加；墙挡、闪避、目标保护或死亡不施加，周期不再次触发命中绑定、回灵/暴击/闪避/随机数。raw_damage在施加组开始时按来源有效ATK×damage_bps冻结；实际跳按当前目标DEF及原伤害取整/最小伤害执行。HOT在提交时按来源自身基础maxHp×heal_bps冻结，实际回复按当前缺口裁剪；满血/零量记录0，不复活、不转盾/MP。不新增其他治疗乘区。

首跳等待间隔，截止点排除；队列按scheduled_at、DOT优先于HOT、实例ID排序。非整步在首次达到的固定步执行，下一计划不漂移；到期优先，不补到期历史跳。周期在本步移动/AI/提交/弹道及撤离完成前执行，绝对终局和主动放弃优先。来源/目标保护、后台或未ready时，该实例消耗到期次数但跳过效果；NPC来源或目标归途中同样跳过。只影响相关实体，另7名成员和其他来源实例继续。

DOT造成实际HP损失走原撤离中断、死亡、击杀归属、一次掉落和原资产结算。归功于状态实际来源及代次；同NPC多个DOT同刻致死只给一次击杀/掉落。致死DOT先清状态，同刻HOT不能复活；目标成员死亡只结束本人，其他成员继续。

## 清理、权限与预算

成员死亡/撤离/Leave/断线超时/绝对终局，从进入settling起清除以本人为目标及实际来源的状态/在途弹道；不依赖金融回执成功，不删除别人的实例。来源和目标清理使用明确source_invalid/target_invalid；NPC死亡/归位复位同样清理；关闭立即释放所有临时状态。退出视图冻结与grace沿SDK-5-20，不用重同步继续观察生存者。重启只恢复原Closed金融责任，不恢复周期或按墙钟补跳。

StatusApplied/Refreshed/Ignored/Rejected/Removed与PeriodicTick/PeriodicHealTick沿EventV4::Private按权限路由：成员自身/受击状态给目标本人；成员→NPC详细状态给实际来源本人；NPC自身HOT给当前存活成员。Removed按原实例权限拆分ID，不能整组广播。公共Damage/MonsterDefeated仅携带原公共HP/归属事实，不附带其它成员私有SP/CD/周期量。

沿原16定义、每绑定最多2引用、每实体≤32槽、每实例≤128跳；机制38按成员数+固定NPC数验证总状态预算≤128。容量检查必须在费用/CD/状态授予/弹道创建前原子完成；命中附带整组不足时不部分刷新。预算、伤害/治疗比例、时间、绑定、source_scoped及refresh/ignore均由配置初始化，Node/H5只提交意图、解码展示和执行存储事务。
