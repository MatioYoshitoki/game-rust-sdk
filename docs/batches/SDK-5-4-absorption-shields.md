# SDK-5-4 通用吸收护盾最小闭环

2026-11-04；**先冻结规格，再实现；SH01～SH10受控验收通过**。目标crate **0.7.0**、机制 **22**，仍为schema4/协议3、单人PVE、现有主技能/怪物弹道的提交self及命中target绑定。复用状态身份、来源分组、槽位、期限、清理和资产闭环。

## 配置与授予

1. 状态定义新增`mechanism:"absorption_shield"`、必填`shield_bps`整数1～10000；盾量为`floor(目标基础maxHp × shield_bps / 10000)`，本批仅这个授予公式。沿用id/duration_ms/source_scoped；重复策略仅refresh/ignore，禁止stack/max_stacks、attribute、modifier_bps（含null）或额外策略。旧属性定义禁止shield_bps；旧机制禁止所有新盾字段（含null）。
2. status_rules新增必填于盾定义的`shield_cap_bps`整数0～10000；每目标聚合盾帽为`floor(基础maxHp × shield_cap_bps / 10000)`。数值由配置初始化，来源常规30%样例使用3000；本批不签收PvP或秘境额外容量分类。
3. 新授予只裁剪本组，可用量=聚合帽−其它组剩余盾量。新实例remaining=min(请求盾量,可用量)，不倒扣其它组。refresh替换本组剩余量为该计算值并刷新整组期限/最新来源；ignore完全保持原来源、剩余量与截止。基础maxHp与本局配置固定，因此refresh不减少已有剩余量。
4. 合法授予计算为0（帽满/帽0/小HP向下取整）时不创建实例/期限，发零授予事件；已有ignore保持。绑定组仍先按原槽位规则整组预检，零授予不绕过满槽拒绝；容量足够的零授予正常提交并付原成本/CD，不退款。
5. source_scoped按原实体/代/轮次分组；非分组refresh由最新来源拥有整组，来源失效清理。每组一个槽/期限，无盾量读增/自动补盾；破盾立即移除，后续合法授予为新ID。[start,end)，同刻先到期；重连不刷新，重启不恢复。

## 伤害链与事件

- 资格/保护/墙/闪避→原ATK/DEF/暴击/元素/取整/minimum_damage→消耗护盾→剩余伤害夹到HP→受击/死亡。必须先吸收未按HP截断的伤害，再夹HP，超杀不能提前缩减护盾消耗。无有效盾的旧链保持，原随机消费次数保持。
- 各目标有效盾按**截止、创建时刻、稳定实例ID字典序**消费；刷新沿原applied_at_ms更新创建排序时点。一次命中逐组扣减，耗尽立即移除，零伤害/被拒绝接触不扣盾。同刻多个合法命中依Rust原顺序逐次消费；重试/重复回执不重复扣。
- `Damage.amount`仍是实际HP伤害，完全吸收时为0，保留合法接触事件。新`shield_absorbed`包含攻击来源、目标、吸收合计和逐组(instance_id,absorbed,remaining)，在同一伤害流程内先于对应Damage输出；`status_removed`增加depleted原因。授予输出`shield_granted`的requested、granted（实际新增量）、remaining和可选instance_id，已有status_applied/refreshed/ignored继续沿用。
- 保持原接触/HP区别：合法接触仍可触发命中状态、剑印、手动接触打断支援/反击窗口以及撤离中断；吸血、Boss血量阶段、正HP伤害才中断的调谐/交互及原普攻回灵条件继续使用实际HP伤害。完全吸收不触发死亡、掉落或击杀奖。主动放弃/绝对终局不被护盾阻止。
- 所有现有PVE伤害入口共用吸收：玩家普攻/主技能、怪物近战/弹道、范围、重击、反击和限时站位/直接命中伤害；既有取消/归位/旧轮隔离保持。此批不添加其它伤害/免疫类型。

## 输出、宿主与边界

StatusView新增可省略shield `{granted,remaining}`（granted为本次裁剪后的授予额度，remaining为可消费余额）；盾实例modifier_bps为0、不贡献派生属性。机制22的Snapshot/MonsterView新增shield_total（含0），旧机制及旧非盾实例省略新字段，旧19～21 JSON保持。公开Rust字段/枚举/事件为0.7.0次版本源码变更；六类调用、协议1/2/3、资产/结果正文与恢复schema1保持。

Node/H5只展示剩余盾、吸收和实际扣血，不算金额、不直接写盾量；进程重启的Closed视图移除shield_total及临时状态，不恢复World/护盾或按新配置重算冻结责任。来源behavior §4.2的吸收/排序/本来源裁剪是基线；refresh/ignore和有限授予公式在本批明确注册，不签收全部86状态、PvP/秘境护盾、控制/驱散/DOT/HOT、反伤、SPD/HP动态上限、多技能槽、新地图或第二款游戏。
