# B2-4 并发、背压与外部 I/O 适配契约

日期：2026-11-03。用户已授权收尾本小步。范围为当前单机验证宿主的有界队列、异步 I/O 隔离、并发幂等和适配契约，不签收生产库存服务、跨机接管或正式容量。执行结果见 [验收记录](../evidence/B2-4-flow-control-2026-11-03.md)。

## 交付与门槛

| 边界 | 本批行为和验收 |
|---|---|
| 会话准入 | 每会话最多 64 个执行中/等待任务，普通输入与 ACK 合计最多 56，保留 8 个控制任务空间；FIFO 不插队。超限返回 HTTP 429/QUEUE_FULL，未执行请求体，无资产副作用 |
| 控制与收尾 | 排空、回执、断线和关闭使用控制空间；慢 I/O 不占会话执行队列。正常队列满时仍可接纳关闭；控制空间也满时明确拒绝，由调用方按原身份重试；Rust 自身期限独立生效 |
| I/O 调度 | 全宿主最多保留 32 项请求、执行 8 项，每会话执行最多 2 项；跳过被单会话额度阻塞的排队项，其他会话可前进。容量不足的冻结责任保留到以后调度 |
| 挂起与迟到 | 不因本地超时释放仍可能写入的远程任务槽；不自动重试写。错误/断连按 unknown，由 Rust 查询/核对，超时关闭不等待 provider 完成。迟到结果经原业务回执入口校验 |
| 原子业务 | 同一 operation/attempt 正在执行时去重，改变冻结载荷拒绝。存储层仍必须按原 operation ID 原子去重，跨 attempt、迟到旧写和人工修正不可重复变更资产 |
| Rust 排空 | drain 的响应接收者已经断开时，原批次放回输出队列，身份/检查点不变。响应已被调用方接纳后，持久责任由宿主承担 |
| 并发语义 | 同身份并发 create 仅一份读取；不同身份竞争同运行时仅一方成功；重复事实仅一份入场请求；并发拾取不重复物品；同所有者并发开局不产生多局扣费 |
| 慢客户端 | 128 项发布历史/未 ACK 上限与 512KiB SSE 写缓冲阈值；慢客户端断开并换代，旧连接失效，无重复准入。HTTP 最多 128 条连接，请求/请求头超时 5 秒 |

验证入口 `python3 scripts/verify_flow_control.py`：5 项 Rust、7 项确定性队列/I/O 测试、8 项真实 Rust/HTTP/Chromium 场景；同时重跑 B1、等距性能、B2-1/2/3。数值是本地验证 profile 的资源边界，不是生产吞吐量或 p99 指标。

## 生产接入契约

宿主工厂可注入 `ioExecute(context, executeLocal)`，返回 `Promise<ReceiptOutcome>` 或同步 outcome。`context` 只包含认证 principal、MatchKey、sessionId 和冻结 BusinessRequest，不包含 World。默认调用 `executeLocal(request)`，保持当前 SQLite 测试账本；注入入口只存在宿主代码，浏览器没有 provider 或检查点写接口。第二参数为本地参考实现，真实远程适配器应调用其正式库存服务。

1. 适配器不得重算 quantity、kept、cultivation 或选择玩法阶段；返回值只表示原业务的权威存储事实。Rust 继续校验 revision/commitId、原请求和尝试。
2. 存储事务须原子提交资产与原 operation 的幂等凭据，冻结载荷冲突须拒绝；使用认证 principal/MatchKey/incarnation 隔离账户与实例，校验 expected_revision，不能只按浏览器 requestId 去重。
3. 请求异常、HTTP 超时、连接重置或缺少记录均只能是 unknown；只有完成旧 attempt fencing 且可隔离迟到提交时，才能返回 not_committed。不能把重试隐藏在 HTTP SDK 中另发新操作。
4. QueryOperation 查询原业务，不产生新资产；ReconcileOperation 由具备权限的库存核对服务履行，以原冻结载荷和匹配的 Reconciled 凭据完成。H5 的人工按钮只是测试替身，不构成生产运营授权。
5. 真实驱动须非阻塞，提供有限连接池/排队和明确提交边界。当前异步 Promise 隔离不能隔离同步 CPU 死循环或同步磁盘卡顿；需要阻塞驱动时应放到独立进程/worker。当前 SQLite 仍是本地同步参考实现。
6. 关闭宿主最多短暂排空已完成 I/O 回执；仍在远程执行的写不能假定撤销。退出后按持久责任查询，远程任务需使用其服务端 fencing；本地独占 SQLite 的旧进程退出证明不能代用。

真实库存适配器须用同一套成功、拒绝、未知、已提交丢回执、未提交隔离、并发 CAS、人工修正、迟到任务、断网及重启场景提供独立证据。没有真实服务接口和凭据时，不能把本批标为生产数据库接入通过。
