# SDK-5-73 NPC 弹道减速

对应 R3.2/M03/M04 与原行为规格 §3.2、§4.4。目标 SDK 0.75.0、机制 90、schema 7、协议 6。NPC 弹道可通过命中施加 `timed_attribute_modifier / movement_slow`。配置有效时长和 `modifier_bps`（-9999～-1），同源刷新并保留来源身份。多个有效减速实例按最强一项计算，最强项结束后自动回到仍有效的下一项。

Rust 先按身法计算基础速度，再乘减速、地形和适用的施法阶段倍率。方向移动、导航与普攻追击共用实时步长预算。减速本身保留原移动意图、导航、追击及准备中的动作。速度变化从下一次实际移动步开始生效。定身、眩晕和原有锁定阶段继续优先阻止位移。到期或净化后恢复有效速度，无需重发移动指令。

沿用定时免疫、首控免疫、控制时长减免和 `cleanse_self_statuses`。同一次命中的多个控制最多消耗一次首控机会。沿用目标私有状态发布，H5 展示服务端状态和坐标。本批以 NPC 弹道、成员移动为最小闭环，原加速、镇足叠层、其它来源和 NPC 移速规则按各自规格接入。
