# 磐心守一与状态保命

本批属于 DELIVERY-01。可信熟练阶段决定同一瞬发自身技能的冷却与提交状态。通用状态保命沿用减伤、护盾、实际扣血与保命恢复的权威结算顺序，并由实体代次和配置组保存冷却。

| 验收项 | 预期 |
|---|---|
| 五阶段 | 磐心守一消耗 1800000 灵力，后摇 80 ms，可通过移动或显式动作取消。入门的冷却为 40 秒、窗口为 5 秒，熟练起分别为 36 秒和 6 秒。五阶段均提供 70% 减伤和控制免疫。 |
| 致命保护 | 精通起仅在有效的本人状态窗口内，实际穿过护盾且足以致死的伤害才可触发。保留 1 点生命并施加 2 秒伤害免疫。圆满额外按当前最大生命的 15% 计算治疗。 |
| 内置冷却 | 首次成功启动 120 秒内置冷却。刷新、载体切换和同一 World 重连保留冷却；不同实体、代次和配置组独立。失败或完全吸收不启动冷却。达到期限且拥有有效载体时可再次触发。 |
| 自然结束 | 大成起自然到期施加 20% 减伤，持续 2 秒。驱散、死亡、离场和关闭只做清理。保命叶子及余韵沿用原生状态和现有事件。 |
| 兼容 | 旧的战斗档案保命保留每实体代次一次。新增配置严格校验熟练阶段、有效载体、附带状态与冷却组。 |

样例以原主动阶段的精通条目和守护因子的 2000 ms 作为无敌时间。资料中另有一条描述 3 秒无敌的同名状态，属于待核口径。圆满治疗沿用原生受疗倍率和缺口上限。常驻成长和真意另行验收。

将样例技能加入验收基底的 `additional_skills`，按 ID 合入状态和战斗配置表，并将样例的减伤聚合帽写入 `pve.status_rules.attribute_caps_bps.damage_reduction`。宿主为该技能提供可信阶段及足够灵力。 [配置样例](../../examples/combat-host/source-lin-mi.json) · [验收基底](../../examples/combat-host/mastery-stages.json)
