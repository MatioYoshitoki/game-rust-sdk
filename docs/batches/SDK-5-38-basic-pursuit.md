# SDK-5-38 锁定普攻短追击

对应 R3.1/M02 及原需求的锁定普攻短追击。目标 SDK 0.40.0，协议 6，schema 7，机制 55。范围为同 World 1～8 成员 PVE，显式锁定敌方 NPC 的直线追击。

对局可选 `basic_pursuit: {"max_range":350,"duration_ms":1500}`。追击范围必须有限、大于实际普攻射程、至多 10000。时长为与固定步对齐的正整数，至多 1800 ms。仅机制 55 开放该字段。未配置以及自动选择目标的 `attack` 沿用原射程规则。射程内的 `attack_unit` 沿用原准备或冷却排队。

`attack_unit` 指定的敌方 NPC 超过实际射程但在追击范围内时，需当前已就绪、普攻冷却结束、动作槽空闲、目标有效且可见，并能沿原移动碰撞规则直线抵达射程边缘，才受理一次追击。受理保存请求 ID、目标代次和截止时间。追击占用准备入口，不设冷却，不发弹道。禁止并发普攻、技能与撤离。移动、导航和停止仅更新待恢复的手动意图。

每个固定步以目标当前权威位置朝射程边缘推进。速度沿现有玩家属性与地形配置，沿用扫掠碰撞。碰墙、目标失效、失去视线、超出追击范围或达到截止等号时拒绝原动作，不绕路、改选或补追。进入实际射程时沿原 ID 转入普攻前摇。该前摇冻结移动，提交重验目标和射程，按既有事务发射并设置冷却。成功、失败或主动取消后恢复最新手动意图。后台、失联、重连或终局清除追击与旧移动。已有的射程内攻击保留原移动语义。

本人协议 6 快照可选 `basic_pursuit`，带 `action_id`、目标代次、起始和截止。准备与实际提交沿现有投影，失败沿用本人 `action_rejected`。Node/H5 继续使用 `attack_unit` 与 `cancel_action`。绕障导航、追击期间重新锁定、冷却内排队追击与玩家目标分别验收。

| ID | 验收 |
|---|---|
| BP01 | 配置版本、射程、时长与固定步边界，机制 54 和未配置行为兼容。 |
| BP02 | 指定目标从追击进入原前摇、移动缓冲、实际弹道、伤害与冷却各一次。 |
| BP03 | 超距、路径阻挡、目标代次、视线和截止等号失败无费用、弹道或冷却。 |
| BP04 | 取消、幂等、连接切换、成员隔离与私有 full/delta 坏帧原子拒绝。 |
| BP05 | 普通 Node 与真实 H5 四人验证追上并发射，八人验证中途取消与独立结算。 |
| BP06 | 同候选 Rust/Node、格式/Clippy、空缓存离线交付及机制 54 包外回归。 |
