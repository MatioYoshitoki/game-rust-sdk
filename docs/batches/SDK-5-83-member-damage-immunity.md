# SDK-5-83 定时伤害免疫

对应 R3.3/M04 和原行为规格 §4.2。目标 SDK 0.85.0、机制 100、schema 7、协议 6。多人 PvE 的自身技能可提交 `timed_control / damage_immunity`，通过配置定义持续时间、同源 `refresh` 和 `source_scoped: true`。沿用状态容量、技能成本与冷却、私有状态发布及退场清理。

NPC 弹道和合法近战对成员的接触在资格与保护检查后，先检查目标的当前伤害免疫。免疫有效时，本次攻击结束，保留护盾与 HP，跳过闪避与近战暴击随机抽取及命中附带状态。NPC 近战仍消费原攻击间隔。成员承受的 NPC 周期伤害在每跳实际执行时检查免疫，该跳伤害为零，跳数和周期进度照常推进，原状态的期限继续流逝。免疫到期时恢复原普通伤害链。

客户端观察受保护成员的私有免疫状态与现有弹道、伤害、周期事实。固定种子 Node 和 H5 四人、八人房观察免疫前、有效期间及到期后的三发 NPC 弹道。该切片覆盖多人 PvE 的 NPC 普通直接伤害与周期伤害。

| ID | 验收 |
|---|---|
| DI01 | 机制 100 接受合法自身技能免疫，拒绝旧机制、非法重复策略、数值负载、道具和其他绑定。 |
| DI02 | NPC 弹道和近战在闪避及暴击前检查免疫，验证护盾、HP、附带状态与随机流，近战保留原攻击间隔。 |
| DI03 | 验证刷新、精确到期、成员私有归属和退场清理；NPC 周期伤害在免疫期间跳过伤害但推进节拍，到期恢复。 |
| DI04 | Node 和 H5 四人、八人房验证三发伤害为 66 → 0 → 66，每位成员各准入并结算一次。 |
| DI05 | 同一交付包通过仓库外空缓存离线接入、机制 99 NPC 命中复验及 Rust 和 Node 回归。 |
