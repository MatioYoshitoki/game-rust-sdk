# 同刻普攻器型与剩余机制分组

本批属于 DELIVERY-01 与 R3.4 的交叉验收。已有可信席位配置继续选择普攻 profile。本批新增两种通用的 `basic.impact.timing.followup`，用万镜回廊和照骨碎光的原始参数验收。旧单次 `refraction` 和固定延迟各自沿用原形状。自动从装备实例解析器型及局内换装继续按原工作包验收。

| 剩余机制组 | 对应器型 |
|---|---|
| 同刻多段接触与主目标爆破 | 万镜回廊、照骨碎光 |
| 开放式方向引导 | 贯世明光 |
| 蓄力、姿态和档位释放 | 八荒卷云、不动玄甲、破军冲阵、大日坠炉 |
| 多段实体弹道、累计与召回 | 子母同心、六曜藏锋、六印回锋、回天飞盾 |
| 碰撞安全位移、减速和形态交替 | 逐风散阵、开门纳妖 |
| 世界附着、周期伤害与传播 | 风眼留痕、火种燎原、焚野成海、落塔镇岳 |
| 终态层数与下一击替换 | 九重浮屠 |

## 本批范围与验收

- `alternating_refraction` 冻结主目标枢纽，按距离和 ID 排序可从枢纽以精确弹道视线接触的副目标。副目标按此顺序轮转，段序为主目标、副目标、返回主目标。上限包含首段；有合法副目标才能开始往返。每个身份的首次接触使用该角色的基础系数，后续计划接触对该身份的上一系数应用配置衰减，逐次向下取整并保留配置下限。
- `target_burst` 冻结主目标接触中心，只选其范围内通过精确弹道视线的不同副目标。按距离和 ID 截断，上限包含主目标。每个副目标只处理一次，不产生后续段。
- 主目标首段成功接触后才启动后续段。每段重验来源及目标身份；失效的副目标跳过，与其对应的返段也跳过，失效的返程枢纽终止后续往返。段的独立闪避和伤害裁决沿用直接命中。公开段序只描述实际进入裁决的段，序号从 0 开始且连续。受保护、退场和伤害收益沿用原动作终态。一次动作无论多少段，回灵、动作吸血和冷却只结算一次。

| 验收项 | 预期 |
|---|---|
| 万镜回廊原参数 | 范围 360，半径 230，至多 8 段，主副系数 9000/2200，逐目标重复衰减 8500，最低 1400。验证多人、单体、等距、遮挡和枢纽失效。 |
| 照骨碎光原参数 | 半径 140，最多 6 个不同目标，主副系数 12000/3500。中心使用主目标接触点，边界及遮挡按原生规则，爆破不递归。 |
| 动作与发布 | 两种器型同局并保持本人 profile、同一步段序、独立目标伤害、同动作一次回灵与冷却。命中和结束事件关联同一计划，旧输入和旧事件省略新字段。 |
| 可靠性 | 试图混用单次折射和新形态、越界段数、非法倍率和未知参数时冷载入拒绝。分别验证 Rust、适配层和交付包普通 Node 宿主。 |
