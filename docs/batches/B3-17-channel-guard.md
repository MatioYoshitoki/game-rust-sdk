# B3-17 灵流镇守与灵脉洞窟闭环

2026-11-04。C01～C05 受控验收通过。[执行记录](../evidence/B3-17-channel-guard-2026-11-04.md)

沿用限时站位的开始、冻结、判定和取消流程。配置可为固定点位指定完成后将其移出轮转的侧路，并选择成功时按最大灵力比例回复。点位仍按原数组顺序循环。开始读条时冻结点位、截止时刻和效果数值。读条中完成侧路，当前读条照常判定，从下一次选点起跳过已稳定点位。同一遭遇轮次继续从上次点位之后选取，整组脱战复位后从首个可用点位开始。

灵脉洞窟采用资料包的炉心主流、晶心支流、暗河支流，充能间隔 6.5 秒，读条 3 秒，半径 80。晶心廊和暗河潭分别稳定晶心支流和暗河支流，炉心主流始终可用。截止时角色中心在当轮圆内即阻止脉冲并回复最大灵力的 12%，回复按整数向下取整并受灵力上限约束。站在圈外时由镇炉傀触发一次攻击力 0.8 倍的脉冲，走现有伤害、死亡与结算流程。退出终局范围、保护、镇炉傀死亡或终局关闭清理未决读条。

使用来源等距地形，在来源锚点附近的可达空地布置灵眼和单人验证敌群。用已有普通攻击、功法、调谐、解封、拾取和撤离完成全程。H5 显示当前灵眼、剩余时间和已稳定数量，并用原导航输入前往点位。
