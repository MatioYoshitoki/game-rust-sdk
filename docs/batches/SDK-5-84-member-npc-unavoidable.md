# SDK-5-84 NPC 弹道不可闪避

对应 R3.3/M04 和原行为规格 §4.2。目标 SDK 0.86.0、机制 101、schema 7、协议 6。多人 PvE 的基础怪物和附加模板可在 `combat.projectile` 配置可选布尔值 `unavoidable`。省略与 `false` 使用原闪避判定，`true` 令该 NPC 弹道跳过闪避。显式配置该字段需要机制 101。

NPC 弹道释放时冻结该标记，接触时按目标资格与保护 → 伤害免疫 → 闪避策略 → 伤害、护盾和附带状态的顺序结算。不可闪避会跳过闪避随机抽取，仍受伤害免疫、碰撞与墙体、来源和目标资格约束。技能费用、冷却和弹道寿命沿用原流程。该切片通过 NPC 普通弹道投放此通用接触策略。

Node 和 H5 固定种子样例按四次 NPC 弹道观察基础伤害、成员闪避增益、成员伤害免疫及免疫到期。四人配置 `true`，八人配置 `false`，成员增益数值和抽取种子一致。

| ID | 验收 |
|---|---|
| UD01 | 基础怪物与附加模板接受布尔值；省略与 `false` 等价；拒绝旧机制、空值、数值、字符串及不支持的投放位置。 |
| UD02 | 验证释放时冻结不可闪避策略，跳过闪避随机数；实际接触受资格、墙挡和伤害免疫约束，保留护盾及附带状态顺序。 |
| UD03 | 验证普通可闪避弹道和旧机制的概率流、费用、冷却、来源失效及关闭清理。 |
| UD04 | Node 和 H5 四人房四发伤害为 66 → 66 → 0 → 66，八人房为 66 → 0 → 0 → 66，所有成员各准入并结算一次。 |
| UD05 | 同一交付包通过仓库外空缓存离线接入、机制 100 定时伤害免疫复验及 Rust 和 Node 回归。 |
