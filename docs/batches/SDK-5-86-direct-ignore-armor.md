# SDK-5-86 直接攻击忽略护甲

对应 R3.3/M04 和原行为规格 §4.2 第 6 项。目标 SDK 0.88.0、机制 103、schema 7、协议 6。多人 PvE 的成员 `basic`、六种伤害技能和 NPC `combat.projectile` 支持可选布尔字段 `ignore_armor`。省略与 `false` 使用原 DEF 减伤，`true` 在该次直接攻击结算时令护甲项为零。显式配置需要机制 103。

成员弹道、区域计划和 NPC 弹道在物化时冻结策略。接触顺序为资格与保护、伤害免疫、闪避、基础伤害乘区、护甲项、暴击与取整、受伤减伤、护盾、HP 和附带状态。忽略护甲时仍按这一顺序处理其他乘区与效果。穿透及区域重复接触复用冻结策略，周期伤害按原周期配置结算。

Node 和 H5 四人、八人房均先使用普通护甲结算的普攻，再施放方向弹道。四人技能开启忽略护甲，八人关闭。数值、技能 ID 和费用从各自配置初始化。

| ID | 验收 |
|---|---|
| IA01 | 普攻、六种伤害技能和基础/附加 NPC 弹道接受布尔值并按原义序列化，拒绝旧机制、空值和非布尔及其他投放位置。 |
| IA02 | 复验原 `defense-true` 向量，验证成员弹道与区域的策略冻结、暴击/取整、护盾、命中附带与重复接触预算。 |
| IA03 | NPC 弹道实际释放后冻结策略；验证免疫、闪避、受伤减伤、护盾及扣血顺序，省略/关闭及旧机制兼容。 |
| IA04 | Node 和 H5 四人房普攻与技能伤害为 66 → 100，八人房为 66 → 66，每位成员各准入并结算一次，技能费用只扣一次。 |
| IA05 | 同一交付包通过仓库外空缓存离线接入、机制 102 成员不可闪避复验及 Rust 和 Node 回归；历史数值边界逐项保持。 |
