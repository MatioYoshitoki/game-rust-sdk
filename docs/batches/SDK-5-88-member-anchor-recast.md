# 成员施法锚点再施放

本批归 R3.4。原技能运行时的 `relocate` 在有限窗口内迁移同一个实例。沿用固定施法锚点和 World 时钟，宿主可为每个布置技能配置迁移窗口、最多次数和每次灵力费用。

| 验收项 | 预期 |
|---|---|
| 配置 | `combat_rules.member_cast_anchors[skill_id].recast` 可省略。配置时要求 `window_ms` 是固定步的整数倍，至少一固定步，至多锚点寿命和 30000ms 中较小的值。`max_count` 为 1～8，`spirit_cost` 遵守宿主的资源上限。 |
| 准入 | `recast_anchor` 携带锚点 ID、原布置动作 ID、下一次 `recast_index` 和新世界坐标。只允许同一代次的存活所有者在窗口内使用，且须仍装备原布置技能。前摇、引导、后摇、撤离读条及状态门禁继续生效。 |
| 几何 | 原点须在锚点使用距离与视线内，新点沿用布置技能的合法落点、射程及视线规则。迁移瞬间生效，新点须与原点不同。 |
| 结算 | 成功只扣本次灵力，保留实例 ID、原动作、到期时间和原冷却。连续序号每个只生效一次。失败保留位置、次数和灵力。后续区域和弹道读取新位置，已经提交的效果保留各自的位置。 |
| 发布 | 公开 `areas` 保留迁移窗口、使用次数及原动作，同一 ID 只有次数前进时才能改变中心。成功发布一次 `anchor_relocated`。同 World 重连恢复当前点和次数，窗口关闭后锚点仍可按原寿命用于后续施法。 |
| 回收 | 到期、原锚点被替换、来源死亡或退场及关局后旧输入无法执行。双方退场后完成原结算。 |

本批只迁移点锚。后续批次支持[跟随领域](SDK-5-88-anchor-following-fields.md)及[点锚返回与主动结束](SDK-5-88-anchor-return-and-end.md)。生产地图几何另行验收。
