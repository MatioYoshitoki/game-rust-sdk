# SDK-5-10 严格敌方单位目标最小闭环

2026-11-04；**先冻结需求与验收，现已实现并通过受控验收**。目标crate0.13.0、机制28；schema4/协议3、单人PVE、最多两个玩家技能。

## 配置、身份与输入

新增玩家mechanism=unit_projectile，字段与原projectile一致：ID/成本/前后摇/CD/倍率/射程/弹速/半径，以及可选已有self/hit状态绑定。主/副槽均可使用，仍最多2技能，与原方向弹道和self_status共用现有事务。新机制仅28/schema4/PVE，数值、唯一ID、引用/绑定/未知字段严格沿原约束；目标策略不靠技能名/地图名分支。

新增CastUnit：`{"kind":"cast_unit","skill_id":"...","target":{"id":"...","generation":1}}`。target必须含Rust视图给出的ID与代次（非空有效ID≤128字节、generation为非零u32）；禁止方向、坐标、敌我、金额或其它多余字段。匹配当前World，不接受玩家自身或未发布/失效怪物。已发布怪物在本批PVE中均为敌方，友军/阵营/多人另批。

机制28 MonsterView增加可省略unit_target（仅当前存活、启用且不在归途/复位倒计时中的敌人提供）；代次沿现有状态实体代次，归位/实际复位后递增，不因Boss普通阶段切换而改变。旧1～27不输出新字段。ID相同但代次不同视为另一个目标，客户端不得自动绑定新代。

在动作可接纳时：旧机制的新意图UNSUPPORTED，未知技能UNSUPPORTED，意图/技能类型不匹配INVALID_MESSAGE；目标不存在/死亡/未启用/归途/复位中/代次不匹配/非敌方为新增INVALID_TARGET，超射程或视线阻挡为OUT_OF_RANGE。非法结构/ID/零代次为INVALID_MESSAGE。准备/后摇/CD、保护/ready和资源沿原门禁，多个错误同时存在时沿验证顺序返回，不另定优先级。

## 接受、提交与命中

接受与提交两次检查同一ID/代次、存活/敌方资格、中心距离≤配置range（等于合法）及既有Grid视线；不自动替换目标，不自动导航/追击。接受时冻结技能定义/参数、目标身份和遭遇轮次；提交时取目标与施法者的合法当前位置，计算并冻结方向。重合导致方向无效按OUT_OF_RANGE拒绝。

提交重验失败移除准备、发ActionRejected对应原因，不扣费、不开CD、不授予self状态或创建弹道。当前灵力与整组self状态容量仍原子预检，成功才沿原顺序施加self状态、扣自己成本、开启独立CD和共享后摇，冻结有效ATK及已有命中绑定后创建严格目标弹道。0前摇仍在下一固定步提交。

提交后不追踪目标、不重新瞄准，不因目标移动换人；沿原速度/射程预算/半径/TTL和地形弹道阻挡执行。首个物理接触若为原ID/代次目标，才执行原伤害及合法hit状态；其他存活单位先接触则只消耗弹道，不伤害或施加状态，不穿透。地形与单位同距仍地形优先，单位同距沿原稳定索引顺序。目标死亡/归途/换代/实际复位使在途严格弹道在下一步失效，不迁移到新代或其他单位，不退款/回滚CD或已生效状态。方向弹道原首接触行为保持。

共享准备/后摇、独立CD和灵力、未提交取消/后台/死亡/终局/关闭/实际换轮免扣、提交后取消不退款均沿原机制。切换UI选择不修改已接受动作或在途弹道；现有目标代次失效只允许重新显式选择。重复输入/回执不重复提交或扣费。

## 输出与接入

机制28的pending_action和单位技能ActionCommitted可省略增加unit_target，准确记录冻结目标；原技能布尔/成本、player_skills与主技能CD别名保持。旧1～27配置、输出和动作语义不变；公开Action/Error枚举与视图可选字段为Rust源码变更，消费方须适配，六类Client/协议1～3/资产与恢复schema保持。

H5提供显式目标列表与等距地图点击/触摸选择、高亮、所选身份展示；无选择时单位按钮禁用并提示，单位失效清选择而不偷偷换代/换人。Node参考按已发布身份提交意图。两套包外配置改变ID/数值/绑定并交换主副位置，验证第二个非默认目标的实际命中、self技能组合、两名敌人击杀/拾取/双终局。客户端不计算命中/伤害/成本/CD或补造身份。

重连保留同World代次、已提交CD/后摇/状态，准备沿原连接策略取消；旧连接拒绝。进程重启只履行原冻结责任，不恢复World/准备/在途弹道/临时目标或按新配置重算旧金额；Closed展示移除临时目标引用。

本批不含友军目标、单位瞬时治疗/效果、追踪弹道、穿透/多目标、地面目标、更多技能槽、引导/蓄力/再施放、HP成本、多技能AI、多人或完整技能目录；D-03/D-05及生产门禁保持。
