# SDK-5-59 自身持续治疗溢出转护盾

对应 R3.3/M04 及原需求 §4.3。目标 SDK 0.61.0、机制 76、schema 7、协议 6。本批将多人 PvE 成员自身的周期治疗（HOT）作为第二个显式转换入口。可在 `pve.status_definitions` 的 `periodic_heal` 定义上配置 `overheal_shield`，以 `status_id` 引用 `refresh` 策略的吸收盾，以 `conversion_bps` 配置 1～10000 万分比。成员可沿用技能自身提交或道具自身状态施加 HOT。

每跳按执行时有效的受治疗倍率调整冻结的基础量，先补当前气血缺口，再将溢出按比例向下取整。护盾新增量受单盾与总盾上限裁剪。实际增加时保留旧余额并刷新同一护盾实例。零新增时保留原期限。处于保护或已失效的 HOT 沿用原有跳过规则。有可授盾量但状态槽已满时，保留该跳实际气血回复，并只拒绝转换盾。

协议 6 继续以本人 `periodic_heal_tick` 记录实际气血回复，以 `shield_granted` 记录申请量和实授量。护盾沿用吸收、到期和清理规则。

| ID | 验收 |
|---|---|
| HT01 | 机制 76 接受显式成员 HOT 转换配置。旧机制、错误盾引用、非法比例、非 HOT 定义和 NPC 绑定均拒绝。 |
| HT02 | Rust 验证受治疗倍率后的溢出、取整、气血优先、护盾上限、余额保留和零新增时的期限。 |
| HT03 | 验证保护跳过、槽位不足保留本跳气血回复、本人事件隔离和护盾到期。 |
| HT04 | 四人、八人房在 Node 和 H5 中跑通自身施法、连续三跳、授盾到期和退出结算。四人房气血实回 0/0/0、实授盾 50/50/0。八人房气血实回 100/60/0、实授盾 0/20/50。 |
| HT05 | 同一发布包通过仓库外离线接入、机制 75 用药转盾兼容复验、Rust 和 Node 回归。 |
