# SDK-5-52 多人成员持续治疗倍率

对应 R3.3/M04。目标 SDK 0.54.0、机制 69、schema 7、协议 6。同一多人 PvE World 内，成员对自己的 HOT 可受配置化 `healing_received` 状态影响。成员自身技能提交和成功使用恢复道具可施加该状态。沿用已有的 `timed_attribute_modifier`、`refresh`/`ignore` 和来源分组，强度为 −10000～100000 bps。首批覆盖自身 HOT，品质覆盖、敌对命中施加、队友治疗和 NPC 治疗留待各自验收。

每跳沿用施加时冻结的 `raw_heal`，在 `executed_at_ms` 读取目标仍有效的倍率。倍率等于 `max(0, 10000 + 有效修正之和)`。先用宽整数计算并向下取整，再按当前气血缺口截断。状态截止时起失效，迟到的跳按执行时状态结算。零倍率、满血和保护跳过的实际恢复为 0。已有死亡清理和 DOT 优先级继续适用。

恢复道具的即时回复沿用原公式，成功后施加的状态供后续 HOT 跳使用。协议形状沿用 `periodic_heal_tick` 的基础量和实际恢复量，只按既有权限发给本人。机制 68 多人配置继续拒绝受治疗状态，已接入的 HOT 和减伤行为沿用原规则。
