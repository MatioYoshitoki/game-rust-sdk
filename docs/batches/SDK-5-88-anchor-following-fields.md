# 跟随施法锚点的成员领域

本批归 R3.4。宿主在锚点的 `following_field_skill_ids` 选择跟随的圆形持续领域。该列表必须是 `consumer_skill_ids` 的无重复子集。省略配置时，锚点施法只在提交时读取坐标。普通地面施法仍固定在提交落点。

| 验收项 | 预期 |
|---|---|
| 布置 | 用 `cast_at_anchor` 提交已配置的 `ground_field`。复用原费用、冷却、容量和接受与提交重验。领域绑定同一成员代次的具体锚点 ID。 |
| 跟随 | 锚点成功迁移时，绑定领域的中心同时移动，预警期与活跃期规则一致。领域保持原 ID、来源、预警、周期、到期和命中预算。同一步没有额外跳数。 |
| 结算 | 每跳按当步的新中心判定范围和地形遮挡，沿用技能伤害、命中历史和重复接触间隔。迁移前后跨同一目标的预算连续累计。 |
| 回收 | 锚点到期或被替换时回收绑定领域并发布 `anchor_invalid`。到期固定步先回收再处理领域命中。来源死亡、离场及关局沿用原区域回收。领域自身到期或耗尽时，锚点仍可继续使用。 |
| 发布 | 协议 6 在 `areas` 的绑定领域上发布 `attached_anchor_id`。快照和增量校验同 ID 锚点、来源和中心。重连恢复现有位置、跳数及命中历史，离场视图省略其他成员的跟随领域。 |

验收使用通用宿主配置、两名成员和两个敌对目标。点锚返回与主动结束见[后续批次](SDK-5-88-anchor-return-and-end.md)。生产地图几何另行验收。
