# 回岁长息主动阶段配置验收

本组继续归 DELIVERY-01。将原技能 `suiyue-ruge` 的五个主动阶段绑定到同一 SDK 技能。使用已有可信熟练阶段、HOT、状态拦截、净化、治疗余量转灵力和到期恢复。

把样例的 `skill` 加入技能目录，`status_definitions` 并入 PvE 状态表，`combat_rules` 按表合并。宿主将可信阶段索引 0～4 写入座位的 `combat_build.powers["suiyue-ruge"].mastery`，并选用具有五个阶段的功法威力模型。初始灵力和宿主费用上限须覆盖原技能费用。新减益必须在宿主的状态政策表登记为可驱散减益，才参与拦截与净化。 [配置样例](../../examples/combat-host/source-suiyue-ruge.json)

| 验收项 | 预期 |
|---|---|
| 施法 | 自身瞬发，提交支付 5000000 灵力，冷却 60000 ms，后摇 80 ms，按原配置允许移动及显式动作取消后摇。重复请求只产生一次提交与扣费。 |
| 入门与熟练 | 入门 10000 ms，其余阶段 12000 ms。每个有效周期按持有者实时最大值恢复 5% 生命和 5% 灵力。 |
| 减益与精通 | 活跃期间阻止可驱散减益的新增或刷新。精通起每跳清除最多一份本次状态施加以来的可驱散减益。自然结束按清理上限处理仍存续的可驱散减益。 |
| 大成 | 每跳开始时满血，按本次有效治疗余量的 50% 额外恢复灵力。基础回灵与转换分别验证。 |
| 圆满 | 自然结束时恢复各自最大值的 10%，上限按实际缺口及规则裁剪。退出或关局只回收。 |
| 多人接入 | 同一配置让不同成员按可信阶段选中各自状态。Rust 与 Node/H5 观察权威周期、状态、末端资源、重连及独立结算。 |

源资料给出 1 秒周期和持续时间，未单独指定周期恰与自然到期重合时的执行顺序。本次按 SDK 的现有截止规则验收，周期只在截止前执行，分别为 9 跳和 11 跳。同刻末跳保留为原规则复核项。熟练经验到阶段的推导、圆满常驻属性与真意按各自工作包继续。
