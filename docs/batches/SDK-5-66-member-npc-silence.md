# SDK-5-66 NPC 弹道沉默

对应 R3.2/M03/M04 及原行为规格 §4.4、§5.1。目标 SDK 0.68.0、机制 83、schema 7、协议 6。新增 `timed_control` 状态及 `silence` 标识，普通 PvE NPC 可通过弹道的 `on_hit_target_statuses` 配置。沉默时间用 `duration_ms` 配置，实例按来源分组并采用 `refresh`。有效命中存活成员后尝试施加，沿用状态容量、保护、到期和双方退场清理。

施加成功时取消目标未提交的主动技能及技能排队，结束正在引导的技能，停止后续引导费用。已经发生的扣费、冷却和在途弹道继续按原规则。沉默期间，主动技能、蓄力更新或释放、弹道再施放被拒绝。移动、普攻、拾取和离场继续走原规则。到达截止时刻后按原资格恢复施法。只有目标私有快照和状态事件含沉默。

本批关闭固定时长的沉默切片。控制免疫、缩时、驱散和其它控制类型按各自规格另行验收。

| ID | 验收 |
|---|---|
| SI01 | 机制 83 接受来源分组的 NPC 弹道沉默，拒绝旧机制、非法状态策略和玩家／道具绑定。 |
| SI02 | 有效命中后取消未提交主动技能与技能排队，结束引导。拒绝和打断保持未支付费用及未建立的冷却，已提交责任按原规则。 |
| SI03 | 验证到期恢复、保护或容量不足不施加、来源退出清理。验证移动、普攻和同房其他成员不被沉默门禁拦截。 |
| SI04 | Node 和 H5 在四人、八人房验证 NPC 弹道命中、前摇被打断、沉默期保留非技能操作、到期恢复施法和退出结算。 |
| SI05 | 同一交付包通过仓库外空缓存离线接入、机制 82 友方 HOT 转盾兼容复验、Rust 和 Node 回归。 |
