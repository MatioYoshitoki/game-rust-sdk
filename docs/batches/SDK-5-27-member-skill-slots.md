# SDK-5-27 配置化多技能槽

2026-11-05；实现前冻结 MS01～MS12。起点0.28.0/协议6/schema7/机制43；目标0.29.0/协议6/schema7/机制44。对应R3.1/M02的更多技能槽切片：固定1～8必需成员PVE，配置决定1～8个技能，复用现有单准备/共享后摇、按技能ID独立CD/费用、区域/弹道/状态与成员生命周期。本批不添加地图内容或新的伤害、目标、轨迹机制。

## 配置与事务

沿skill主技能＋additional_skills数组，实际槽数=1+数组长度，顺序由配置冻结；不另加可与数组冲突的容量数值。机制44/schema7允许数组0～7项（可省略或显式空），SDK工程上限8；旧1～43仍保持最多两技能和原字段存在规则。每项必须完整有类型，ID全局唯一，任意末槽的非法机制、数值、状态绑定及预算都在任何I/O前拒绝。复用注册的projectile/unit_projectile/self_status/ground_circle/ground_field/line_field/piercing_projectile，不增加通用method/args或客户端数值覆盖。

配置预检与实际结构校验显式传递版本对应的槽数上限，不能靠裁掉末槽或降级配置绕过检查；原始JSON/hash和旧配置不修改。全部技能的接触、历史与输出工程预算取真实全表的最坏值，仍服从共享区域/弹道/状态容量，增加槽数不增加并发槽或预算。

每个成员按技能ID记录独立CD，所有技能共用本人灵力、一个准备动作及同一后摇。准备中不能切技能替换/并行排队，后摇中换技能不能缩短约束；取消/后台/重连中断未提交动作时无扣费/CD/自授状态。移动沿原规则保留准备，在提交时重验实际位置，不额外付费或重置CD。提交前重验真实目标/落点/起点、成本、整组状态与全World计划容量，失败原子；成功仅该技能付费/CD一次，其他技能不变，普攻有独立CD但仍共享准备/后摇。已有计划存续期间可在合法时刻施放其他槽，遵守原全局容量与实际来源规则。

同World重连保持全部已提交CD、后摇和原计划预算/期限，不重授状态或返还成本；旧连接拒绝。一人settling/退出/死亡清本人未提交动作及已提交计划/状态，不等金融、不误删同伴。Close/绝对终局和金融恢复规则沿原契约；重启只恢复Closed金融责任，不恢复技能CD/World/计划/基线。

## 发布与接入

沿PrivateMemberView.player_skills数组：严格按配置顺序发布真实skill_id/ready_at_ms，未提交为0。pending_action.skill_id与本人ActionCommitted沿原私有投影；公共成员不增加技能列表/CD/成本。full/delta仍完整替换own私有视图，全部CD、pending与后摇原子重建；无新协议字段、Action或Client方法。Rust/JS解码器拒绝超过8、重复/非法ID、非法时间及不在列表的准备技能，坏帧不污染缓存，旧合法输出保持。公开机制能力描述保留旧两槽声明，另增机制44多槽能力和上限。

两套新4槽/4成员、8槽/8成员外部配置；全部数值/绑定只在配置初始化。Node普通宿主实际施放每槽，再经主攻击完成战斗/共享拾取/独立终局；H5提供由配置生成的技能选择器，按所选机制提交现有有类型意图，显示Rust返回的逐槽CD/准备/后摇。选择器和公共意图助手不判断命中、扣费或伤害。参考探测可向空地施放区域/方向技能；严格单位槽须用真实发布身份，自身槽须授予真实状态，最终收益仍由真实战斗产生。

独立4216预览、4217浏览器验收、4218包外只读端口/账本；不修改既有预览。槽位仅按同一冻结配置提供给各成员，本批不支持局中换装/重排/解锁或按成员动态不同配置。
