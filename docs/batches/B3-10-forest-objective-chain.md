# B3-10 森林单人主目标链与调谐消耗

日期：2026-11-03。状态：M01～M08受控验收通过；基线B3-9为395项，新增40项，最终435项唯一Rust、15项浏览器/进程和18组回归通过。

## 本批闭环

迷雾森林单人路线：湿地节点 → 遗迹旧殿 → 圣所两波战斗/阶段守将 → 全部目标完成 → 前往藏匣调谐 → 显式解封/开箱 → 落地拾取 → 撤离或死亡 → 原子结算。允许中途退出，只结算实际战果与背包；完成地图目标不强制撤离，也不直接发奖。

本批把已实现战斗机制组合成完整单人主目标链，不签收原版森林全部战斗内容。地图、节点名称/原点、火灵石×2/2000ms调谐和圣所奖池取自不可变来源；节点顺序、合法点位校正、使用现有怪物/阶段/圆形技能的组合明确属于本批路线配置。原版支援次数/反制窗口/特殊重击、全部原怪物被动、贡献/优先权和多人另批，不用普通技能冒充已支持的原特殊技能。

## 配置与规则

schema2、mechanism_version=9。可选 `encounters[].requires` 为前置遭遇ID数组，全部完成才允许按原位置条件触发。加载拒绝未知/重复/自身/环引用，支持前向引用；每局状态单向推进。前置完成当步不递归触发后继，下一合法模拟步可触发。无字段保持旧行为和RNG。

可选 `pve.map_objective={id,name,required_encounter_ids,reward_chest_id,attune_duration_ms,cost:{item_id,quantity}}`，每局一个，所有字段显式初始化；目标非空且引用合法/无重复，覆盖其依赖闭包；奖励箱存在，成本物品已注册。时长step_ms～60000且不超过terminal_ms，数量0～1000000，ID/名称非空无控制字符≤64字节。该奖励箱本局只开一次，不重生；其他箱沿原规则。

公开输入 `attune_objective{objective_id,expected_revision}`、`cancel_attunement{}`。开始需Active/存活/前台ready/无保护、目标完成、当前背包修订、材料足够、在奖励箱交互距离且有通路、无施法/撤离/破解/其它调谐。开始不扣材料，停止导航/移动；重复开始拒绝。读条期间禁止攻击/施法/拾取/撤离/开箱。移动/导航、正伤害、取消、后台/断线/接管、死亡/关闭中断并清空读条，不扣材料。Stop不取消。到期按原位置/资格/材料重新验证后，原子扣材料、背包修订+1、记录一次调谐完成；之后不会重复扣费，不因刷新恢复或重复请求重做。免费调谐也记完成并更新修订。

调谐到期在本步战斗伤害后判定，正伤害先中断。完成后仍显式破解/开启/拾取；满背包/地面满不退已成功的调谐成本，也不重复扣。失败开箱恢复RNG。保护中逻辑时间沿旧契约继续，恢复不复活已取消的读条。终局与服务重启不恢复战斗/读条；未冻结终局仍只补原入场。

结算新增可选 `map_progress`：完成遭遇ID（排序去重）、attuned、reward_opened、consumed物品列表。旧能力禁止该字段，新地图配置必须带。消耗由原配置与attuned精确推导，完成集合须依赖闭合且击杀摘要足以支撑对应指定目标；开箱必先调谐。逐物品 `入场+拾取=保留+掉落+消耗`，ItemSettlement.looted保留累计拾取含已消耗量；死亡只对剩余背包抽格。恢复按旧raw/hash核对原成本/数量/正文/operationId，不按新配置重算，不返已冻结消耗。Node只提交Rust算出的保留资产，H5只展示权威状态。
