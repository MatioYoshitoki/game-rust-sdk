# 友方自选主目标与治疗叠纹

本批属于 DELIVERY-01。宿主可以为即时友方技能开放本人作为主目标，并为按阶段配置的治疗附加来源隔离的叠层状态。继续使用 `cast_unit`、原预约及状态事件。客户端根据公开配置显示本人选项，并校验待提交目标与实体代次。

| 验收项 | 预期 |
|---|---|
| 自选主目标 | 青芽诀、青芽续生、万木归元、万木长春按原 targeting 表开放本人。配置开启才接收显式本人实体，确认、取消、重连与提交沿用原预约及扣费。范围治疗只计算一次主目标。 |
| 愈纹 | 万木归元正常提交加一层，万木长春加两层。同一来源、持有者和状态 ID 刷新 24 秒，上限五层。SDK 配置可选择施法者或受疗者，层数写入原生状态并受原容量、封禁及退出清理约束。 |
| 满层释放 | 可选恢复公式在到达上限时消费整份有效愈纹，对同局有效成员各执行一次恢复。通过原生状态消费和治疗事件验证，失败或重复输入不会补发。缺少正式数值时在验收中显式注入测试公式。 |
| 进阶护盾 | 万木长春绑定原技能表的费用、冷却和直接治疗公式。沿用已有溢出盾配置入口；生产盾上限、时长和转换比例待源规则补齐，以测试配置验证可执行。 |

愈纹的两处归属记录分别指向受疗者和施法者。样例暂用施法因子标注的受疗者，两种都保留验收。正式满层恢复数值、进阶盾参数和常驻成长仍独立跟踪。
