# 装备实例解析与局内换装

本批归 R3.4。宿主从已认证账户读取装备实例，负责所有权、养成和正式库存事务。SDK 读取对局冻结的 `combat_rules.weapon_catalog`，解析模型、家族与器型，并执行对应普攻。入场与换装均走可信宿主入口。

| 验收项 | 预期 |
|---|---|
| 配置与实例 | 模型绑定家族，家族绑定基础普攻和允许的器型。配置引用在加载期验证。无器型、未知器型或跨家族器型使用基础普攻，快照只给出实际器型。未知模型拒绝，卸下武器后用场景默认普攻。旧席位仍可直接选普攻配置。 |
| 换装提交 | 宿主提供成员身份、代次、操作 ID 和预期修订号。相同操作重试返回原回执，复用 ID 改内容或修订过期均拒绝。一个实例同一时刻只可装备在一个席位。玩家输入无换装命令。 |
| 动作边界 | 换装取消本人的蓄力、追击、排队普攻及未释放普攻，结束开放式射线，保留移动意图、主动功法与已经产生的冷却。已释放且仍在结算的普攻阻止换装，宿主可待终态后重试。已脱离普攻动作的持续领域保留释放时策略。换实例清理器型专属进度及自身浮屠层。 |
| 发布与恢复 | 本人收到修订号、有效装备与普攻配置，另一成员配置和操作不受影响。同 World 重连重建当前装备。进程恢复只保留财务责任与已接受操作回执，拒绝新战斗变更。 |

本批用两席位和原器型 ID 验证，从入场解析、真实出招、换装到重连及退出。渡劫风刃的区域进入和强制位移继续按独立世界效果验收。

机制 105 的多人场景启用通用战斗配置时，可注册最多 32 个状态定义，让完整器型表与普通功法共用场景。每实体及全 World 的活跃状态容量继续按原预算校验。
