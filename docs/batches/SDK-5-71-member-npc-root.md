# SDK-5-71 NPC 弹道定身

对应 R3.2/M03/M04、原行为规格 §4.4 和原战斗设计中的权威定身语义。目标 SDK 0.73.0、机制 88、schema 7、协议 6。NPC 弹道通过命中绑定施加 `timed_control / root`。时长由配置初始化，来源独立，同源刷新。伤害沿用现有命中链。

定身命中时清空移动方向和导航路径，取消正在追击的普攻。有效期间拒绝方向移动、寻路和需要位移的普攻追击，并停止固定步位移。原地普攻、主动技能、停止、用道具和其他非位移操作仍按各自规则处理。到期或净化后可接受新的移动指令，原路径和追击不自动恢复。

定身和沉默共用定时免疫、首控免疫、时长减免的命中顺序。同一命中的多个控制最多消费一次首控机会。机制 88 起，`cleanse_self_statuses` 可显式引用定身定义，沿用同一个库存事务。状态归属仍为目标私有。这个切片覆盖步行和普攻追击，后续位移技能按自身规格定义与定身的交互。

| ID | 验收 |
|---|---|
| RT01 | 机制 88 接受合法 NPC 命中定身及显式净化引用，拒绝旧机制、非法字段和其他绑定。 |
| RT02 | 定身清空移动与导航、取消正在追击，阻止所有本批移动入口。保留原地攻击和施法，精确到期后只执行新指令。 |
| RT03 | 验证目标私有、同源刷新、免疫优先、一次抵挡同次控制、缩时及按配置净化。 |
| RT04 | Node 与 H5 四人、八人房用真实时钟验证 NPC 命中定身、停止位移、原地动作、到期恢复和每位成员一次结算。 |
| RT05 | 同一交付包通过仓库外空缓存离线接入、机制 87 净化沉默兼容复验及 Rust 和 Node 回归。 |
