# SDK-5-25 多人线形区域计划

2026-11-05；实现前冻结 LA01～LA12。起点0.26.0/协议6/schema7/机制41；目标0.27.0/协议6/schema7/机制42。固定1～8必需成员PVE，将既有line_field接入同一World区域计划，复用SDK-5-24调度/容量/ContactBudget及SDK-5-23直接接触/伤害流程；本批不实现穿透弹道或新地图内容。

## 范围和机制

沿用cast{skill_id,direction}，仅机制42开放多人line_field；direction必须有限且非零，由Rust归一化。cast_ground/cast_unit/cast_self不能施放线形技能。接受及提交检查来源中心处于地图内、半宽足迹不与弹道阻挡或边界相交；准备中断沿原规则。提交以当时来源位置为起点、已接受方向×配置range为请求终点，用现有连续扫圆碰墙方法裁剪终点，允许裁剪成零长度胶囊，不检查地面落点或视线，不吸附、不追踪来源。宽度=2×radius，半径0.1～128、长度0.1～10000及所有比例/预警/时长/间隔/绑定/重复/容量数值只从配置初始化。

单次圆、圆形持续、线形持续共享members.area_capacity=1～8和全World历史/输出预算。提交先重验起点、成本、整组self状态、全局槽，失败不扣费/CD/授状态/创建计划；提交self绑定后冻结有效ATK。线形不创建弹道、不占弹道槽。线形及圆形持续共用同一个调度、截止排除、最多128跳、计划时刻补跑、重复预算和来源生命周期；不另写线形伤害公式。预警后等待间隔首跳，warning=0也不能在提交步伤害。

目标以当前足迹与固定胶囊接触，最近轴上点→目标的弹道遮挡有效。按轴向进度、到轴距离平方、稳定ID、代次排序，圆形排序不变；每跳上限/总成功预算/repeat=0每代一次或正数含等号沿ContactBudget。闪避不消耗预算，全盾接触仍消耗并触发原命中附带；当前位置/DEF/盾实时读取，友方、死亡、归途、不合格代次过滤。死亡归功、掉落、DOT和护盾使用统一直接接触链。

后台、移动、同World重连保持已提交几何/绝对期限/接触历史，只中断未提交准备；来源settling/死亡/Leave/撤离/断线超时立即清自己的计划，不等金融回执且不误删同伴。Close/绝对终局清全部，费用不退；重启仍仅金融Closed责任，不热恢复World/区域/基线。

## 公开接口与兼容

复用areas数组和area_started/tick/ended，新增AreaPlanKind::LineField（wire=line_field），新增可省略line:{start:[x,y],end:[x,y],width}。仅line_field必须存在且非null；旧circle/field必须省略。line.start严格等于center、width严格等于2×radius，端点有限、轴长≤10000，允许零长。旧圆形序列化完全不变；Rust结构字面量补line:None。Rust/JS原子校验未知字段、错误形状/端点/宽度/时序/历史，坏帧不污染缓存。数组存在完整替换、[]清空、省略不变，旧机制areas继续省略。协议/六类Client/金融及恢复DTO不变。公开World计划ID不暴露私有请求ID、冻结攻击/绑定/成本。

两套新配置（4席/8席、不同半宽/伤害比例及状态重复策略），新Node/H5入口复用原宿主。H5通过选择方向点和cast实际输入，按Rust发布胶囊显示预警/活动、来源/跳数/预算；前端只投影和观察，不计算命中或伤害。独立4210预览端口/账本，旧4173～4207预览保持。
