# 同刻接触与固定延迟普攻

本批属于 DELIVERY-01 与 R3.4 的交叉验收。机制 105 新增 `basic.impact`。宿主可在既有逐成员普攻配置中选择 `hitscan` 或 `fixed_delay`。投送方式与波面、穿透互斥，均沿用普攻的前摇、范围、终态回灵与冷却。原攻击输入不扩字段。

同刻接触在前摇结束的固定步完成。可配置一次折射，先锁定主目标，再从其位置按半径、精确弹道视线、距离和实体 ID 选最近的另一个敌对目标。主目标成功接触后才处理冻结的副目标。无合法副目标或主目标接触失败时只处理主目标，候选不递归也不补位。

固定延迟从成功释放开始计时。到达时重验来源、目标代次、敌对状态及冻结原点到当前目标的弹道视线。允许目标移动出原射程，延迟与距离无关。来源退场结束计划，保护或断线撤销收益资格。独立的 `basic_impacts` 全量与增量发布恢复剩余计划。事件描述释放、接触和结束。

`basic.effects.on_end_damage_self_heal_max_hp_bps` 在一次普攻确实扣过目标气血时，于终态按来源当前有效最大气血计算一次恢复，经过受治疗倍率和缺口。零实际扣血、失效、保护或退场不授予。治疗发出独立的 `heal_resolved` 事实，和既有吸血分别结算。

| 验收项 | 预期 |
|---|---|
| 镜的原参数 | 前摇 100 ms、范围 360、间隔 900 ms、主副倍率 90% 和 65%、折射半径 220。两次接触同一固定步，回灵和冷却只结算一次。 |
| 折射边界 | 等距按 ID、遮挡过滤、独苗回退、主目标闪避或免疫时不折射。副目标可位于主目标附近且超出施法者初始射程。 |
| 鼎的原参数 | 前摇 180 ms、范围 260、间隔 900 ms、伤害 78%、固定延迟 350 ms。近远目标同时钟，终态按最大气血恢复 2.5%，无实际伤害则不恢复。 |
| 生命周期 | 延迟期间可重连恢复计划。目标换代、退场或被地形遮挡时无伤害与恢复。已释放的失效计划仍结束并结算冷却。 |
| 接入 | 同一 World 可同时使用两种计划。计划不占弹道容量，旧配置省略新字段。Rust、Node/H5 解码和普通 Node 宿主验收。 |

本批覆盖镜和鼎的基础普攻。十八种命名器型、局内换装和器型专属会话仍由 R3.4 验收。
