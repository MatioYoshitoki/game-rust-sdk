# NPC 固定落点单次打击

本批归 R3.4。新增按 NPC 技能 ID 配置的固定落点单次打击，用原天雷落验收。复用固定地面领域的预警、区域容量、合法落点和接触结算。

| 验收项 | 预期 |
|---|---|
| 预警与提交 | 从 NPC 当前选敌的权威位置冻结圆心，公开预警。结构化施法配置给出 750 ms 准备，结构化投送半径为 96。提交时重验原落点、射程、视线和活体来源。准备被打断或失效时撤销预警。合法提交扣费并启动冷却一次，落空同样算一次提交。 |
| 单次结算 | 提交时按当前可战斗成员位置、角色碰撞半径及地形遮挡，选圆内最近的一人，等距按成员 ID 排序。圈内为空则落空。已选目标的伤害免疫或闪避使本次打击落空。样例开启不可闪避，成员可通过移出预警圈规避。结算后立即结束。 |
| 伤害与麻痹 | 读目标当前最大生命，取 800 基点，按减伤、盾、扣血和保命顺序结算。成功接触且原来源与目标存活时，对配置的状态组掷一次概率。样例 1500 基点，麻痹映射为 30% 减速、持续 3000 ms，沿用原状态免疫、归属、刷新及清理。 |
| 发布与恢复 | 协议 6 发布预警、一次结算和结束，状态只发给本人。预警期重连恢复同一圆心和提交时刻，完成后重连恢复已产生的有效状态。来源死亡或同 ID 换代撤销旧预警。已退场成员的冻结快照省略 NPC 区域，留场成员继续收到区域结算。 |

旧文案的 1.5 秒采用结构化生命周期覆盖。旧状态参数与“移动速度降低 30%”冲突，延续此前 D-03 按文字映射的规则。随机落点、安全区和试炼阶段编排按模式工作包验收。
