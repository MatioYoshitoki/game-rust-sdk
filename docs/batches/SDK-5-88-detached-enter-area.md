# 来源失效后的移动区域命中

本批归 R3.4，补齐已释放的移动区域在 NPC 死亡或换代后继续命中的闭环。沿用罡风刃配置、移动扫掠、命中预算和碰撞安全击退。

| 验收项 | 预期 |
|---|---|
| 生命周期 | 准备中的区域随来源失效结束。已释放区域按 `end_on_source_invalid` 决定是否结束。继续存续时保持原轨迹、施法原点、动作 ID 和来源代次，至路线终点、期限或预算用尽。 |
| 结算与归属 | 旧区域继续读取目标的最大生命、减伤、护盾和保命，按原位置裁剪击退。可闪避的区域在释放时记录原来源命中基线，失效后继续读取目标当前闪避。保护或伤害免疫拒绝接触。反击、击杀收益和需要两端活体身份的触发继续按活体规则裁决。 |
| 持续状态 | 区域可在 `retained_hit_statuses` 配置来源隔离的定时减速。施加时走共享免控、缩时、容量及刷新规则。减速保留原来源代次，按自身期限、净化和目标退场规则回收。转移和旧 NPC 命中状态绑定继续按活体来源链管理。 |
| 发布与恢复 | 命中、扣血和位移事件归旧来源。协议 6 可发布旧来源代次的区域减速，同一 World 重连重建有效减速与剩余命中预算。多席位命中、清理和退出各自独立。 |

独立存续状态只接受简单的定时减速。需要活体来源取样、触发或续跳的状态继续由原状态链管理。
