# 普攻蓄力、架盾与冲阵

本批属于 DELIVERY-01 与 R3.4。八荒卷云、不动玄甲、破军冲阵使用同一服务端普攻蓄力会话，并各自绑定配置。阵营和候选范围沿用同一 World 的 PvE 关系。

| 验收项 | 预期 |
|---|---|
| 会话与输入 | 协议 6 使用开始、释放、取消三个输入。服务端发放会话 ID，仅持有者可结束匹配会话。客户端只提交目标或方向。匹配的释放即使因目标或方向非法而失败也结束会话，旧 ID 不影响新会话。按住期间继续接收移动、导航与停止，权威位置暂停推进，结束后恢复最新意图。保护、眩晕与退场清理会话。 |
| 八荒卷云 | 释放按服务端已蓄时间选档，650/1350 ms 切档，3000 ms 封顶。三档分别为 300 范围、112° 定向波与 220/310 半径全向波，目标上限 5/8/10，主副系数 12500/11000、16500/14500、35000/32000。三档对普通怪径向击退 90，对精英和首领改为 35% 减速 1500 ms。释放时冻结档位，准入、追击与前摇重验使用该档射程。 |
| 不动玄甲 | 架盾期间减伤 50%，护盾后实际扣血的 60% 经统一伤害链反击来源。满 3000 ms 或会话终止即停止。合法释放执行一次盾击，实际扣血后授予 7% 最大生命护盾，持续 1800 ms。 |
| 破军冲阵 | 可在强化就绪时开始蓄力。250 ms 内点按距离 180，之后按时间线性插值至 3000 ms 的 450。释放冻结方向与距离，盾系前摇后沿可行走地形安全位移。只对实际路径半宽 42 内的有效敌人各结算一次，按投影距离与稳定 ID 排序，最多八个，主副系数 9000/7200。普通怪受 90 击退和 900 ms 眩晕，精英与首领只受击退。首次就绪，成功冲阵后等待 6000 ms。普通攻击入口仍可执行家族盾击。 |
| 边界与接入 | 蓄力无需灵力。扇与盾击沿用原普攻前摇、冷却与动作终态；冲阵沿用同一结算链。非法配置、过期会话、无权限目标、撞墙以及容量均有验证。Rust 和 Node/H5 验证状态投影、同局独立性及保护恢复。 |

大日坠炉的飞行体、重复灼烧与终点爆炸作为下一种投送机制接入同一蓄力会话。九重浮屠仍按独立的命中后叠层与第六击替换验收。
