# SDK-5-16 通用线形持续区域接触最小闭环

2026-11-05；先冻结需求与验收，再实现。目标crate0.19.0 / 机制34 / schema4 / 协议3 / 单人PVE。新增line_field，复用现有PlayerField调度、ContactBudget、直接命中/状态/击杀/掉落及资产责任；不按地图或技能名分支。

## 配置与提交

两槽均支持line_field，必配id、cost、windup_ms、recovery_ms、cooldown_ms、damage_bps、length、width、warning_ms、duration_ms、tick_interval_ms、contact_policy，self/hit状态绑定沿既有可选字段。length为中心线长度0.1～10000，width为完整宽度0.2～256，必须有限；其余数值、引用、周期及预算沿原严格校验（warning≤60000、duration≤60000、step≤tick≤60000、截止前1～128跳、周期目标1～32、总成功1～128、重复间隔0～60000）。仅机制≥34/schema4/PVE；null/省略必填/额外字段、speed/range/radius/目标坐标等不兼容字段拒绝，旧1～33拒绝此机制。

复用Cast{skill_id,direction}；只接受有限非零方向，接受时归一化并冻结技能/方向/轮次/参数。提交取施法者当前位置；起点须在地图且以width/2为半径满足弹道可通行足迹，接受/提交均验证，提交前移动导致非法时免扣。以冻结方向和length生成中心线，使用现有连续圆盘扫掠在首个弹道墙/边界截断，实际端点由Rust冻结；墙同距优先，退化为起点胶囊合法，起点足迹非法则拒绝。成功后固定于世界坐标，不随施法者移动/转向或外部配表变化。

线形区域与ground_circle/ground_field共享最多2份未完成区域计划；资源、self状态整组容量、区域容量全部原子预检。失败不扣费/开CD/施加self或创建计划。成功self效果后冻结直接ATK比例量，成本/CD/共享后摇只提交一次；不生成移动弹道，不周期扣费。

## 几何、时间与接触

几何为有限线段及两端圆帽的胶囊：目标当前圆形足迹与线段距离≤width/2+目标半径时才可接触，边缘/端帽等值合法；当前最近点至目标中心的弹道视线仍须畅通，不能绕墙伤害。每周期按线段投影进度、到路径距离平方、稳定ID、代次、索引排序，逐目标重验存活/启用/归途/复位/原轮次，再进入原直接命中链。

激活=提交+warning，首跳=激活+tick；仅计划时刻<截止的跳有效。按计划时间累加周期，非整步/滞后沿现有有界补跑，空区域也推进；每周期每身份最多一次。首次/重复共享contact_policy；0每身份每区域一次，正数按最新成功计划时刻+间隔给资格，等值合法；离开再入/重连不清历史，未接触的周期不补伤害，新代独立。成功含全盾0HP损失消耗周期目标数和总预算并写最新时刻；闪避/失效/墙/间隔未满不消耗或施加命中状态，继续后续候选。附带DOT/反击不重复扣预算；预算耗尽立即结束，击杀掉落仅一次。

每跳读取当前DEF/盾/闪避，提交后直接攻击量与几何/策略保持冻结。移动/CancelAction/后台保留已提交区域；准备取消免扣。死亡、终局、关闭、实际任何遭遇换轮结束全部相关计划及未来伤害/收益；每实例仅结束一次。重连保留实际线段/计划游标/预算/历史，不重施放或重扣。重启只恢复原Create/hash/金额/operation ID责任，不恢复临时战斗区域。

## 发布与接入

沿PlayerFieldStarted/Tick/Ended及PlayerFieldView，新增可省略line:{start,end,width}，仅线形区域发布；原center为start、radius为width/2，明确line决定实际胶囊。预算/最新身份时间/下一资格沿contact_policy；Started/快照均绑定实际截断端点。旧1～33圆形区域及其它输出省略line，客户端六类/协议1～3/责任schema保持，公开DTO源码消费适配新增可省略字段。

Node只发方向意图，H5点选或触摸方向、展示Rust实际线段/宽度/预警/周期/预算；不在前端筛目标、补伤害或计命中。两套包外配置（主副互换、不同数值/策略）验证一次与重复接触、真实状态/伤害/击杀掉落→拾取→撤离/死亡；纯触屏双终局、资源/共享容量/非法方向拒绝、真实历史重连、三处强杀各两次恢复。
