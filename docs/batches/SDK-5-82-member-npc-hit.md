# SDK-5-82 NPC 命中属性

对应 R3.3/M04 和原行为规格 §4.1、§4.2。目标 SDK 0.84.0、机制 99、schema 7、协议 6。多人 PvE 的基础怪物配置 `pve.stats` 和 `pve.additional_templates.*.stats` 可选配置非负整数 `hit`（0～1000000 点），省略等价于 0 点。旧机制显式配置此字段应拒绝，未知属性继续严格校验。

NPC 弹道接触和合法近战尝试在目标资格与保护检查后，共用原闪避公式，读取攻击 NPC 的 `hit` 和防守成员当前的 `dodge_chance`。有效概率为 `min(0.5, dodgeBps / (10000 + hit × 100))`。零闪避不消耗随机数，非零沿用一次闪避抽取；成功闪避时伤害、护盾消耗、近战暴击和附带状态留给成功命中。近战沿用原攻击间隔。周期伤害继续按原周期规则结算。

四人固定种子样例配置 NPC 命中 100 点，八人样例配置 50 点，成员闪避增益均为 5000 bps。相同约 29% 的抽取在四人房命中，在八人房被闪避。两组均观察增益前、有效期间和到期后的真实弹道。

| ID | 验收 |
|---|---|
| NH01 | 基础怪物与附加模板接受合法 `hit`，省略和显式零等价，拒绝旧机制、负数、小数、越界和未知属性。 |
| NH02 | 共用概率公式覆盖 50% 闪避分别遇到 100、50 点命中，资格、精确到期和实际来源隔离；读取整数上界不溢出。 |
| NH03 | 近战与弹道共用命中公式，保持近战间隔、暴击随机顺序、护盾与附带状态顺序；周期与旧机制兼容。 |
| NH04 | Node 和 H5 四人房验证三发伤害为 66 → 66 → 66，八人房为 66 → 0 → 66，所有成员各准入并结算一次。 |
| NH05 | 同一交付包通过仓库外空缓存离线接入、机制 98 成员命中加成复验及 Rust 和 Node 回归。 |
