# SDK-5-32 固定方向引导

对应 R3.1/M02 及原施法生命周期的固定时长引导。起点 SDK 0.33.0，目标 SDK 0.34.0、协议 6、schema 7、机制 49。范围为同 World 1～8 成员 PVE 的普通方向弹道。

技能可选 `channel` 对象，完整配置 `duration_ms`、`interval_ms` 和 `spirit_per_pulse`。时间须对齐固定步。持续时间至少两个间隔，上限 30000 ms。区间内最多 128 次脉冲。周期灵力为 0～1000000 整数。机制 49 允许此字段，旧机制和非法形态在加载时拒绝。普通 `cast` 可按已有固定准备进入引导。蓄力与引导组合单独验收。

接受时冻结定义与单位方向，分配 World 内不复用的引导 ID，并进入原准备槽。提交时重验灵力、位置和自身状态，原子扣初始生命与灵力、写技能冷却、应用自身状态，按提交后的攻击力冻结每发原始伤害。首次脉冲在提交后一个配置间隔，截止步只结束引导。每个到期步最多尝试一发，先重验实际起点、周期灵力和共享弹道容量，再扣周期灵力并创建普通弹道。任一门禁失败会结束引导。初始费用与已发射脉冲费用保留。

活跃期锁定位移和路径推进，接收最新移动意图，拒绝新技能、普攻与撤离读条。引导结束后使用已冻结的后摇移动策略和时长，恢复时应用最新意图。取消、后台、失联和重连清理未来脉冲。后台与连接替换清旧移动意图。离场与死亡沿原终局清本成员弹道和引导。取消与保护保留已经发射的合法弹道。

本人快照包含可选引导状态、方向、截止和下一脉冲时钟。本人事件提供每次实际脉冲费用及结束原因。客户端通过原施法与取消意图接入。连续转向、按住维持、引导结束起算冷却与周期 HP 成本各自分批验收。

| ID | 验收 |
|---|---|
| FC01 | 主槽、附加槽严格加载，时间、次数和费用边界，机制 48 蓄力与重瞄准兼容。 |

| FC04 | 引导锁定与后摇，取消、保护、重连、死亡与离场，私有投影、坏帧和多人隔离。 |
