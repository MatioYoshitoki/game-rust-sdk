# 定向与径向普攻波面

本组属于 DELIVERY-01 与 R3.4 的交叉验收。`basic.wave` 声明计划 ID、几何、速度、目标上限和主副目标伤害系数，复用原普攻的范围、前摇和间隔。方向波面使用扇形夹角，径向波面使用圆形范围。波面要求 `basic.settle_on_end`，同一份普攻配置只能选择一种投送方式。

释放时冻结原点、方向、主目标和候选名单。候选通过敌对、有效状态、几何及弹道通道校验，按主目标优先、距离、ID 稳定截断。定向按轴向投影、径向按直线距离计算到达时刻，向上取整到毫秒，至少延后 1 ms。相同到达时刻沿候选顺序执行。到达时只重验来源、目标身份和敌对资格，已承诺的几何与到达时刻保持。主副系数与释放时伤害预算一起冻结。

| 验收项 | 预期 |
|---|---|
| 原参数 | 用原扇、盾、塔数据核对几何、速度、范围、目标上限、主副系数及基础时序。 |
| 定向 | 目标按扇形与视线筛选。到达按轴向投影时间，晚入场目标不补位，目标移动也不重排已承诺的到达时间。 |
| 径向 | 周边目标按距冻结原点的距离到达。主目标优先用于候选截断，实际命中仍按到达时刻执行。 |
| 终态 | 实际扣血计入现有动作账本，启用动作吸血时最后统一吸血。成功接触只取得一次回灵资格，冷却从最后一个计划目标处理完毕开始。 |
| 失败与连接 | 目标退场或换代时跳过该目标，来源退场清除波面。保护撤销收益资格，仍沿既有规则处理已释放投送和冷却。重连全量恢复剩余计划。 |
| 公共接口 | 通过 `basic_waves` 发布在途计划及待处理目标，结束后增量清空。客户端沿用原攻击指令，波面使用自己的发布和事件，不占用飞行弹道。旧配置省略新字段。 |

本批覆盖投送和伤害系数。盾系受击后的吸收盾、塔系减伤和镇压、命名器型扩展和逐角色装备选配沿原武器工作包验收。
