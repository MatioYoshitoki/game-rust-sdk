# B3-11 支援治疗与主动命中打断

日期：2026-11-03。状态：H01～H08受控验收通过；基线B3-10为435项，新增48项，最终483项唯一Rust、27项浏览器/进程及19组回归通过。

## 本批闭环

森林原路线继续运行：湿地→遗迹→圣所前卫→Boss与支援同组→调谐→解封/开箱/拾取→撤离或死亡→冻结资产恢复。支援治疗受伤队友，玩家可在读条/引导窗口内主动攻击或施法命中支援者打断，无新增按键或“直接打断”业务接口。Rust管理目标、动作身份、时钟、治疗、成本、次数、冷却和中断，H5仅展示/提交原输入。

本批为同组有限治疗与打断机制；不交付眩晕/沉默/通用Buff、原重击/借隙反击、多人贡献、整组复位、动态湿地技能替换或全部原怪物被动。验证路线已经完成湿地，支援模板初始化采用来源削弱版治疗数值；并非运行时新增侧路切换机制。原十一配置raw/hash与无新能力时的AI随机消费保持。

## 配置与能力

schema2、mechanism_version=10，可选严格对象`additional_templates[id].support`：

| 字段 | 作用与边界 |
|---|---|
| mechanism | 固定ally_heal_channel |
| id/name | 非空、无控制字符、≤64 UTF-8字节；与本模板原弹道/自疗/范围技能ID互异 |
| range | 有限0.1～10000世界单位，施法者到治疗目标中心 |
| include_self | 显式bool |
| hp_threshold | 有限0～1，目标HP比例严格小于阈值才入选 |
| cast_chance | 有限0～1，0不启动、1必启动；无合格目标不抽概率 |
| max_casts | 0～64，按本实例成功提交次数计，0禁用 |
| windup_ms | step_ms～60000，至少一个模拟步的准备 |
| tick_interval_ms/ticks | step_ms～60000、1～64；首跳在准备结束，后续按间隔；总生命周期≤terminal_ms且≤3600000ms |
| heal_bps | 0～100000，总预算=floor(开始时目标maxHP×bps/10000)，按ticks均分余数从首跳分配 |
| cost/cooldown_ms/recovery_ms | 灵力0～1000000；正常CD1～3600000ms；后摇0～3600000ms |
| interrupt_window_ms | step_ms～完整准备/引导时长，从开始起算，含截止边界 |
| interrupt_cooldown_ms | 0～3600000ms，玩家成功打断后的全局逻辑冷却 |

全部数值显式初始化，不按模板名字判断机制；旧能力填写新字段、未知/缺字段/错误结构/类型/引用/时间预算拒绝。一个实例最多一个支援动作，与范围/原弹道/自疗及后摇互斥；原32怪物/事件预算不扩容。

## 目标与治疗时序

1. 原AI决策点先尝试支援，再沿原范围/弹道/自疗/近战回退。施法者须存活/启用/仇恨/不归位，玩家Active/前台ready且未保护，次数未耗尽、MP/CD足够、无其它动作/后摇。准备/引导期间停移动、普攻和新技能。
2. 同一encounter_id视为同组（可跨同遭遇旧/新波次）；同箱同代守护视为一组。无组静态怪只允许include_self=true时选自己，不能用空间邻近当治疗归属。同组目标须启用/存活/不归位、距离≤range且视线通过blocks_vision。按HP/maxHP最低优先，用整数交叉相乘比较，平手按稳定monster_id；include_self=false排除本人。
3. 开始固定目标实例ID/代、cast_id、本次总治疗预算与全部时点，不扣费/不减次数/不开正常CD。起点固定，不追踪移动施法者，不在目标失效后换人；阶段变化和非打断伤害不改本次参数。
4. 所有玩家弹道直接命中处理之后，再推进本步支援治疗。同一步有效打断或目标/施法者死亡先于到期治疗；每步每施法者至多一跳。首跳重验资格、目标身份/存活/归位、距离/视线和MP后，原子扣MP、成功次数+1并启动正常CD；之后不重复扣费。每跳按固定预算份额钳目标上限，0治疗也可合法提交，不复活死者、不改阶段/积分/物品。
5. 后续目标失效/离距/遮挡取消剩余跳，不重定向、不退已提交MP/CD/次数/已生效回复。目标被其它方式回满仍沿原预算钳0。完成或取消进入配置后摇，下一步才可再决策。

## 主动打断与生命周期

仅已认证Attack/Cast动作产生的首次直接弹道接触可打断；动作接受时间必须≥该支援开始时间，接触时仍处于含边界的窗口，且玩家打断CD已到。闪避/免伤不算；合法0伤害直接接触可算。旧动作/准备前发起的在途弹道、怪物攻击、普通状态写入、持续或派生效果不算。当前仅支持首次接触弹道，无新的多段/召唤机制。

成功一次移除支援动作，设置玩家全局interrupt_ready=now+配置冷却，发一次打断事件；同动作/重复输入/重复接触不再打断已结束动作。准备阶段取消未扣成本；首跳后中断只停未来治疗，不回滚既有回复/次数/CD。窗口外命中仍走原伤害，不额外中断治疗。

进入归位、成员死亡（施法者或锁定目标）、目标换代、后台/断线/接管、玩家死亡/撤离/关闭/故障均清理受影响动作；多动作取消聚合一个≤32身份事件，关闭预留独立支援取消事件。真正归位不返本实例已用次数/MP/CD；新守护代新实例重置，旧目标/旧动作不得作用于新代。重连保留同World的HP/已用次数/CD，保护取消未完成动作；进程重启只恢复资产，不重建治疗或回放回复。

## 权威展示与验收

MonsterView可选support，含技能名、总/剩余次数、正常/打断CD及可选活动cast：施法身份/目标ID、开始/提交/下跳/打断截止时间、已完成/总跳数、是否已扣费。H5显示治疗对象、读条/引导、剩余次数、连线与有效窗口；终局/保护/换代不保留活动连线。不在客户端算治疗或裁决打断。机制版本10的玩家导航在Rust内优先避让当前中途活怪；狭窄路段无法绕行时保留原接近路径，逐步实体碰撞始终生效。目的地位于目标足迹内时保留接近语义；旧版本路线不变，沿用原导航预算。事件SupportStarted/Pulse/Completed/Interrupted与聚合SupportCancelled表达真实变化。
