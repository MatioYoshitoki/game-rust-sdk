# SDK-5-55 多人自然恢复强化

对应 R3.3/M04 及原需求 §4.3。目标 SDK 0.57.0、机制 72、schema 7、协议 6。多人 PvE 可在 `pve.status_definitions` 配置 `timed_attribute_modifier` 的 `recovery_strength` 属性，并由成员技能的自身提交或恢复道具的自身绑定施加。强度为 −10000～100000 bps，重复策略支持 `refresh` 和 `ignore`，沿用来源分组。多个有效实例的修正相加，最终倍率下限为零。

每个自然恢复周期先按成员当前位置判断附近是否存在存活的敌方 NPC，再选取 `params.regen` 中的近敌或远敌比例。气血和灵力分别用当前上限乘距离比例及一次恢复倍率，向下取整后按当前缺口裁剪。状态从截止时刻起失效。自然恢复沿用 World 的周期和存活资格，保护中的存活成员仍按周期回复。该倍率的作用域为成员自然恢复，治疗倍率继续用于各自已接入的治疗效果。
