# SDK-5-74 自身技能移速加成

对应 R3.2/M03/M04 与原行为规格 §3.2、§4.4。目标 SDK 0.76.0、机制 91、schema 7、协议 6。自身技能通过 `self_status.on_commit_self_statuses` 施加 `timed_attribute_modifier / movement_haste`。配置时长和正向 `modifier_bps`（1～10000），同源刷新并保留来源身份。

Rust 从有效加速中取最强一项，从有效减速中取最强一项，在基础速度曲线之后应用 `1 + (加速 bps + 减速 bps) / 10000`。方向移动、导航、普攻追击继续共用实时预算，沿用地形、施法阶段和硬控制规则。状态生效、刷新和到期只改变步长，保持已有移动和动作。

加速为自身增益，沿用目标私有状态发布和到期、退场清理。现有控制免疫、缩时和净化继续处理敌对控制。这个切片覆盖自身技能加速和 NPC 减速的组合，其他加速来源与原内容专属叠层按各自规格接入。
