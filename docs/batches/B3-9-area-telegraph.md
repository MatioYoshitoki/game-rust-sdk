# B3-9 锁定落点的圆形范围技能与预警

日期：2026-11-03。状态：A01～A08受控验收通过。基线B3-8为353项唯一Rust；新增42项Rust/25项浏览器与进程场景，最终395项唯一Rust与17组完整回归通过。

## 最小闭环

独立b3-9场景复用普通狼/精英→阶段守将→箱子→搜刮→撤离/死亡。守将新增一种圆形范围技能：锁定玩家当时的位置→蓄力预警→到期按玩家当前位置一次判定→冷却。玩家能走出预警躲避，Rust决定落点、时点、命中、伤害、扣费与生命周期；H5仅展示权威圈/倒计时并提交原移动输入。

本批不增加持续危险区、扇形/直线、多段攻击、召唤、眩晕或通用技能图。非致死普通伤害/既有玩家技能和阶段变化不打断预警；取消来自施法者死亡、归位、玩家保护/断线、关闭或代替换。Boss完整来源被动、特殊类型倍率和多人另批。

## 配置与能力

schema仍2，mechanism_version=8增加 `additional_templates[id].area` 可选严格对象：

| 字段 | 约束/作用 |
|---|---|
| mechanism | 固定locked_circle |
| id/name | 非空、无控制字符、≤64 UTF-8字节；ID不得与本模板弹道/治疗ID重复 |
| range | 有限0.1～10000，开始时施法距离 |
| radius | 有限0.1～512，地面效果圆半径 |
| windup_ms | 整数逻辑ms，step_ms～60000，至少一个模拟步以形成预警 |
| cooldown_ms | 1～3600000，蓄力开始时起算 |
| recovery_ms | 0～3600000，判定/取消之后的动作后摇 |
| cost | u32，0～1000000，蓄力开始时扣一次 |
| damage_bps | u32，0～100000，原始伤害=floor(模板ATK×bps/10000) |
| cast_chance | 有限0～1，每次既有AI决策的独立施放概率 |
| min_phase_index | 整数1～本Boss阶段数；无boss能力的模板只允许1 |

全部字段必填，未知字段/错误结构/类型/范围/能力拒绝，null视为省略。旧九raw/hash与旧怪物AI随机序列不改变。此能力也可由静态/守护模板复用，不以名称决定行为；每实例至多一个活动预警，共用原32实例上限，不新增地面物品/积分/奖励预算。

验证配置：撼地击，range550、radius96、windup1800ms、cooldown6000ms、recovery900ms、cost12、damage20000bps、chance1、min_phase1。均为显式验证数值，不宣称复刻完整原Boss。积分仍普通10/精英30/守将100，总140，撤离127/死亡52修为。

## 时序与空间规则

1. 原AI决策到期且未保护、存活/启用、已仇恨、不归位、无弹道/治疗/范围蓄力、后摇完成时，先尝试范围技能，再沿原弹道/治疗/近战顺序回退。范围技能还需CD到期、灵力足够、当前阶段达标、距离≤range、施法者到当前玩家中心有视线。只有条件全部满足才抽本技能概率，旧无area模板不额外抽RNG。
2. 开始时固定center=当时玩家中心、started_at和resolves_at=now+windup、实例内递增cast_id；扣cost一次并设置area_ready=now+cooldown。冷却/灵力在取消、miss、归位或刷新后不返还。原两技能的成本/CD时点不变。
3. 蓄力中施法者停止移动和新近战/施法，玩家可以移动、攻击、拾取或尝试撤离。落点不追踪玩家/施法者；非致死伤害与切阶段不更改已开始的落点/半径/时点/成本/CD。到期前无范围伤害。
4. 到期所在模拟步先处理原玩家移动，再判定范围技能。以当前玩家中心到固定落点的距离≤radius+player_radius作为包含边界的足迹相交；必须同时有落点到当前玩家中心的效果通路（使用blocks_projectiles，与施法开始的blocks_vision独立）。有墙/阻挡或角色整体在圈外则miss。无视线不启动，不穿效果遮挡命中；圆可以覆盖障碍，其遮挡部分不产生伤害。
5. 清除活动预警后最多结算一次。命中复用原护甲/暴击/最小伤害/吸血规则，不增加剑痕；命中为几何/通路通过，实际伤害可为0。沿原伤害函数语义，命中会打断撤离（含0伤害），封印仅正伤害打断。miss不调用伤害随机数。判定后进入area后摇，同步不再开始新怪物动作；下个模拟步按原CD/决策节奏继续。
6. 同一步到期范围伤害先于随后玩家攻击弹道与撤离完成；命中可先打断撤离或使玩家死亡。若在此前步骤已发生Boss死亡/取消，则不再判定。读取公开输入取消在该输入被处理时生效，不事后撤销已结算伤害。

## 取消与身份

进入归位立即取消预警，不待到家；真正到家仍沿B3-7重置HP/阶段/epoch，不重置范围CD/MP。玩家Background、连接丢失与接管进入保护时取消所有预警，普通前台ready不复活旧圈；逻辑时钟/CD继续，恢复后可在原CD条件下重新蓄力。纯同World刷新保留已支付MP/CD与战果，预警依保护规则取消，不承诺刷新冻结时钟或保留攻击。

Boss死亡、玩家死亡/离开/绝对终局、关闭或故障回收移除预警，不能后续伤害/积分；新守护代新monster_id、cast_id从1开始，旧圈/旧连接不能命中新代。正常多圈取消聚合为一个有界事件（≤32个身份），避免保护/关闭输入产生无界事件；队列故障时以终局/回收状态为准，不保证逐圈取消事件。

重启只恢复Closed资产责任，预警/World不热恢复，不重放技能/伤害或重新扣费。原配置、积分摘要、物品守恒及operationId/正文保持。

## 视图与事件

MonsterView可选area_warning={cast_id,skill_id,name,center,radius,started_at_ms,resolves_at_ms}，无area/无预警省略；cast字段活动期间返回该技能ID。每实例cast_id与monster_id联合唯一，代替换使用新monster_id。

AreaStarted含身份、技能、落点、半径和时点；AreaResolved含身份、技能、hit和damage；AreaCancelled含casts:[{monster_id,cast_id}]与reason(background/returning/owner_died/closed/replaced)。H5按同一世界坐标投影成等距椭圆，用权威时点显示倒计时；不计算伤害/扣费/命中或本地触发爆炸。角色应整体离圈，标签说明躲避方式；死亡/保护/关闭立即隐藏历史圈。
