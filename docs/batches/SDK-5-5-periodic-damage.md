# SDK-5-5 通用周期调度与DOT最小闭环

2026-11-04；**先冻结规格后实现，PD01～PD10受控验收全部通过**。crate **0.8.0**、机制 **23**；schema4/协议3、单人PVE、现有玩家主技能/怪物弹道命中target绑定。周期时钟与状态生命周期共用，先注册物理DOT，不签收HOT或任意周期脚本。

## 定义、授予与计时

1. 新状态`mechanism:"periodic_damage"`，必填`tick_interval_ms`整数及`damage_bps`整数0～100000；沿用id/duration_ms/source_scoped/duplicate_policy。仅refresh/ignore，禁止stack/max_stacks、attribute、modifier_bps、shield_bps（含null）。旧定义/旧机制禁止新字段（含null），未知字段/公式/周期类型拒绝启动。
2. interval≥step_ms，duration在原合法范围且严格大于interval；计划跳数上限`floor((duration_ms-1)/interval)`须为1～128。工程上限不是配表伤害值；原16定义、绑定2引用、每实体32实例、全局128状态及发布预算保持。
3. 只允许on_hit_target_statuses，禁止self绑定；本批仅玩家→怪物或怪物→玩家，禁止同阵营/自身DOT。取消、墙挡、闪避、保护或致死目标不施加；合法零HP伤害/完全被盾吸收的直接命中仍可施加。绑定组沿原容量整组原子预检。
4. 在本次绑定组开始前读取来源有效ATK一次，`raw_damage=floor(source_effective_atk×damage_bps/10000)`，随DOT实例冻结。与同组ATK修正的排列无关；在途弹道仍按原规则冻结自身攻击量，但命中施加DOT读取当时来源ATK。之后ATK改变不重算旧DOT，refresh才重取；ignore保持全部原参数与来源。
5. 不立即跳。首跳start+interval，后续按上次计划时刻+interval，所有计划跳必须严格早于expires（[start,end)）。refresh保留实例ID、更新最新来源/开始/截止/冻结量，ticks_done归0、next=start+interval；ignore保留原节拍/次数/期限。跨来源按source_scoped隔离或合并。
6. 每逻辑步先清到期/失效身份，再按next_tick_at_ms、稳定instance_id字典序执行到期跳，然后进入原移动/AI/弹道等流程。同一步新命中施加DOT不立即跳；旧DOT到期跳先于该步后续命中刷新。每跳先推进计划游标，再执行效果，重复读取/输入/回执不多跳。
7. Runtime仍固定步推进，interval≥step，合法每步每实例至多一跳；内部逾期但仍有效时按原计划顺序补齐（每实例最多128跳），以实际执行步的DEF/盾为准；已到期或已关闭实例不补发历史跳；非整步末计划点若首次可执行步已到期，也由到期优先取消，total_ticks是计划上限而非必达次数。不按墙钟重启补跳，不新增每实例线程/宿主tick入口。

## 伤害、保护与归属

- DOT每跳不重判闪避/暴击，不消费伤害随机数；使用冻结物理量→当前目标DEF/原守方常数→floor/minimum_damage→当前盾→实际HP，保持ATK/DEF、盾消耗顺序与超杀边界。零原始量仍遵守配置minimum_damage。
- 不通过主动接触入口，不再施加命中状态、不追加剑印/回灵/吸血、不消费或触发反击/直接命中窗口、不因周期跳打断“主动命中”支援。正HP损伤仍触发原HP阶段/调谐或交互/撤离中断、死亡、击杀、掉落。完全吸收不作为主动接触打断这些行为，也不误杀/发奖。
- 玩家保护/后台/断线期间到期跳消耗节拍但不伤害/扣盾；恢复不补发跳。怪物归途中或遭遇复位倒计时期间同样跳过；真正归位/整组复位清理。跳过事件明确原因。来源/目标死亡、移除、代/轮次失效立即清理；本批不保留死亡来源DOT。
- 玩家来源DOT杀怪按原统一击杀/掉落/首次收益链一次处理；怪物来源DOT可使玩家自然死亡并结算。终局或首个致死结果产生后不再执行其它跳。主动放弃、绝对终局优先于周期执行；同刻DOT伤害先于本步撤离完成。

## 输出与宿主

StatusView新增可省略periodic `{kind:"physical_damage",interval_ms,next_tick_at_ms,ticks_done,total_ticks,raw_damage}`。next为null表示本周期无后续计划，ticks_done包含被保护/归途跳过的时点；视图读取不执行跳。旧19～22实例省略periodic，DOT的modifier_bps为0、不贡献属性。

新增periodic_tick事件含实例/定义/来源/目标、tick_index、scheduled_at_ms、executed_at_ms、raw_damage、absorbed、hp_damage和outcome(applied/protected/returning)。Damage.amount仍为实际HP伤害；无需宿主按事件反算数值。公开Rust字段/事件为0.8.0次版本源码变更；六类调用、协议1/2/3、资产/结果/恢复schema保持。

Node/H5只转交意图和展示下一跳/进度/冻结量/实际扣盾扣血。同World重连保留实例/原期限与节拍（进度随逻辑时钟继续），旧连接拒绝；重启只恢复冻结资产责任，清除临时状态，不恢复World或按新配置/墙钟补跳。

来源behavior §4.2/4.4/5.3支持明确的DOT标尺、状态身份与周期预算；上述物理DOT策略是本批有限注册，不表示全部来源DOT/HOT或86状态等价迁移。HOT、DOT叠层/不同标尺/死亡来源保留、控制/驱散/扩散、多技能槽、多人与新地图/第二款游戏、D-03/D-05继续保留。
