# B3-1 单人地图 PVE 闭环

日期：2026-11-03。状态：本批受控验收通过，见 [执行记录](../evidence/B3-1-map-pve-2026-11-03.md)。PRD v1.9 的首个玩法扩展切片。原资料包、B1 配置与既有验收保持不变。

## 冻结范围

- 选用资料包 `maps/misty-forest-isometric.json` 全部 256×256 逻辑地形单元，导入 walkable、speedMultiplier、blocksProjectiles、blocksVision。全部格子同高 40，本批不需要坡道/高度规则。原投影坐标以 top-face 原点 x=32 反算为正交地面坐标，格边长 32；H5 共用 2:1 投影。
- 原出生点转换为 [4080,1616]，采用原第二撤离点 [6160,3696]。固定三个妖狼出生点 [3952,1488]、[3664,1552]、[3568,1264]，属于本批新编排的单人验证布置；不冒充完整原遭遇/区域模式。
- 使用真实 `yao-wolf` 模板：炼气初期、倍率 0.55，HP/MP=82、ATK=16、DEF=5、SPD=4、暴击=2、闪避=1、命中=0；移动速度按现有对数公式。警戒 280、近战 50、普攻间隔 1200ms、呼救 420、目标记忆 900、牵引 700、归位 32 后满血清仇恨。稳定 ID 和顺序，完整足迹碰撞与有界 Rust 寻路。
- 纳入模板依赖：技能槽优先和 70% 施法检查；巡锋式准备 120ms、耗蓝10、冷却10s、弹速560、距离350、半径6、首接触、寿命720ms、剑印上限3/24s；低于30%HP 的妖息续骨准备200ms、耗蓝25、冷却25s、锁定引导1800ms，600ms一次，25%最大HP预算分3份；普通伤害吸血8%，不能超过实际HP伤害。未提交动作死亡取消，已出手弹道按原寿命保留。
- 妖狼原随机掉落全部保留：血芝30%×1..2、火灵30%×1..2、玄铁20%×1、回血丹10%×1、凝气丹3%×1；每项独立判断，品质和堆叠来自物品表。每只狼独立资源身份、一次性落地；普通回复光球3%HP/15%MP，不占背包、不刷新。
- 玩家沿用现有验证属性、普攻和断金手，新增多目标最近合法目标选择、按物品分账的背包/死亡/结算。沿用5玄铁+1年入场、180秒撤离开放、5秒读条、915秒绝对终局、每击杀10/撤离30积分及炼气0.75/死亡0.5修为系数。
- 新场景有独立 configId/hash。H5 可选择旧测试场或迷雾森林，按服务器配置显示地形、多个怪物、各物品库存和撤离点。所有路径、命中、掉落、数量和结算由 Rust 裁决，Node 不参与玩法计算。

## 验收标准

| 编号 | 必须成立 |
|---|---|
| P01 来源与地图 | 导出校验来源哈希，逐格重建一致；出生/怪物/撤离可站立、可连通；拒绝未知配置，B1 配置不变 |
| P02 地形与导航 | 不穿墙、不越界、圆形完整足迹不挤过窄缝；受地形速度影响；不可走水面与弹道/视线阻挡分开；围墙能绕行，无路保持合法位置，有界搜索 |
| P03 多实例 AI | 三狼身份、HP、仇恨、技能时钟、死亡相互独立；呼救/记忆/牵引、回防免疫、合法重激活、归位恢复按冻结规则 |
| P04 技能与数值 | 两槽优先、耗蓝/冷却/前摇、引导预算/死亡取消、吸血、剑印到期、碰撞首接触和暴击/闪避有确定边界证据 |
| P05 掉落与背包 | 多只击杀各一次；原概率/含上下界数量、稳定 RNG 回放；落点完整可走且可拾取；容量/修订失败不丢资源；物品不合并成玄铁 |
| P06 终局资产 | H5 探索→战斗→拾取→撤离/死亡→原子多物品结算；逐物品 carried+looted=kept+dropped；修为按实际击杀数；World/未决责任最终归零 |
| P07 异常闭环 | 新配置刷新保留多怪/库存/技能状态；关闭、未知回执、人工核对、强杀重启仍按原冻结多物品载荷收尾，不重复发奖；旧连接无控制权 |
| P08 旧版回归 | 原 B1/B2 的 Rust、Node、协议、H5 等距/性能、连接、超时、持久恢复、队列/I/O 验收重新绑定当前源码 |

## 明确边界

本批不启用原地图宝箱、元素机关、程序装饰碰撞、环境采集刷新、原区域完整遭遇权重、多玩家竞争、其他怪物/技能/成长和特殊模式。地形源中这些对象不作为可操作对象展示，不宣称已交付整张正式地图。当前单人只有一份全量，不包含战争迷雾或生产视野协议。正式客户端、生产库存、容量/长稳、战斗热恢复仍按原独立门禁验收。
