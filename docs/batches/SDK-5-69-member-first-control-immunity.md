# SDK-5-69 首控免疫

对应 R3.2/M03/M04 和原行为规格 §4.4 的首控免疫。目标 SDK 0.71.0、机制 86、schema 7、协议 6。自身技能通过 `self_status.on_commit_self_statuses` 施加 `timed_control / first_control_immunity`。配置有效时长，使用 `refresh` 与 `source_scoped: true`。同一实例有一次抵挡机会，同源刷新时仍为一次。

本批接入多人 PvE 的 NPC 弹道沉默。结算直接伤害后，对有效目标按定时免疫、首控免疫、控制时长减免的顺序处理。定时免疫优先并保留首控机会。首控免疫阻止同一次命中的全部沉默定义，最多消耗一个实例。多个实例按最早截止时间、施加时间、实例 ID 依次选择。普通伤害和同次其他合法效果照常结算，已经生效的沉默按原期限结束。无沉默的命中、失效的命中及读取快照均不消费。

沿用目标私有的 `status_rejected`（`IMMUNE`）和 `status_removed`（`depleted`）。未使用实例自然到期或随目标退场清理。本批验收一次性抵挡和与已有控制规则的组合，原护体值、定身及其它控制类型各自按后续规格验收。

| ID | 验收 |
|---|---|
| FC01 | 机制 86 接受合法自身技能配置，拒绝旧机制、非法字段、道具和非自身技能绑定。 |
| FC02 | 首次有效沉默命中消耗一次并保留普通伤害、同次其他状态与当前施法。覆盖多沉默定义同次抵挡、非控制接触不消费与目标私有事件。 |
| FC03 | 验证定时免疫优先、消耗后回到控制缩时、确定性选取、同源刷新、精确到期和退场清理。 |
| FC04 | 普通时钟 Node 和 H5 四人、八人房验证首发沉默被抵挡并消耗，随后一发在原免疫期限内正常施加 2800ms 沉默。所有成员各完成一次结算。 |
| FC05 | 同一交付包通过仓库外空缓存离线接入、机制 85 兼容复验以及 Rust 和 Node 回归。 |
