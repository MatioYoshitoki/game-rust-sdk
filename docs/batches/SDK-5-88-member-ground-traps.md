# 成员地面陷阱

本批归 R3.4。可信配置给已有地面圆形技能绑定定点陷阱。沿用地面施法输入、落点校验、资源事务和区域容量。样例用于验收通用规则。

| 验收项 | 预期 |
|---|---|
| 放置与启动 | 接受和提交均校验同一落点。成功提交一次费用和冷却，并冻结原施法动作、圆心和攻击预算。预警时段由技能的 `warning_ms` 配置。延迟为零时在提交步启动并可触发。活动寿命从启动时算起，截止时刻排除。容量不足和提交前取消均不扣费。 |
| 触发与遮挡 | 用固定步末的碰撞圆和地图遮挡找敌对 NPC。启动时已在圈内也获得一次触发机会。之后按离开再进入识别新机会，连续停留不会重复判定。多目标按距离、ID 和代次稳定排序，同侧成员不参与。 |
| 伤害与预算 | 接触复用伤害、命中状态和来源动作结算。成功含护盾完全吸收时扣除次数，免疫、闪避、超出预算或重复间隔未满均不会扣除次数。留在圈内不重复掷命中；同一目标重入还需满足配置间隔，间隔为零时该代次最多成功一次。 |
| 发布与清理 | 协议 6 发布预警、活动陷阱、进入命中、剩余次数及结束。重连恢复原地点、时限和历史。来源保护仍可保留已提交陷阱，来源死亡、退场或换代、次数耗尽、到期或关局回收。退场成员的冻结快照省略其他成员的陷阱，留场成员仍可继续触发。 |

本批采用固定步末接触，整步穿过且步末在圈外时无触发。陷阱使用成员对敌对 NPC 的既有关系，生产几何和其他模式按对应工作包验收。
