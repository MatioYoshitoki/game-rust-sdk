# SDK-5-78 自身技能暴伤加成

对应 R3.3/M04 和原行为规格 §4.1、§4.2。目标 SDK 0.80.0、机制 95、schema 7、协议 6。自身技能通过 `self_status.on_commit_self_statuses` 提供 `timed_attribute_modifier / critical_damage_bonus`。配置时长和正向 `modifier_bps`（1～15000），同源刷新。有效实例相加，额外倍率封顶 1.5。

成员直接命中 NPC 并成功暴击时，读取攻击者当前有效暴伤加成，加到配置的 `params.critical_multiplier`。基础倍率为 1.5 时，合计最高 3.0。沿用护甲和破甲、暴击、统一取整、护盾的结算顺序。暴击概率、随机流与非暴击、NPC 和周期伤害沿用现有规则。增益到期后，后续命中按当时剩余实例计算。

客户端使用私有状态与现有伤害事实。该切片覆盖自身技能暴伤与成员直接伤害，原装备、专精及其他投放来源按各自规格接入。
