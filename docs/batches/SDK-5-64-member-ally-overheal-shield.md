# SDK-5-64 友方即时治疗溢出转护盾

对应 R3.3/M04 及原行为规格 §4.2、§4.3、§4.4。目标 SDK 0.66.0、机制 81、schema 7、协议 6。允许在 `ally_heal` 技能的即时 `heal` 配置内声明 `overheal_shield`。引用的 `absorption_shield` 采用 `refresh` 和 `source_scoped: true`，转换比例为 1～10000 万分比。沿用指定友方的 `cast_unit` 和接受、提交两次重验。

提交后先扣施法者费用并登记冷却，按目标当时有效的受治疗倍率计算治疗，先补目标气血缺口，再把实际溢出按配置比例向下取整。转换盾按施法者与目标独立记账，受单盾和目标总盾上限约束。实际新增盾时保留余额并刷新，零新增时保持原期限。状态槽已满时保留本次气血回复和技能提交，只拒绝新增盾。

施法者及目标收到治疗和授盾结果，盾状态只进入目标私有快照。施法者退场清理其转换盾，目标退场清理其身上的转换盾。普通友方即时治疗及友方 HOT 沿用原配置。

| ID | 验收 |
|---|---|
| AO01 | 机制 81 接受友方即时治疗的显式转盾，拒绝旧机制、错误比例、非来源分组或非刷新盾定义。 |
| AO02 | 验证目标倍率、取整、气血优先、同来源补盾、单盾和总盾上限及零新增保持期限。 |
| AO03 | 验证容量不足保留治疗，状态归目标且事件只发给施法者与目标。验证来源及目标离场清理。 |
| AO04 | Node 与 H5 四人房满血实回 0、授盾 50，来源先离场。八人房缺 160 气血，实回 160、授盾 70，目标先离场。各成员最终结算一次。 |
| AO05 | 同一交付包通过仓库外空缓存离线接入、机制 80 指定友方护盾兼容复验、Rust 和 Node 回归。 |
