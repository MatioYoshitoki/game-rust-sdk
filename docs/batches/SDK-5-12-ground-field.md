# SDK-5-12 通用持续区域最小闭环

2026-11-04；先冻结需求/验收，现已实现并通过受控验收。目标crate0.15.0、机制30，schema4/协议3单人PVE、最多两个玩家技能。只提供配置化固定圆形持续伤害区域，不增加具体地图规则。

## 配置、提交与周期

新增玩家mechanism=ground_field，复用ground_circle的ID、cost、windup_ms、recovery_ms、cooldown_ms、damage_bps、range、radius、warning_ms，以及合法可选self/hit状态绑定；必配duration_ms和tick_interval_ms。严格字段禁止speed/目标身份/脚本/引导扣费/追踪等无效字段。仅≥30/schema4/PVE，主副槽都支持；已有数值/唯一ID/引用/绑定约束保持。持续时间1～60000ms、间隔step_ms～60000ms，duration_ms必须大于间隔，截止前计划跳数(duration_ms-1)/tick_interval_ms必须1～128；预警0～60000ms，其余沿地面圆形边界。

复用CastGround严格世界坐标输入和接受/提交两次校验：半开地图边界、可行走落点、中心射程等值合法及视线；不裁剪/吸附/导航。接受冻结技能/坐标/轮次，提交前失败免扣。提交原子预检灵力、整组self状态、所有未结算玩家地面计划总容量2（单次圆形+持续区域共享）；容量失败不扣费/开CD/施加状态，不阻止普攻或自身技能。成功施加self状态后冻结直接伤害的有效ATK比例量、中心/半径/时长/间隔/命中绑定/来源及接受时间/轮次，成本只扣一次、CD/共享后摇只开启一次。不产生弹道，不产生周期费用，不依赖技能名/地图名分支。

激活计划时刻=提交时刻+warning_ms，结束时刻=激活时刻+duration_ms。首跳计划在激活时刻+tick_interval_ms；后续按该计划时间加间隔，禁止按实际晚到时间累加漂移。只结算scheduled_at_ms≤当前固定步且严格小于结束时刻的跳；到期点不跳。零前摇下一固定步提交，零预警仍需等待首个间隔。非整步间隔在首个满足条件的固定步执行；已有固定步补跑/滞后预算保持，跳过的调度需有界补齐，最多128跳/区域，不生成无界追赶。

同一步多个到期周期按计划时刻、区域创建顺序执行，每周期按稳定怪物索引检查当前存活/启用、非归途/非复位倒计时、原遭遇轮次、圆形接触半径（技能radius+单位radius）和既有弹道遮挡。每区域每周期每单位最多一次；不同区域独立结算，离开不再接触，再进入可参与下一周期，无进出补跳。空区域仍推进周期；目标死亡不再结算。直接伤害冻结量不因后续增益变化重算，每跳读取当前DEF/盾/闪避，沿原直接命中/取整/状态/击杀/掉落/遭遇链；合法hit绑定按每次真实直接接触施加，附带状态沿原施加时的攻击量捕获及重复策略。无递归区域创建或动作级额外奖励。

## 生命周期、输出与接入

本批来源固定当前participant，来源失效策略明确为结束未来周期；不声称支持配置化保留死后区域或其它来源实体。未提交取消/后台/死亡/终局/关闭/实际换轮沿原策略免扣；移动保持准备，提交重验。提交后移动、CancelAction、后台及同World重连保持已提交区域与CD/后摇，不退款。来源死亡、终局、关闭及任何实际遭遇换轮均结束所有未完成区域，不再产生伤害/状态/击杀/掉落；复位倒计时仅使该遭遇暂不接触，实际换轮才结束。正常到期与来源死亡/终局/关闭/复位使用明确不同原因，每区域只结束一次；已发生的伤害不回滚。

机制30 PveView增加可省略player_fields，含action_id/skill_id/center/radius、started_at_ms、activates_at_ms、expires_at_ms、next_tick_at_ms（无后续周期时null）、completed_ticks/total_ticks；生命周期事实全部来自Rust。沿用pending_action/ActionCommitted.ground_position。新增PlayerFieldStarted{field}、PlayerFieldTick{action_id,skill_id,tick_index,scheduled_at_ms,hits}、PlayerFieldEnded{action_ids,reason}；取消/到期按原因有界聚合，关闭预算包含一条区域结束事件。旧1～29省略新字段/事件，旧单次圆形和NPC圆形时序不变；公共视图/事件枚举源码消费方需适配，Client六类、协议1～3、资产/恢复schema保持。

H5复用显式地面点选/纯触屏，区分预警/活动区域、显示剩余时间和已完成周期；不按前端时钟判伤。Node只提交世界坐标意图。主副交换的两套包外配置改变ID/时长/间隔/倍率/绑定，验证空区域、多次周期、实际状态/治疗、战斗拾取及撤离/死亡双终局。已有单位选择跨快照保持，旧1～29正常功能回归。

同World重连恢复区域中心、计划时刻、周期进度及CD/后摇，准备沿原连接策略取消，旧连接拒绝；重复输入不重复建区/扣费/跳数。进程重启只履行旧Create/hash/金额/operation ID的冻结资产责任，不恢复临时区域/准备/状态/World，也不按新配置重算旧责任。
