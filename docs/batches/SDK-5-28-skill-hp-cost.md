# SDK-5-28 技能生命成本

2026-11-05；实现前冻结 HC01～HC10。起点0.29.0/协议6/schema7/机制44；目标0.30.0/协议6/schema7/机制45。对应R3.1/M02资源事务切片，沿固定1～8成员PVE、静态1～8技能及现有七类技能机制；不添加具体地图或技能内容分支。

## 配置与语义

每个skill/additional_skills条目可选完整hp_cost对象：mode为fixed或current_hp_ratio；value为有限非负数，fixed上限1000000、ratio上限1；min_hp_after_cost为1～1000000整数。fixed先floor(value)，ratio先floor(提交瞬间当前HP×value)，再夹到[0,currentHP.saturating_sub(min_hp_after_cost)]。HP已低于最低保留值时成本为0，不凭成本治疗；存活且其它校验合法时仍可提交。未声明生命成本的技能继续零成本，显式null/未知字段/缺项/坏类型/非有限或越界值拒绝。

仅机制45/schema7/协议6支持hp_cost；旧机制1～44即使空对象/null也拒绝字段，旧JSON与旧合法输出不变。机制45保留机制44的1～8技能槽和所有整表预算。实际HP和灵力、最低保留值、比例/固定值均来自初始化配置/权威World；客户端只能发原有技能意图。

接受时冻结技能的成本定义，不能预扣HP、灵力或启动CD。提交时先重验实际目标/代次/起点/落点、灵力、整组自状态与全World计划容量，全部通过后才按当前HP求成本，原子扣HP与灵力、建立该技能CD/共享后摇并创建效果。HP成本在提交自状态前执行；不经伤害链、不消耗护盾、不触发伤害归功/DOT/受击/吸血，不取消已合法提交。提交前取消、后台、重连、退出/死亡或提交失败均不收费。已提交后取消/断线/退出不退款，也不重复收费；周期/弹道后续接触无二次生命成本。

原私有ActionCommitted事件增加可选hp_cost整数：只对声明hp_cost的成功技能发布，包含实际0；旧技能/普攻省略字段。只发本人，公共HP投影继续按原规则；无新Action、Client方法、Snapshot字段或金融/恢复责任。full/delta和重连使用既有HP/CD/准备事实，显示端不反算生命成本；重启继续仅Closed金融收尾。

新两套4槽/4人、8槽/8人配置分别验证固定/比例与混合槽。Node/H5观察真实私有提交事实，按配置生成选择器并显示累计实际生命成本；等距地图与原战斗/共享拾取/独立终局保留。独立4219预览、4220浏览器验收、4221交付只读端口/账本；旧预览和账本不改动。
