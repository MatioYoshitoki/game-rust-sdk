# 波面位移与交替普攻

本批属于 DELIVERY-01 与 R3.4。继续由可信宿主为各席位选择普攻 profile。通过可选的 `basic.wave.behavior` 配置击退，或交替使用定向和径向波面。逐风散阵与开门纳妖作为原资料验收配方。机制使用相同的攻击输入、目标身份、波面时钟和动作终态。

| 验收项 | 预期 |
|---|---|
| 逐风散阵 | 射程 280，扇面 116°，最多 5 个目标，主副伤害系数 7000/6200 基点，沿用扇的前摇、速度与冷却。有效接触且存活的普通怪沿冻结方向最多推 140 单位。实际移动后，同来源同一目标有 1600 ms 击退间隔。精英和首领刷新 30% 减速 1250 ms，连续接触和不同来源均不叠加强度。 |
| 地形与碰撞体 | 使用怪物碰撞半径，沿直线到最早地形或地图边界接触前停止。弹道可穿而角色不可走的地块也会挡住位移。开门牵引向接触时的施法者，最多 70 单位，并保留双方碰撞半径之和。位移后废弃旧寻路。 |
| 开门与闭门 | 首次释放 230 射程、90°、720 速度的定向波，主副伤害系数 5000/4400。下次释放 190 半径、1200 速度的径向波，主副系数 7200/6500。每形态最多 5 个目标。准入、自动选敌、追击和释放校验共用当前射程。只在波面释放成功时切换形态，目标失效或前摇取消保留当前形态。 |
| 门印 | 开门有效接触后给存活目标留下 4500 ms 门印。精英和首领可获得门印。闭门对本来源未过期门印的冻结伤害预算增加 22%，向下取整后进入共同伤害链，成功接触即消费。免疫、闪避不消费。门印和击退间隔按来源、目标代次独立维护。 |
| 终态与发布 | 塔的终态镇压走既有配置，器型按原覆盖停用基础释放减伤。回灵、吸血和冷却沿用同动作结算。私有全量与增量公开下一次波面形态，波面发布标识已释放形态，怪物快照同步位移。保护或重连沿用已释放波面的生命周期，死亡或退场清理该席位的波面和隐藏状态。 |
| 兼容与接入 | 旧配置、攻击输入、波面发布继续有效。拒绝非法位移、减速引用、形态几何、计划 ID 和超预算配置。Rust 验证时序和边界，Node/H5 验证双成员发布和重连。 |

本批覆盖逐风散阵和开门纳妖的 PvE 行为。渡劫风刃的技能命中位移、玩家敌对规则、装备实例解析及局内换装各自验收。
