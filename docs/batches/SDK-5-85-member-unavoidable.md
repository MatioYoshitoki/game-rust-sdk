# SDK-5-85 成员直接攻击不可闪避

对应 R3.3/M04 和原行为规格 §4.2。目标 SDK 0.87.0、机制 102、schema 7、协议 6。多人 PvE 的 `basic` 以及伤害技能 `projectile`、`unit_projectile`、`piercing_projectile`、`ground_circle`、`ground_field`、`line_field` 支持可选布尔字段 `unavoidable`。省略与 `false` 沿用原闪避判定，`true` 跳过该攻击的闪避及其随机抽取。显式配置需要机制 102。

成员弹道与区域计划在提交物化时冻结该策略，后续接触复用上一批的通用直接接触入口。资格、目标身份与关系、墙挡、伤害免疫、护盾、命中附带和接触预算沿原顺序处理。费用、冷却及命中回灵只按原成功提交或成功接触处理。穿透和区域重复接触对每次接触使用已冻结的策略。

Node 和 H5 四人、八人房使用相同固定种子与 NPC 闪避配置，先普攻再施放不可闪避方向弹道。四人普攻开启不可闪避，八人关闭，技能均开启。

| ID | 验收 |
|---|---|
| MU01 | 普攻和六种伤害技能支持布尔值并按原义序列化；拒绝旧机制、空值和非布尔，以及自身/友方技能中的该字段。 |
| MU02 | 验证普通、严格单位和穿透弹道提交时冻结策略，跳过闪避随机数，并保留目标资格、墙挡、护盾、附带状态与命中回灵。 |
| MU03 | 验证单次圆形、持续圆形和线形区域的冻结策略与接触预算；省略/关闭及旧机制兼容，来源退出清理。 |
| MU04 | Node 和 H5 四人房普攻与技能伤害为 66 → 66，八人房为 0 → 66，每位成员各准入并结算一次。 |
| MU05 | 同一交付包通过仓库外空缓存离线接入、机制 101 NPC 不可闪避复验及 Rust 和 Node 回归，历史数值边界逐项保持。 |
