# SDK-5-50 恢复道具附带直接减伤

对应 R3.2/M03、R3.3/M04。目标 SDK 0.52.0、机制 67、schema 7、协议 6。本批为恢复道具增加可配置的自身直接减伤，用原资料中的玄甲丸验证。状态仍由 `on_use_self_statuses` 绑定，采用 `timed_attribute_modifier`、`damage_reduction` 和 `refresh`，强度接受 1～5000 万分值。不同品质可沿用 `on_use_self_status_overrides` 配置强度和时长。

范围是同一多人 PvE World 内 NPC 对成员的有效直接攻击。结算顺序为防御、百分比减伤、护盾、生命。不同有效状态的减伤率相加，合计最高 5000 万分值。同一状态按原实例刷新。减伤后的整数结果先向下取整，再以小数部分为概率向上取整，使用该局已有的种子随机源。整除时不抽样，命中时已到期的状态不参与计算。周期伤害继续走原规则。新状态本批由恢复道具施加。

用药继续要求实际恢复与整组状态容量通过校验。失败、重复、隐私、重连和净拾取结算沿用现有契约。四人房样例用 25% 减伤，八人房用 32%，实际攻击验证生效前、有效期内和到期后三段伤害。样例采用短时长便于观察。

| ID | 验收 |
|---|---|
| MR01 | 机制门禁、属性类型、重复策略、合法道具绑定和 1～5000 数值边界。 |
| MR02 | 验证防御后、护盾前的实际直伤，聚合上限、周期伤害隔离、整除与有余数的种子舍入。 |
| MR03 | 验证品质覆盖、同实例刷新、到期边界以及满值、重试和冷却的提交行为。 |
| MR04 | 验证本人状态私有、重连保留时限和退出按净量结算。 |
| MR05 | 普通 Node 和 H5 跑通四人及八人房，从拾取、承伤和用药到减伤到期与结算。 |
| MR06 | Rust 和 Node 回归通过，同一交付包通过空缓存离线构建和机制 66 品质状态兼容验证。 |
