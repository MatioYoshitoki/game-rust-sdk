# SDK-5-57 NPC 弹道施加灵力回复封锁

对应 R3.3/M04 及原需求 §4.3、§4.4。目标 SDK 0.59.0、机制 74、schema 7、协议 6。多人 PvE 的 NPC 普通弹道可在 `on_hit_target_statuses` 引用已有的 `spirit_recovery_lock`。合法命中时先结算伤害，再向仍存活的敌对成员施加状态。护盾完全吸收伤害时，合法命中仍可施加。状态记录 NPC 实体及代次，沿用 `refresh`、`ignore` 和 `source_scoped`。

封锁生效期间，成员的自然恢复、普攻命中、光球和即时用药产生的灵力回复归零。状态从截止时刻起失效，来源死亡、来源归位重置及目标终止也会移除对应实例。成员本人收到状态事件，队友视图按既有权限投影。

| ID | 验收 |
|---|---|
| NL01 | 机制 74 接受 NPC 普通弹道的命中绑定。旧机制、NPC 自身提交和玩家攻击绑定拒绝。机制 73 的自身施法和道具来源继续可用。 |
| NL02 | Rust 验证有效命中、护盾全吸收、受保护目标、致死命中、来源代次，以及多个来源的隔离清理。 |
| NL03 | 核对封锁只作用于被命中的成员，精确到期后可回灵。来源死亡或归位重置后，已失效来源的状态清除。 |
| NL04 | 四人及八人房在 Node 和 H5 中验证真实 NPC 弹道命中、自身光球在封锁中与到期后的实回、普攻回灵和退出结算。两房光球实回分别为 30/0 到 30/30、150/0 到 150/120。 |
| NL05 | 同一发布包通过仓库外离线接入、机制 73 自身封锁兼容复验、Rust 和 Node 回归。 |
