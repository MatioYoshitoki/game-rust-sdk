# 普攻弹射、驻留与召回

本批属于 DELIVERY-01 与 R3.4。在 `basic.projectile_followup` 中增加连续走廊与逐段弹射，复用原动作 ID、实体弹道、全局容量、伤害结算及终态收益。使用六印回锋、回天飞盾和选配回程的回天飞盾验证。席位配置由可信宿主选取。

| 验收项 | 预期 |
|---|---|
| 六印出剑 | 剑系射程 330、速度 1500。出剑方向和目标中心在释放时冻结，端点向目标后方延伸 84，并沿同一直线裁到地图边界。28 半宽内按当前目标中心的路径投影与 ID 稳定处理，主副系数 10000/4000，每个目标代次在每条路径最多裁决一次。主目标实际扣血后，出剑抵达端点或被后方障碍挡下时留下剑印。 |
| 六印召回 | 累计六印后等待 100 ms，从第一枚剑印起按锚定的 55 ms 间隔发射。每枚发射时冻结当时的来源位置，各自完成直线路径或受阻终止。每条路径先处理障碍，再结算合法目标。召回系数 1800，命中后同源刷新 20% 减速 2000 ms。没有目标的路径仍完整推进。最后一条路径终止后才结算同一动作的冷却与收益。 |
| 回天飞盾 | 继承盾系前摇和间隔。首段射程 300、飞行速度 720，主副系数 7200/5600。每段成功接触后，以实际接触点为下一段起点，在半径 190 内按距离和 ID 选取本动作未接触的不同实体，最多四段。飞行中碰到墙体或目标失效时停止外抛。每次成功接触刷新来源与目标代次独立的 5000 ms 震印。第三枚消费，并对未配置抵抗的怪物施加 800 ms 眩晕。 |
| 选配回程 | 原资料的基础回光叠影参数通过选配配置表达。最多六段，搜索半径 237.5，副系数 8400。外抛结束后从实际终点以两倍速度飞向此时来源位置，回程无碰撞、接触或伤害。成功回程且来源仍有终态收益资格时，按不同实际扣血目标数授予统一护盾，首目标 4% 最大生命，每额外一个加 1%，上限 9%，持续 1800 ms。零实际扣血时只执行回程。 |
| 发布和生命周期 | 公有快照同步尚未召回的剑印与在途段角色。重连恢复同局剑印、在途计划和剩余收益责任。死亡或退场清理该席位的剑印、震印和计划。配置或容量不足拒绝释放，源目标换代隔离。普通 Rust 和 Node/H5 宿主验收。 |

配置目录上限提高到 32 份，可并存原六家族与命名器型。被动功法的装备解析、成长换算和局内换装各自验收。
