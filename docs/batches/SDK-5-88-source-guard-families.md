# 坤甲功、撼山劲与记录盾家族

DELIVERY-01 在同一批验收两组普通和进阶护体。宿主通过可信技能表发放进阶技能，通过可信熟练阶段选择状态。SDK 沿用统一护盾池、伤害链和快照，增加按来源与目标隔离的盾家族，以及按结束原因选择反击的配置。

| 验收项 | 预期 |
|---|---|
| 两组技能与五阶段 | 普通与进阶技能保持各自 ID、费用、冷却与 80 ms 可取消后摇。逐阶段对照原表的最大生命盾量、期限、减伤、来源功法威力记录帽及反击比例。精通前的样例宿主不发放进阶技能。 |
| 同一护体 | 同一来源和目标的同家族盾最多一个。比较统一盾池钳制后的新余额与旧盾剩余量。新余额更强时替换，较弱或等量时原实例、期限和记录继续有效。普通和进阶互换时无额外反震或余韵。其他家族和来源继续使用统一盾池。 |
| 受击与结束 | 护体先减伤，再记录吸收前伤害，最后由统一盾池吸收。进阶反击取记录值的 60%。圆满护体结束留下配置减伤，圆满反击命中附带减速。破盾、自然到期分别按声明执行，重连恢复盾量和记录，离场或驱散只清理。 |
| 兼容 | 旧盾沿用原刷新及结束规则，协议沿用现有盾状态和事件。校验家族、配置引用、反击原因和状态容量。 |

样例依据精通段的「结束或破裂」为进阶护体配置两个独立的反击原因，普通护体只在圆满结束时释放余韵。原表只在圆满行列出反击半径，样例将各家族该半径沿用到较早的进阶阶段。反击伤害类型样例选用物理，原类型待复核。样例按原技能注册表的施法费用配置，常驻成长、真意与进阶解锁的业务发放另行验收。

将样例的技能定义加入 `skill_library`，按 ID 合入状态和战斗配置表，并将样例的 `shield_cap_bps` 设置到 `pve.status_rules`。宿主通过 `SkillLoadout` 声明可用技能，普通与进阶技能使用对应功法的可信熟练阶段。样例将两种护体的记录帽绑定到同一功法的威力，验证时使用固定的 100 点功法威力。 [配置样例](../../examples/combat-host/source-guard-families.json) · [验收基底](../../examples/combat-host/mastery-stages.json)
