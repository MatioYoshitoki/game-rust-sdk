# 普攻生成的固定领域

本批属于 DELIVERY-01 与 R3.4。通过 `basic.wave.field` 配置由普攻生成的独立周期领域，用风眼留痕和落塔镇岳验证。武器和场地数值由可信配置提供，宿主继续使用原普攻输入。

| 验收项 | 预期 |
|---|---|
| 风眼留痕 | 原扇系前摇、间隔和波速，范围 270、扇角 84°、最多四目标，主副伤害系数 6500/5600。主目标首次有效接触时在其当时位置生成半径 74 的固定领域。同一来源最多保留 12 个，每场独立选取最多六个目标，并以当时有效攻击力计算每跳 1500 基点。 |
| 落塔镇岳 | 原塔系前摇和间隔，锁定射程 320，以目标释放时的位置为爆心，按速度 1400 到达后在半径 150 内处理冻结候选。候选须在到达时仍合法且位于爆心范围与视线内，最多五个，主副系数 7200/6200。爆心与镇域不会随目标移动，目标在途中失效仍会落塔。每来源只留最新领域，旧场收到替换终态。每跳系数 1800，预算在普攻释放时冻结。 |
| 场地时钟 | 两种领域分别持续 10000/6000 ms，每 1000 ms 结算一次，首跳在间隔到达后，末跳在期限当步。每跳按实时位置、圆形碰撞与地形视线选敌。只走共同伤害、受击方事件与击杀归属，不重复触发攻击方动作收益。 |
| 守域减伤 | 镇岳来源在自己的领域内时获得 1200 基点减伤，合并到已有减伤上限后在护盾前结算。离开范围或场失效时停止，进入另一个来源的领域不授予此减伤。 |
| 容量和重连 | 技能区域与普攻领域各有容量，使用共同发布。接纳带领域的普攻时预留空位或本来源可替换的旧场，其他来源的场不会被淘汰。暂时保护或重连保留已释放领域，来源终结则清理。在同一 World 的 Rust、Node/H5 验收固定中心、替换、重连和独立结算。 |

灼烧叠层和死亡传播、基于配装的被动成长另按对应工作包验收。
