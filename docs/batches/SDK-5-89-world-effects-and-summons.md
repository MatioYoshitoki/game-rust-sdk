# SDK-5-89 武器、世界效果与召唤

2026-11-10，DELIVERY-02 的 R3.4 与 R3.5 已通过 SDK 机制验收。实际地图、器型、实体模板和数值由宿主提供。 [模块 02 签收](../evidence/SDK-5-89-delivery-02-acceptance-2026-11-10.md) · [模块 01 签收](../evidence/SDK-5-88-delivery-01-acceptance-2026-11-10.md)

## 实施顺序

1. 核对已支持的轨迹、接触、位移、陷阱和锚点。先验证配置准入、固定步触发、预算、归属和退场。以能复现的契约差异驱动修改。
2. 实现有界召唤的首个闭环。合法技能提交产生有真实身份和原来源代次的单位，宿主声明模板、数量和寿命。单位能按明确的敌友关系参战、受到伤害，并随死亡、到期、来源退出或关闭回收。
3. 按需求补齐确有用途的能力复制白名单和世界效果组合。沿用原命中、状态、资源责任和清理契约。生产几何在模块 03 接入，模式及容量组合在模块 05 补验。

| 编号 | 范围 | 可判定结果 |

### WE03 首个召唤闭环

- 宿主为自身技能绑定单位模板、单次召唤数、持续时间和成员同时存活上限。提交时重验上限与落点，失败保留灵力、生命和冷却。配置没有绑定时沿用原行为。
- 单位在施法者提交位置生成并可承伤，从下一固定步起可以主动攻击。生命、攻击、防御、体积、近战范围和间隔来自模板。成员和召唤体同队，敌方 NPC 可以选中召唤体近战，现有直线弹道也能接触它。击杀记到当前来源成员。
- 到期、致死、来源死亡、退出、换代和关局都移除实体及其状态，并清除 NPC 对它的锁定。连接保护期间暂停该来源召唤体的交战，重连后在有效期内恢复。
- 公开快照与增量发布携带召唤体的身份、所有者和到期时点。用两名成员验证独立额度、友方排除、目标清理与重连。移动、技能复制和其他召唤行为按后续需求与验收单独核对。

首个召唤闭环已通过 Rust 和两组合成 Node 接入验证。 [有界召唤基础验收](../evidence/SDK-5-89-bounded-summons-2026-11-10.md)

### 能力复制和组合验收

资料包的技能说明、`factor_summon` 与精通阶段接口要求按比例继承攻击、防御和最大生命，并间隔复制普通非终极技能。资料同时要求列的死亡爆破和实际归属清理。宿主选择允许的技能 ID 和数值，精通阶段映射由宿主提供。存活时给本体的加持进入 R5.2，与成长和模式组合验收。

| 编号 | 可判定结果 |
|---|---|
| WE03a | 可选比例在生成时采样本体有效攻击、防御和最大生命。复制仅允许已装备且显式授权的普通直线弹道、严格单位伤害或无预警单次圆形伤害。拒绝递归、引导、蓄力、重施和陷阱/锚点。镜像只执行伤害，沿用自身身份、时钟、目标资格、位置与宿主配置倍率。 |
| WE03b | 每只召唤体按复制技能各自计冷却，同一来源代次共享复制间隔。只有重验成功并释放才消费间隔。脱离、保护、换代、控制、容量耗尽、到期和死亡清理待释放动作或在途复制弹道。实际致死可按配置执行一次有限爆破。 |
| WE04a | 两组包外合成输入组合陷阱、锚点、区域或弹道与召唤。覆盖同一步接触预算、阻挡、重连全量、离场增量、独立结算和关闭。以同一 SDK 构建验证 Rust、Node 和离线发布包。 |
