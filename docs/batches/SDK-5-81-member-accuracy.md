# SDK-5-81 自身技能命中加成

对应 R3.3/M04 和原行为规格 §4.1、§4.2。目标 SDK 0.83.0、机制 98、schema 7、协议 6。自身技能通过 `self_status.on_commit_self_statuses` 提供 `timed_attribute_modifier / accuracy`。配置时长和正向 `modifier_bps`（1～10000），同源刷新，有效实例相加后封顶 10000 bps。100 bps 对应原公式中的 1 点 `attacker.hit`。

多人 PvE 的成员对 NPC 发生合法直接接触时，读取该成员当时的命中加成与闪避压制。有效闪避概率为 `min(0.5, max(0, dodge × 100 − penaltyBps) / (10000 + accuracyBps))`，等价于原公式的概率形式。先扣闪避压制，再除以命中修正，最后应用 50% 上限。零概率不消耗随机数；有概率时沿用一次对局闪避随机抽取，再按成功接触结算。成员普攻、直接技能弹道和区域等沿共用直接接触入口使用此公式。入场基础命中、NPC 命中与周期结算沿既有路径。

客户端观察施法成员的私有状态及现有弹道、伤害事实。固定种子四人和八人样例用同一 NPC 目标验证状态生效前、有效期间和到期后各一次普攻。
