# B3-5 配置化区域遭遇闭环

日期：2026-11-03。状态：E01～E08受控验收通过。以B3-4的216项Rust为基线，新增31项Rust/16项浏览器；最终247项Rust与13组完整回归通过。

## 最小范围

新增独立b3-5验证场景。区域触发→整组敌人生成→击败指定目标→解锁绑定奖励容器→显式解封/开箱→落地/拾取→撤离或死亡结算。先实现单组、每局一次的遭遇控制器；可配置多个独立遭遇验证隔离，不实现多波次、前后依赖、Boss阶段、调谐成本、贡献/优先权或多人。它是复用来源森林/妖狼/封印奖池的机制验证场景，不签收完整原森林圣所。

Rust实现触发、状态推进、整组生成、目标判定与奖励资格；配置初始化区域中心/半径、模板/实例ID/点位、必杀目标ID、绑定箱ID、属性/奖励。配置schema仍2，机制版本4；原五配置及归档raw/hash保持。现有六类Client能力不变，不提供浏览器触发完成、生成敌人、写进度或直接发奖励入口。

## 状态与时序

1. `dormant→spawning→active→completed`，每局每遭遇最多推进一次。未触发时敌人仅占有界预留槽位，不进入快照/碰撞/AI/掉落。角色在Active、存活、foreground/ready且未保护/撤离引导时，权威位置距中心≤配置radius即触发；按模拟步采样，不做跨步扫掠/视线触发。出生位于区域内则第一个合法活跃步触发。
2. 移动先推进，再检查触发，随后整组生成和AI/战斗。固定候选点由配置给定，须满足各自足迹/可达路径、组内间距与玩家/现存活怪间距。全部合法才原子启用，不部分生成；受阻保留spawning，每ai_decision_ms重试，不抽随机数且每遭遇只报一次受阻事件。离开区域不撤销已触发状态。
3. active只按本遭遇required_monster_ids中已实际生成且HP=0的实例计数；不使用全局计分击杀或模板数量。必杀列表非空且为本组实例子集；其他静态怪、守护或其他遭遇死亡不贡献。目标归位不算死亡；不计分目标死亡仍可推进。最后目标死亡后的本步完成，不重复完成/解锁；若角色已死亡/终局则不再推进。
4. 绑定箱始终可展示但有遭遇资格锁。dormant/spawning/active都拒绝破解与开启；completed只解除该锁，仍检查箱代、守护、距离、封印和容量。完成本身不动RNG、物品、修为或箱代，也不自动开箱。每箱最多绑定一个遭遇；箱重生不重置已完成遭遇，之后每代仍沿用原箱领取规则。
5. 所有敌人仍按各自模板计分/掉落。活跃非必杀目标可在完成后继续战斗；完成不会删除敌人/弹道。允许未完成即撤离/死亡，结算只含已击杀/实际拾取资产，锁定箱无收益。
6. 刷新/短断线保留同World的状态、槽位/ID、目标进度及箱锁，无重复触发。保护中不生成/推进遭遇，恢复后继续；旧连接输入照旧隔离。Closed/死亡不推进或生成。服务重启只恢复Closed责任/结果，无终局只退原入场，不恢复遭遇现场。

## 配置与边界

`pve.encounters[]`为可选严格数组，每项必填id/name、trigger{center,radius}、monsters[{id,template_id,position}]、required_monster_ids、reward_chest_ids。能力4才允许；模板引用基础/额外模板，怪物ID全局唯一且不得guardian-前缀，遭遇ID唯一；目标须属于本组且不重复，奖励箱须存在、非空且不重复/不跨遭遇共用。半径有限0.1～1000，中心与各点有限且可达，模板自身足迹合法；同组生成点不得重叠。

每配置最多8个独立遭遇，单组至少1敌人；基础+静态额外+所有遭遇预留+守护预留总数≤32，仍受资源128/逐物品10亿/终局计分击杀4096等预算约束。恢复产量与成长上界包含一次性遭遇实例，不因尚未触发删减已冻结责任的合法可能上界；旧配置解释保持。

## 验收标准

| 编号 | 必须成立 |
|---|---|
| E01 配置 | 原五配置不变；合法模板/目标/箱关系和多组隔离；错版本、重复/保留ID、空/错引用、错误结构/数值/预算、地形/足迹/路径拒绝 |
| E02 触发 | 圈外不触发、边界/圈内触发、出生圈内首合法步触发；保护/未ready/非活跃/死亡/关闭不触发；重复进出/输入不重建 |
| E03 生成 | 未启用槽位不参战；异模板整组原子生成，玩家/活怪阻挡无半组、移动清障恢复；不消耗随机数、重复重试不刷事件/状态 |
| E04 推进 | 只认本组必杀目标的实际死亡，支持不计分目标；部分死亡/归位/别怪/别遭遇不完成；最后目标一次完成，重复伤害无双记账；离开不重置 |
| E05 奖励与资产 | 完成前公开破解/开启被拒；完成只解除资格，仍显式解封/开启/拾取，满地面/满包等沿用原原子语义；未完成提前退出/正常完成撤离/死亡逐物品守恒 |
| E06 生命周期 | 同World刷新/旧连接/保护恢复保持状态和ID；重生不重开遭遇；提交前后强杀、丢回执、旧配置/人工责任/重复重启不重发；无终局只退入场 |
| E07 H5 | 等距地图显示触发区、权威阶段/必杀进度/箱锁，提供前往遭遇区域；桌面/手机/一键公开输入完成闭环，无本地推进状态 |
| E08 回归 | 新Rust/浏览器矩阵与原完整专项通过，多个遭遇同一步的事件峰值不能使输出队列越界，超容量须冻结原结算并受控回收；最终源码/配置/二进制绑定，测试总数不重复计入各子集 |

顺序：规格→配置/有界遭遇状态机→奖励门禁与恢复→H5→专项/原完整回归→保留账本升级预览。
