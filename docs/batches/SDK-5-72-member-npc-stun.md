# SDK-5-72 NPC 弹道眩晕

对应 R3.2/M03/M04、原行为规格 §4.4 和原战斗接口的眩晕语义。目标 SDK 0.74.0、机制 89、schema 7、协议 6。NPC 弹道命中可按配置施加 `timed_control / stun`，使用配置时长、来源分组及同源刷新。

成功施加时中止准备中的技能与普攻、排队的动作、移动追击、引导后续脉冲和正在进行的撤离引导，清空移动方向与导航路径。准备被中断时保留原本尚未提交的费用与冷却。已提交动作的费用和冷却按原规则结算，已生成的弹道继续运行。有效期间拒绝移动、寻路、主动技能、普攻、主动弹道重定向及开始撤离。沿用已注册动作的控制打断规则，停止、取消、用道具和离场仍可按原规则执行。到期或净化后可提交新指令，原动作不自动重启。

眩晕沿用定时免疫、首控免疫、时长减免及 `cleanse_self_statuses`。同次命中的多个控制最多消耗一次首控机会。状态施加、刷新与移除仍由目标私有发布。这个切片验证多人 PvE 的 NPC 弹道入口，原内容的触发、免疫条件和其它来源按各自规格接入。

| ID | 验收 |
|---|---|
| ST01 | 机制 89 接受 NPC 命中绑定及净化引用，拒绝旧机制、非法字段和其他绑定。 |
| ST02 | 眩晕清空准备、排队、追击和移动，结束引导与撤离，保持已提交弹道和已付费用。有效期拒绝新的受控指令。 |
| ST03 | 验证目标私有、精确到期、定时和首控免疫优先、缩时、同源刷新及净化后恢复。 |
| ST04 | Node 和 H5 四人、八人房验证命中、准备中断且不扣费、眩晕期间位置不变、到期后新移动和新动作，以及一次结算。 |
| ST05 | 同一交付包通过仓库外空缓存离线接入、机制 88 定身兼容复验及 Rust 和 Node 回归。 |
