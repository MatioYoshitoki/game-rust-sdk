# B3-19 返剑窗口与仙陨边界闭环

2026-11-04。S01～S05 受控验收通过。[执行记录](../evidence/B3-19-sword-trial-2026-11-04.md)

沿用定向重击的剑路锁定、角色足迹、主动离开与反击流程。锁定玩家的剑式须正常结束，玩家已主动离开剑路且整个动作未接触玩家，才开启返剑窗口。窗内新发起的普攻或功法首次直接命中存活核心时追加一次物理伤害。旧动作、闪避、错误目标、超时和派生伤害无法消费窗口。已有脱战复位、保护、终局及核心死亡清理适用于返剑。

配置可按侧路完成状态延长窗口或缩放追加伤害。获得窗口时读取条件，冻结截止时刻和伤害预算，单项或两项可分别生效。仙陨边界基础窗口 2.4 秒、追加倍率 2.0。演武残场完成后，后续窗口延长 1.4 秒。承寰玉垣完成后，后续返剑倍率乘以 1.35。动作开始与返剑窗口打开之间完成的侧路在本次开窗生效。已开窗后完成的侧路从下一次开窗生效。

使用来源等距地形，在裂玉坛附近选择能完整推进剑路的可达空地，并用受控敌群和保底调谐材料完成单人验证。裂玉剑匣采用来源保底和独立随机掉落条目，来源五行抽选池另批交付。H5 展示锁定剑路、当前返剑窗口和实际追加伤害。普通攻击先结算，返剑走现有伤害、死亡、掉落和结算流程。
