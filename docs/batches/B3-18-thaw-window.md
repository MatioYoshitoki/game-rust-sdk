# B3-18 破冰窗口与万古冰川闭环

2026-11-04。T01～T05 受控验收通过。[执行记录](../evidence/B3-18-thaw-window-2026-11-04.md)

沿用限时判定的节拍、侧路条件、参数冻结和取消流程。新条件以玩家发起的直接命中判定。普攻或功法须在窗口开始后由 Rust 接纳，在截止前有效接触仍存活的核心。发起时刻等于开启时刻可计入，命中时刻等于截止时刻则已超窗。普通攻击先结算，若核心仍存活，首次有效命中追加一次冻结的破冰伤害，复用死亡、计分和掉落流程。普通攻击已经击杀核心时，破冰追加量为零。

窗口前发起的动作、闪避、命中其它成员、非主动接触和派生伤害均无法消费破冰。窗口内成功一次后，其它攻击仍走原伤害流程。窗口到期且没有成功破冰时，存活核心按冻结比例回复最大生命，实际回血受缺口约束。退出终局范围、保护、核心死亡或终局关闭清理窗口。整组复位清理旧轮次，已完成侧路继续生效。

万古冰川使用来源等距地形与冰门附近可达空地，采用单人验证敌群和保底玄冰。来源参数为 6 秒节拍、2.2 秒窗口、玩家攻击力 1.6 倍追加伤害，回冻按核心最大生命的 8% 计算。悬冰斗使后续窗口延长 1.5 秒，融雪泥沼使后续回冻乘以 35%。窗口开始后，侧路变化只影响后续窗口。H5 显示核心、窗口倒计时、破冰与实际回血。
