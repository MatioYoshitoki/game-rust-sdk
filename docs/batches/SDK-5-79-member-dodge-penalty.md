# SDK-5-79 自身技能闪避压制

对应 R3.3/M04 和原行为规格 §4.2 的 `dodgePenalty`。目标 SDK 0.81.0、机制 96、schema 7、协议 6。自身技能通过 `self_status.on_commit_self_statuses` 提供 `timed_attribute_modifier / dodge_penalty`。配置时长和正向 `modifier_bps`（1～10000），同源刷新，有效实例相加后封顶 10000 bps。

成员对 NPC 的直接接触通过资格判定后，读取攻击者当前压制，从 NPC 的闪避百分比扣除对应百分点，然后将本次闪避率限制在 0～50%。该切片采用原公式 `hit = 0` 的压制与封顶部分，原永久命中属性按其规格接入。0% 闪避使用确定结果，其余沿用 Rust 对局随机流。闪避时按原规则结束接触，伤害、暴击、普攻回灵及附带状态仅在有效命中后进入后续结算。

客户端观察私有加成状态、弹道与既有伤害事实。攻击者的压制只作用于其当前直接接触，其他成员、NPC 和周期伤害各走原路径。旧机制沿用对应的闪避计算。
