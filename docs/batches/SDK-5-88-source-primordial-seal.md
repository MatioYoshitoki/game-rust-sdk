# 玄域绝法主动阶段与易伤

本组归 DELIVERY-01。宿主通过 `combat_rules.unit_hit_statuses_by_mastery` 为即时敌对单位技能选择命中状态，按可信熟练阶段选最高满足下界的一行。无可信阶段或未达到首行时使用原命中列表。通过 `status_damage_taken_bps` 为有害状态配置易伤。Rust 在统一伤害链对物理和元素伤害乘以最高有效易伤倍率，保留原最终取整，随后结算护盾和生命。

将样例的 `skill` 加入技能目录，`status_definitions` 合入 PvE 状态表，`combat_rules` 按表合并。阶段来自座位的 `combat_build.powers["wushi-shu"].mastery`，对应索引 0～4。宿主为本技能配置可表示这些索引的威力模型，并提供足够的灵力和单次费用上限。 [配置样例](../../examples/combat-host/source-wushi-shu.json)

| 验收项 | 预期 |
|---|---|
| 配置 | 严格拒绝不适用技能、引导技能、无效阶段、重复/乱序下界、非法状态引用和越界易伤。默认列表、旧配置和无易伤目标沿用原路径。 |
| 原施法 | 350 距离的指定敌对单位效果，180 ms 前摇、140 ms 后摇、2000 ms 冷却。接受预留 3500000 灵力，成功提交只扣一次，目标失效不扣费。原物理功法倍率为 400%。 |
| 封印 | 入门 5000 ms，熟练起 6000 ms，按原状态因子降低 50% 防御。封禁新增或刷新的可驱散增益，保留已有增益。熟练和精通使用原表相同效果。 |
| 大成 | 同源命中刷新原封印，额外承受 15% 物理和元素伤害。多来源保留独立实例与时限，易伤取最高有效值。 |
| 圆满 | 封印自然结束时清除目标一份仍有效的可驱散增益。主动驱散、死亡、退场和关局只清理。 |
| 多人 | 同一配置按可信阶段选中不同状态。Rust 和 Node/H5 验证实际伤害、封禁刷新、作用目标、重连及一次结算。 |

易伤作用于配置化物理与元素伤害，真伤沿用既有定义。原资料只给出本效果的 15%，本批采用最高有效易伤处理多来源重叠。原真伤交互、常驻成长和真意另行验收。
