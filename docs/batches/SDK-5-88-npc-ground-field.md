# NPC 固定地面领域

本批归 R3.4。NPC 技能可配置固定圆形领域，复用施法准备、合法落点、共享区域容量、状态和伤害结算。用原火海领域验证。渡劫波次、天雷落和生产地图组合按各自范围验收。

| 验收项 | 预期 |
|---|---|
| 预警与释放 | 选敌时冻结合法落点，公开圆形预警，目标移动后落点保持原位。释放重验视线、落点、费用和打断，失败即回收。 |
| 周期结算 | 第一次伤害在释放后一个间隔。每个间隔按当前占位和墙体遮挡选人，按距离和身份排序。到期和末跳同刻时先结算末跳。火海半径 140，持续 8000 ms，每 1000 ms 取当前目标最大生命的 1%，最多 16 个目标一跳、256 次成功接触一实例。相同目标可在后续跳再次受伤。 |
| 入场状态 | 可信技能的命中状态在领域激活后的首次合法入场独立施加，重复进出不重复施加。火海灼烧按原定义持续 3000 ms，每 1000 ms 计算固定 15 加当前持有者攻击力的 350 基点，火属性。标准状态结算和清理继续生效。 |
| 失效与恢复 | 准备中的领域随来源失效结束。已释放领域可配置继续结算，保留旧来源代次。依赖活体来源的入场灼烧沿用状态清理。保护和伤害免疫拒绝伤害，减伤、盾和扣血复用通用结算。重连恢复固定落点、时间和命中预算，单成员退场保留其他席位的领域与状态，关局回收。 |

采用结构化施法配置的 750 ms 预警。试炼接口定义每跳按最大生命结算，样例将火海设为不可闪避，宿主可为其他技能配置闪避判定。原重复间隔为零的约束用于入场状态，固定周期独立计时。灼烧沿用状态到期排除规则，持续 3000 ms 时在第 1000、2000 ms 结算。已释放领域按配置存续时，仍需要原活体来源才能施加灼烧。
