# SDK-5-11 严格地面目标与单次圆形范围技能

2026-11-04，先冻结需求和验收，现已实现并通过受控验收。目标crate0.14.0 / 机制29，schema4 / 协议3单人PVE，最多两个玩家技能。本批只补通用机制，演示内容均为配置。

## 范围与契约

玩家新增mechanism=ground_circle，配置ID、cost、windup_ms、recovery_ms、cooldown_ms、damage_bps、range、radius、warning_ms。主副槽均可使用，沿现有两槽唯一ID、灵力、独立CD、共享准备/后摇。严格字段不允许speed/target/追踪等无效字段；可复用已有可选self/hit状态绑定及原容量/引用约束。版本必须≥29、schema4/PVE。range0.1～10000，radius0.1～128，warning_ms0～60000；其余沿已有边界。0预警仍至少跨一个固定步，不能同一步创建并结算；不添加持续区域、陷阱、更多槽或新伤害类型。

输入CastGround为`{"kind":"cast_ground","skill_id":"...","position":[x,y]}`。严格两个有限数值，不接受direction/target/金额等额外字段。坐标使用世界坐标，与H5等距投影无关。旧1～28不支持新意图；未知技能UNSUPPORTED，技能/意图不匹配INVALID_MESSAGE。

接受与提交都检查同一冻结坐标：地图内半开区间[0,width×cell_size)、[0,height×cell_size)，落点所在格可行走（不要求整个技能圆在地图内），中心距离≤range，既有Grid视线可达。非法非有限数为INVALID_MESSAGE；越界/不可行走落点INVALID_TARGET；超距/视线阻挡OUT_OF_RANGE。射程等值合法，可以选自己脚下。严格拒绝，不吸附、不裁剪、不自动导航。UI换选不改已接受坐标，施法者准备期间位移导致提交超距也免扣拒绝。

提交前再次预检当前灵力、self状态整组容量和未结算地面计划容量（每World最多2个）。失败发ActionRejected、不扣费/不开CD/不施加状态/不创建预警。成功施加合法self状态后读取有效ATK，冻结原始攻击量、配置、中心、来源、接受时间和遭遇轮次，沿原事务扣费、CD和共享后摇；发布预警。计划ID沿动作ID，重复输入不重复创建/扣费。

到期在固定步执行一次：按稳定怪物索引依次检查当前存活、启用、非归途、非复位倒计时、原遭遇轮次；中心距离≤radius+怪物半径且中心到单位无遮挡（既有弹道阻挡）才进入原直接命中链。读取当前DEF/护盾/闪避，沿原取整、击杀、掉落、遭遇和合法hit状态，不递归触发新区域；一次计划每敌人最多一次，多个敌人可命中，空区域也只结算一次。冻结攻击量不因后续增益到期/参数变化重算；目标移动进出按结算位置，地形和圆相交裁剪由逐目标视线完成。

## 生命周期与输出

提交前CancelAction/后台/死亡/终局/关闭/实际换轮沿原准备取消策略，免扣。移动沿原机制保持准备，提交按施法者当前位置重验射程/视线。提交后的移动、CancelAction、后台或同World重连不撤销已提交计划，不退款/回滚CD；玩家死亡、终局、关闭或任何实际遭遇换轮统一清空未结算玩家计划（带聚合取消事件），不会跨终局/新轮伤害或奖励。复位倒计时仅使该遭遇敌人暂不可命中，真正换轮才取消计划。同World重连恢复预警/CD/后摇，旧连接拒绝；重启仅处理冻结资产责任，不恢复World/预警/地面选点或重算旧金额。

机制29 pending_action和地面ActionCommitted增加可省略ground_position；PveView增加可省略player_area_warnings，每项action_id/skill_id/center/radius/started_at_ms/resolves_at_ms。新事件PlayerAreaStarted/Resolved/Cancelled提供同一身份、命中数或取消原因；取消最多一条聚合事件并计入关闭输出预算。旧1～28不输出地面字段，旧怪物圆形技能的成本/前摇/攻击量时序保持，只共享圆形接触与遮挡几何判断。公开Action/事件/视图为Rust源码变更，消费方需适配；Client六类、协议1～3、资产/恢复schema保持。

H5提供显式地图点选/纯触屏点选、坐标展示与圈形提示；未选点禁用技能，不偷偷取鼠标方向/单位位置或自动施法。已提交预警由Rust视图绘制，不自行判伤。Node仅提交选定世界坐标。两套包外配置交换主副槽、修改ID/数值/状态，以普通Node/H5验证预警、空区域、范围伤害、击杀拾取及撤离/死亡双终局。
