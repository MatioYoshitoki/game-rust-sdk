# 普攻实体弹道续段

本批属于 DELIVERY-01 与 R3.4。通过可信宿主选择普攻配置，使用可选的 `basic.projectile_followup` 表达命中后追加一枚伴生弹道，或按主段有效接触累计并发射多段弹道。用子母同心和六曜藏锋验证。两种器型继续使用原普攻输入与共同伤害链。

| 验收项 | 预期 |
|---|---|
| 子母同心 | 沿用剑系 330 射程、1500 速度、100 ms 前摇、700 ms 基础间隔。主剑与子剑伤害系数为 10500/3500 基点。主剑有效接触才在 90 ms 后释放一次子剑。发射时优先使用仍合法且在射程内的主目标，失效则按距离和实体 ID 选取当时合法且弹道可达的目标。没有候选则结束动作。 |
| 六曜藏锋 | 主剑系数 10000。每次主剑有效接触存一剑，按每剑 800 基点提高普攻时钟速率。第六次有效接触触发六剑齐射，第一枚在该接触步释放，其余按原定 55 ms 间隔在相应固定步释放。每枚小剑系数 3500，复用主剑释放点及本轮命中位置，绑定触发时的目标代次。目标失效后剩余小剑仍按冻结点飞行，且不改追或结算其他目标。最后一枚终止后清零，再开始基础间隔。 |
| 有效接触和阻挡 | 主段被障碍阻挡、落空、闪避或免疫时，不增加进度也不触发续段。有效接触沿用共同伤害链，护盾完全吸收时仍算接触。所有段使用连续的精确弹道阻挡，障碍与单位同刻时先处理障碍。附加段不叠加进度。 |
| 动作和容量 | 续段继承同一动作 ID，在发射主段时为可能并发的后续弹道预留容量。容量不足拒绝整次释放。回灵、动作级吸血和普攻冷却最多终态结算一次；死亡或退场释放所有容量。保护或重连保留已释放动作及其续段，沿用既有终态收益取消规则。 |
| 接入 | 公有弹道投影计划 ID、动作 ID、段序、发射时刻和冻结的瞄准点。私有快照投影当前储剑进度、上限和配置化攻速加成。重连恢复在途弹道和本人成长进度。验证 Rust、协议 6 解码及 Node/H5 普通宿主。 |

本批覆盖两种剑系器型的 PvE 行为。六印回锋的驻剑召回、回天飞盾的目标间弹射及被动回程由对应计划验收。
