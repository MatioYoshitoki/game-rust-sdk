# B3-13 整组脱战复位与重复挑战

日期：2026-11-04。状态：2026-11-04 R01～R08受控验收通过；基线531项，新增48项，最终579项唯一Rust、28项浏览器/进程及21组回归通过。

## 闭环与配置

部分击杀→移出追击范围→倒计时→未完成遭遇整组复位→重新挑战所有波次→真实完成→调谐/解封/开箱/拾取→撤离/死亡→资产恢复。只扩展单人遭遇；不交付多人贡献、动态侧路加持、通用Buff或战斗热恢复。原十三配置raw/hash与未配置复位时的AI/RNG保持。

schema2、mechanism_version=12。encounters[id].reset可选严格对象：mechanism=whole_encounter_round、reward_policy=first_defeat_per_spawn、pursuit_radius为有限trigger.radius～10000且包含本组出生足迹、delay_ms为step_ms～60000且不超过terminal_ms。数值全部配表，类型/未知或缺字段/能力/边界/布局非法拒绝。按终局时限与延迟推导最大轮次和真实死亡预算，总量≤4096；重复光球按TTL与清理周期核对原128地面资源预算；同组每轮同一槽位最多死亡一次。收益与物品上界仍按逻辑出生槽位计算，不因可复位而放大。

## 时序与复位

1. 只有已触发但未完成的Waiting/Spawning/Active遭遇可计时。玩家中心位于追击圆内或边界时保留本轮；离圆后开始now+delay_ms，不因持续离开重设时点。玩家真实移动先执行，截止同刻回到圆内优先取消。单纯前后台/断线不算空间离场：在圆内不启动复位，圆外已经开始的逻辑计时继续。死亡、成功撤离、关闭/故障停止计时，不产生新轮。
2. 倒计时期间该组存活成员停止战斗、取消施法/治疗/预警/反击并回防，但不单独回满生命、恢复灵力、清冷却/次数或重置阶段；本组回防期间暂停自然回复。提前回圆取消计时，继续同一轮剩余生命、MP、CD、支援次数和阶段，允许重新正常决策。
3. 到期仍离圆时，在本步AI/旧动作之前一次复位全部本组槽位，包括已死者和未来波次保留位。回初始位置/生命/灵力/初始阶段，清仇恨/路径/旧施法/后摇/CD/支援用量；所有波次进度回零，round+1，回Dormant，重新进触发区才安排第一波。保留稳定monster_id，epoch和能力动作序号单调，不复用旧动作身份；出生净空仍整组检查，受阻按原预算重试，不发布残缺波。
4. 不回滚其它已完成节点、玩家生命/MP/CD、背包/地面拾取、积分与已冻结资产。已完成/已领奖单调，不复位。玩家共享打断CD不随怪物复位清零。只清理该组来源的剑印层，其他来源保留原到期时间。

## 旧轮隔离与收益

玩家动作接纳时由Rust记录各遭遇轮次，提交弹道时携带该记录；旧动作和旧在途弹道对新轮成员不参与命中，不能伤害/打断/取得或消费反击机会，仍可作用于没有换轮的其它目标。清理本组来源敌方弹道、支援（含锁定该组目标者）、范围/重击/反击，关闭或到期不能补发旧效果；客户端没有设置轮次或直接复位接口。

每个可复位逻辑出生槽位保存本局死亡次数与最后死亡轮次。首次真实死亡才计入原ScoreSummary收益击杀、积分、修为及物品奖池；复位重杀仍走正式伤害/死亡/当前轮目标完成链，但不重复这些收益、不抽物品RNG。重复击杀可保留原光球恢复，光球ID带轮次且不产出物品；旧地面物品/光球及已拾取资产不重置。首次奖池即使没拾取或已过期也不再次发放。原普通容器/守护的独立重生策略不受影响。

ScoreView公开真实累计击杀，计分击杀/积分保留收益口径。冻结新增可选reset_progress={actual_kills,encounters:[{encounter_id,round,completed,defeats:[{monster_id,deaths,last_round}]}]}。数组严格排序、身份/归属/轮次/时限/次数有界；每个已配置组必须有一行。actual_kills=原收益摘要kills+重复死亡数。首次死亡按模板与原ScoreSummary核对，剩余非复位生成上界单独核对；完成组须本轮全部指定目标真正死亡，且与map_progress一致。缺失、重复、伪造、跨组、放大收益或物品证明拒绝。恢复仅履行原hash/正文/operationId一次，不重建轮次战斗或回放奖励。
