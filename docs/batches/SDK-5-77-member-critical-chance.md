# SDK-5-77 自身技能暴击率

对应 R3.3/M04 和原行为规格 §4.1、§4.2。目标 SDK 0.79.0、机制 94、schema 7、协议 6。自身技能通过 `self_status.on_commit_self_statuses` 提供 `timed_attribute_modifier / critical_chance`。配置时长和正向 `modifier_bps`（1～10000），同源刷新，有效实例相加后封顶 10000 bps。

成员直接命中 NPC 时，在资格和闪避判定之后读取攻击方的当前暴击率。0% 和 100% 使用确定结果，中间概率沿用 Rust 对局随机流。先计算有效护甲和破甲，再乘配置的 `params.critical_multiplier`，之后统一取整、应用原最低伤害、处理护盾及气血。NPC 原伤害、周期伤害与其他来源沿用各自规则。

客户端观察攻击者的私有加成状态与既有伤害事实。这个切片覆盖自身技能加成与当前多人 PvE 直接伤害，永久暴击属性、额外暴伤和专属内容按各自规格接入。

| ID | 验收 |
|---|---|
| CT01 | 机制 94 接受合法自身技能暴击率，拒绝旧机制、越界、非法重复策略、道具和其他绑定。 |
| CT02 | 验证原 `defense-crit` 算例，覆盖有效护甲、破甲、暴击、一次取整及护盾顺序。 |
| CT03 | 验证命中读取、封顶、精确到期、目标私有、命中与闪避后的随机流及其他伤害路径。 |
| CT04 | Node 和 H5 四人、八人房实测三次普攻伤害分别为 66 → 100 → 66 与 66 → 133 → 66。每位成员结算一次。 |
| CT05 | 同一交付包通过仓库外空缓存离线接入、机制 93 破甲兼容复验及 Rust 和 Node 回归。 |
