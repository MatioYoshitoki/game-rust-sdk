# 普攻灼烧与地面火海

本批属于 DELIVERY-01 与 R3.4。用火种燎原和焚野成海验证仅附状态的延时普攻、叠层状态的死亡扩散和地面普攻领域。可信配置提供交付方式、范围、伤害、时钟和状态定义。

| 验收项 | 预期 |
|---|---|
| 火种燎原 | 沿用炉系射程 260、前摇 180 ms、间隔 900 ms 和释放后延时 350 ms。单位必须存活、身份相符且通过精确视线与接触判定。一次有效接触施加一层灼烧，直接伤害和炉系自疗为零。 |
| 来源独立灼烧 | 同一目标可同时持有不同来源的实例。每来源最多 10 层，后续叠层刷新 5000 ms 有效期并保留 500 ms 跳时，刷新时按施加者当前攻击力重新取样。每层每跳按攻击力的 700 基点计算火焰伤害。每层降低受治疗 300 基点，同一状态定义跨来源合计最多降低 3000 基点。 |
| 死亡爆燃 | 仅配置了爆燃的来源，其对应灼烧跳直接击杀目标后，在死亡位置半径 125 内按死亡层数结算每层 900 基点的火焰伤害。候选按距离和稳定身份排序，受精确视线与配置目标上限约束。幸存者继承向上取整的 50% 层数。爆燃伤害的击杀不会继续爆燃。 |
| 焚野成海 | 锁定单位或显式地面输入均可。接纳输入时冻结落点，校验边界、射程和精确视线，前摇结束重新校验落点。释放后 350 ms 生成固定领域，目标移动或死亡不取消落点。半径 135、持续 7000 ms、间隔 500 ms，最多选八个目标，每跳按释放时攻击力的 900 基点结算。有效接触使幸存敌人减速 2500 基点、持续 750 ms，并叠加一层同源灼烧。 |
| 行为归属和恢复 | 火海只保留同来源最新一片，预留容量，保留其他来源场地。周期接触不重复触发普攻收益、自疗或冷却。离线保留已释放场地和状态，来源终结清理。Node/H5 从共同快照及增量读取落点、领域和状态。 |
| 边界和兼容 | 非地面普攻拒绝地面输入，混传单位和坐标、非有限坐标、越界与墙后落点拒绝。仅阻挡行走的地块可作为落点。免伤、目标退出、护盾、过期和容量遵循现有权威结算。旧普攻输入与发布形态保持兼容。 |
