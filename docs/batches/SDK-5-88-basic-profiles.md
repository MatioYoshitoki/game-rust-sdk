# 逐成员普攻配置与终态状态效果

本批属于 DELIVERY-01 与 R3.4 的交叉验收。机制 105 的可信宿主在 Create 席位传 `basic_profile`，由 `combat_rules.basic_profiles` 解析。每个成员在本局使用同一个配置 ID，配置包含前摇、范围、间隔和已有投送方式。没有席位选择时沿用对局 `basic`。原攻击指令仍只携带目标。配置及席位进入原创建身份与恢复校验。命名单体弹道绑定主目标，途中被别的敌人拦住时结束。

普攻可引用三个阶段的通用状态配置。释放时可施加一个自身状态，状态容量与其它提交条件一起预检。终态可在发生实际 HP 伤害后施加一个自身状态，也可对每个实际受伤且仍有效的目标按战斗种子均匀抽取一个状态。同一目标代次在同一动作内最多抽取一次，目标顺序采用实际伤害首次发生的顺序。状态使用已有来源、层数、持续时间和上限结算。目标品阶倍率按既有 NPC 战斗配置档位匹配，仅缩放该负面数值。保护撤销终态收益资格，退出清理沿用状态与投送生命周期。

| 验收项 | 预期 |
|---|---|
| 同一 World | 至少两人选择不同普攻配置。验证范围、前摇、波面及冷却分别生效，本人全量和重连可读冻结的配置 ID。 |
| 可信边界 | 错误配置 ID、旧协议传入和畸形数据在创建前拒绝，动作载荷无法注入配置。原配置和省略字段的原宿主可继续接入。 |
| 盾的终态吸收 | 按原盾系 5% 最大生命、1200 ms 验证。多目标只授予一次，零实际 HP 伤害与保护中断均无授予。 |
| 塔的提交与镇压 | 有效释放立即获得 15% 减伤，持续 900 ms。动作终态向实际受伤且有效的每个目标抽取一次 5000 ms 状态，单层基础 10% 移速或普攻频率，或 8% 攻击力，同状态最多两层并刷新，精英和首领按 75% 和 50% 缩放。 |
| 发布和交付 | 旧字段省略时保留协议形状。Rust、普通 Node 宿主和发布解码验证同局成员选择、生命周期和账务。 |

镇气依原设计和接口说明映射为攻击力修正。样例把宿主可信武器 ID 映射到房间的普攻配置 ID。本批冻结于创建，镜的同刻折射、鼎的固定延迟、命名器型和战斗内换装继续由 R3.4 验收。
