# SDK-5-56 多人灵力回复封锁

对应 R3.3/M04 及原需求 §4.3 的灵力封锁。目标 SDK 0.58.0、机制 73、schema 7、协议 6。多人 PvE 可在 `pve.status_definitions` 配置 `timed_attribute_modifier` 的 `spirit_recovery_lock` 属性，由成员技能的自身提交或恢复道具的自身绑定施加。沿用状态定义的 `modifier_bps: -10000` 表示完整封锁，重复策略支持 `refresh` 和 `ignore`。任一锁定状态有效时，该成员的自然回灵、普攻命中回灵、光球回灵和即时用药回灵均为零。按每次回复的执行时间判断，到期时刻恢复回灵资格。

气血照常结算。封锁时仍可拾取并消费自己的光球，气血回复按缺口裁剪。即时用药仅在仍有实际气血回复时消费，纯回灵药在封锁中拒绝，且保留原库存、修订和冷却。施加封锁的道具先结算当次回复，再应用附带状态。技能继续从当前灵力支付成本。

| ID | 验收 |
|---|---|
| SL01 | 机制 73 支持自身技能及道具绑定。旧机制、非完整倍率、叠层和命中或 NPC 绑定拒绝。 |
| SL02 | Rust 覆盖四条回灵路径、气血独立结算、成员隔离和精确到期。 |
| SL03 | 覆盖封锁中的光球单次消费、纯回灵药原子拒绝、双恢复药可凭气血回复成功。 |
| SL04 | 四人及八人房在 Node 和 H5 中走通自身施法、封锁中击杀拾取、到期后再次击杀拾取及退出结算。两房封锁时光球实回气血 / 灵力为 30/0 与 150/0，到期后为 30/30 与 150/120。 |
