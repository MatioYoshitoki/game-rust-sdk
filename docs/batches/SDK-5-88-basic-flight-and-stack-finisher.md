# 蓄力飞行爆炸与叠层终击

本批属于 DELIVERY-01 与 R3.4。大日坠炉复用普攻蓄力和实体弹道，九重浮屠复用叠层状态与径向波。可信配置提供档位、伤害、控制和时间。

| 验收项 | 预期 |
|---|---|
| 大日坠炉释放 | 800/1600 ms 切档，3000 ms 封顶。释放接受单位目标、地面坐标或方向三选一。单位取当时位置，方向按配置最大射程取点。服务端冻结档位、方向和落点，校验边界、射程和精确弹道视线。蓄力和 180 ms 前摇期间保留移动意图并维持发射原点，普通点按第一档锁定目标。 |
| 大日坠炉飞行 | 范围 430、速度 520，半径 28/42/60。沿路径连续扫掠，最多记八个独立目标。同目标的有效接触至少间隔 90 ms，按固定步执行，每档最多 3/4/5 次，伤害系数 1600/1800/2000 基点，每次有效接触叠一层同源灼烧。 |
| 大日坠炉爆炸 | 只在抵达冻结点后结算一次，半径 80/115/155，最多八个目标，伤害系数 6200/9000/12500，幸存目标分别追加 1/2/3 层灼烧。途中撞到弹道障碍则终止，目标移动、换代或退场不会改变已冻结落点。一次动作合并结算普攻收益，来源终结清理，保护和重连保留已发弹道。 |
| 九重浮屠筑层 | 基础波半径 190，最多四个目标，主副系数 6200/5600。每次普攻终态有实际扣血才筑一层，最多五层，刷新 6000 ms 有效期，每层 200 基点减伤，走共享减伤上限和护盾顺序。两名成员各自计数。 |
| 九重浮屠终击 | 前摇结束时仍持有五层才替换为半径 230、最多六目标、主副系数 9500/8200 的径向波。已释放终击在终态清层，即使候选在途中失效或实际扣血为零。释放前取消、目标非法或容量拒绝保留现有层数，层数到期按普通波重验射程。 |
| 发布与兼容 | 火球沿用弹道集合，发布动作、档位、落点及飞行和爆炸事件。塔影通过本人已有状态视图发布。用 Rust 和 Node/H5 验证同局独立性、重连、退出与旧协议字段兼容。 |
